## 2. บั๊กที่ต้องแก้ก่อน (เรียงตามความสำคัญ)

### ระดับ 1 — ต้องแก้ด่วน (Codex C17 พบ)
1. **ใบยืนยันเก่าของ "กางเกงช้าง" และ "กางเกงมวยไทย" ตัวเลขขนาดหายเมื่อเปิดแก้ใหม่:**
   - **เกิดอะไร:** ถ้าเปิดไฟล์ใบเก่า (ก่อนอัปเดตล่าสุด) ที่เคยกรอกขนาดแบบกำหนดเองไว้ ระบบไม่แสดงตัวเลขรอบอก/ความยาวเดิมในช่องใหม่ และพอส่งออก PDF ตัวเลขเหล่านั้นหายไป (ทั้งที่ข้อมูลเดิมยังอยู่ในไฟล์)
   - **กระทบใคร:** แอดมินที่เอาใบยืนยันเก่าของกางเกงช้างหรือมวยไทยมาทำซ้ำหรือแก้ไข
   - **ระหว่างรอแก้:** ให้ดูตัวเลขขนาดจาก PDF ใบเดิมแล้วกรอกลงช่องรอบเอว/สะโพก/ความยาวขาใหม่ก่อนส่งออก PDF

### ระดับ 2–3 — ควรทยอยแก้ (รวมของรอบ 15 ที่ค้าง + รอบ 16)
2. **ขนาดติดลบในช่องกรอกสเปกยังส่งออก PDF ได้ (R15-01 + ขยายไปช่องขนาดกางเกงใหม่):** ช่องรอบอกเสื้อเจอร์ซีย์และรอบเอวกางเกงช้างรับเลขติดลบ (เช่น `-2.5`) แล้วพิมพ์ลง PDF ได้
   - *ระหว่างรอแก้:* แอดมินตรวจตัวเลขในตัวอย่าง PDF ก่อนกดส่งออก
3. **แถบแจ้ง "มีระบบรุ่นใหม่" แสดงภาษาพม่าให้แอดมิน/ผู้บริหาร (R15-04):** ถ้าเครื่องเคยเปิดโหมดพม่ามาก่อน พอล็อกอินแอดมิน/ผู้บริหาร แถบอัปเดตยังจำภาษาพม่าอยู่
   - *ระหว่างรอแก้:* กดรีเฟรชหรือกดปุ่มโหลดบนแถบนั้นได้เลย (ปุ่มทำงานปกติ)
4. **คำเตือนภาษาไทยในจอพม่าเมื่อกดซ้ำ / ชื่อถูกตัดบนจอมือถือเล็ก (R15-02, R15-03):** ข้อความแจ้งเตือนตอนแท็บเก่ากดชนกันยังขึ้นไทยในบรรทัดล่าง และบนมือถือจอเล็ก 375 px ชื่อผู้ใช้มุมขวาบนกับปุ่ม "แจ้งปัญหา" มุมขวาล่างถูกตัดท้ายคำเล็กน้อย
5. **ปุ่ม "เปลี่ยนเป็น PDF ใบใหม่" ไม่มีแถบสีเขียวบอกหลังบันทึกสำเร็จ (R16-AG-01):** พอกดเปลี่ยน PDF สำเร็จ ปุ่มแค่รีเซ็ตกลับเป็นให้เลือกไฟล์ใหม่ แอดมินอาจไม่แน่ใจว่าบันทึกแล้วหรือยัง
   - *ระหว่างรอแก้:* เลื่อนดูในประวัติการทำงานด้านล่างว่าขึ้น "เปลี่ยน PDF ใบยืนยัน" แล้ว
6. **ปุ่มติ๊ก "มาตรฐาน" ในตารางกระเป๋าบนมือถือเล็กไปนิด (R16-AG-02):** ช่องติ๊กบนมือถือสูง 20 px ทำให้กดด้วยนิ้วยากกว่าปุ่มอื่น

## 3. สิ่งที่ต้องบอกทีมหน้างานและแอดมิน
1. **เวลาลูกค้าขอแก้ที่อยู่หลังรับงาน:** ให้เปิดรายละเอียดงาน → กด **"ลูกค้าขอแก้ใบยืนยัน"** → กด **"เปิดใบยืนยันในฟอร์ม"** → แก้ที่อยู่ + ใส่เลข **"แก้ไขครั้งที่"** → ส่งออก PDF ให้ลูกค้าเซ็น → กลับมาแนบ **"เปลี่ยนเป็น PDF ใบใหม่"**
2. **ถ้าลูกค้าขอแก้สเปกการผลิตด้วย (ไม่ใช่แค่ที่อยู่):** การแก้ในฟอร์มใบยืนยัน **ไม่เปลี่ยนข้อมูลบนการ์ดงานของฝ่ายผลิตอัตโนมัติ** แอดมินต้องเปลี่ยน PDF ใบใหม่ **และ** อัปเดตม็อคอัพกำกับสเปก (หรือแจ้งฝ่ายผลิตหน้างาน) ด้วยทุกครั้ง
3. **กางเกงช้าง / ชุดนอนแบบกำหนดขนาดเอง:** ช่องใหม่แยก รอบเอว / รอบสะโพก / ความยาวขา ให้แล้ว และซ่อนตารางไซซ์โรงงาน FS/PS ออกให้อัตโนมัติเวลาลูกค้ากำหนดขนาดเอง

## 4. ข้อเสนอที่ไม่ใช่บั๊ก (ทำเพิ่มเติมทีหลังได้)
- อัปเดต **คู่มือแอดมิน** เพิ่มขั้นตอน *"ลูกค้าขอแก้ใบยืนยัน"* และอัปเดตภาพประกอบเก่าใน `docs/คู่มือ/img/` ให้ตรงหน้าจอล่าสุด
- เพิ่มแถบข้อความสีเขียว `"เปลี่ยน PDF ใบยืนยันแล้ว"` หลังแอดมินกดเปลี่ยนไฟล์ PDF เพื่อให้มั่นใจทันทีโดยไม่ต้องเลื่อนลงไปดูประวัติ
