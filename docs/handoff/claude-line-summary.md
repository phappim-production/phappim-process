# สรุปงานส่งไลน์ (ต่องาน)

Branch `claude/line-summary` · ไม่แตะฐานข้อมูล · ไม่เพิ่ม dependency

## เจ้าของขอ
"ต้องการข้อมูลสรุปส่งในไลน์ ในแต่ละงาน เพื่อให้แอดมินด้วย" · ส่งตัวอย่างข้อความมา (เลขที่ใบ + ลูกค้า · วันที่ส่งงาน · ชื่องาน · สเปกเป็นข้อ ๆ · จำนวนทั้งหมด · ขึ้นตัวอย่าง)

## เปลี่ยนอะไร
- `production-confirmation.html`: ฟังก์ชัน `lineSummary()` สร้างข้อความจากใบยืนยัน (ป้ายชื่อช่องของทุกสินค้าอยู่ในฟอร์มนี้ที่เดียว จึงสร้างที่นี่) + ปุ่ม "สรุปส่งไลน์" บนแถบบน + กล่องข้อความที่แก้ก่อนส่งได้ · ปุ่ม "ส่งเข้าไลน์ / แชร์" (`navigator.share` · ขึ้นเฉพาะเครื่องที่แชร์ได้ เช่น มือถือ) · "คัดลอกข้อความ" (คอม) · เปิดจากระบบพร้อม `line: true` = เปิดกล่องให้ทันที
- `app/src/pages/Revision.tsx`: แยกการเปิดใบยืนยันเป็น `openConfirmationView` · เพิ่ม `LineSummaryButton`
- `app/src/pages/JobActions.tsx`: ปุ่ม "สรุปงานส่งไลน์" ในรายละเอียดงาน ให้แอดมิน / เจ้าของ / ฝ่ายผลิต / หัวหน้างาน (ไม่ขึ้นที่หน้าจอพนักงานสถานี / QC)
- ข้อความมี: เลขที่ใบ ลูกค้า (แก้ไขครั้งที่) · วันที่ส่งงาน · ชนิดสินค้า · ชื่องาน · สเปกทุกช่องที่ใบฉบับโรงงานแสดง · จำนวนตามสี/ไซซ์ หรือรายการ (ขนาด × จำนวน) · ตำแหน่งพิมพ์ · จำนวนทั้งหมด (+ เผื่อเสีย) · ขึ้นตัวอย่าง / งาน Develop + วันส่งตัวอย่าง
- **ไม่ใส่** ผู้ติดต่อ เบอร์โทร ที่อยู่ การรับสินค้า ไฟล์งาน รูป (ส่งเข้ากลุ่มไลน์)

## ยังไม่ได้ทำ / ข้อจำกัด
- ระบบไม่มีเวลาส่ง (มีแต่วันที่) และไม่มี "หักตัวอย่างในออเดอร์ / คงเหลือ" · แอดมินพิมพ์เพิ่มในกล่องก่อนส่งได้
- งานที่รับเข้าโดยไม่ใช้ฟอร์มใบยืนยัน ไม่มีสรุป (ขึ้นข้อความเดิมของปุ่มดูใบยืนยัน)
- ยังไม่ได้ลองบนมือถือจริง (แชร์ไปไลน์จริง) · ในระบบจำลองลองด้วย `navigator.share` จำลอง
- ไม่ส่งไลน์อัตโนมัติ (ต้องใช้ LINE OA + token) · ทำได้ภายหลังถ้าเจ้าของต้องการ
