ใครกดอะไร

จุดในระบบคนกดสิ่งที่บันทึก
รับงานเข้าโรงงานผู้ควบคุมงานแนบ PDF, ข้อมูลหัวใบ, ประเภทสินค้า, เส้นทาง, วันกำหนดเสร็จ
เช็ควัตถุดิบแอดมินQCฝ่ายผลิตติ๊กรายการที่ฝ่ายตัวเองรับผิดชอบ
สั่งฟิล์ม DTF / ได้รับฟิล์มแอดมินวันที่สั่ง, วันที่คาดว่าจะมาถึง, วันที่ได้รับจริง
ขึ้นตัวอย่าง: เริ่ม / เสร็จแต่ละสถานีผู้ควบคุมงานเวลาเริ่มและเสร็จ, รอบที่
ผลตัวอย่าง ผ่าน / ไม่ผ่านแอดมินผลหลังลูกค้ายืนยัน, สิ่งที่ต้องแก้
สถานีผลิต: เริ่ม / ติ๊กขั้นตรวจ / เสร็จผู้ควบคุมงานเวลาแต่ละสถานี, ผลตรวจ, จำนวนชิ้นที่ตัด
เย็บ: อนุมัติตัวแรกผู้ควบคุมงาน (หัวหน้า)ผ่าน / ไม่ผ่าน, สิ่งที่ต้องแก้
เย็บ: กรอกยอดเย็บแล้วผู้ควบคุมงานยอดสะสม, เวลาที่กรอก
QC: ผลตรวจ / ส่งกลับแก้ผู้ควบคุมงานQCจำนวนผ่าน/ไม่ผ่าน, สาเหตุ, สถานีต้นเหตุ
ติดปัญหา / พักงานผู้ควบคุมงานสาเหตุ, เวลาเริ่มพัก, เวลาแก้เสร็จ
กฎที่ระบบบังคับ

สิ่งที่ระบบไม่ยอมให้ทำ

รับงานไม่มี PDF เซ็นครบ รับงานไม่ได้ปุ่มรับงานจะกดไม่ได้ จนกว่าแนบใบยืนยันฉบับที่ลูกค้าและเจ้าหน้าที่เซ็นแล้ว
ด่านวัตถุดิบไม่ครบทุกฝ่าย ขึ้นตัวอย่างไม่ได้ถ้ายังติ๊กไม่ครบ งานจะค้างที่ “รอวัตถุดิบ” และแสดงว่ารอฝ่ายไหน
ด่านตัวอย่างตัวอย่างยังไม่ผ่าน ผลิตจริงไม่ได้ต้องมีผล “ผ่าน” จากแอดมินก่อน ถ้าไม่ผ่าน งานกลับไปขึ้นตัวอย่างรอบใหม่
ทุกสถานีข้ามสถานีไม่ได้สถานีถัดไปเริ่มได้เมื่อสถานีก่อนหน้ากด “เสร็จ” ครบทั้งก้อนแล้ว
ทุกสถานียังไม่ติ๊กขั้นตรวจ กดเสร็จไม่ได้เช่น ตรวจงานพิมพ์, ตรวจสีและการติด, กรอกจำนวนชิ้นที่ตัด
เส้นทาง DTFยังไม่ได้รับฟิล์ม รีด DTF ไม่ได้ปลดล็อกเมื่อแอดมินกด “ได้รับฟิล์มแล้ว” และระหว่างรอ การ์ดงานจะขึ้นวันที่คาดว่าฟิล์มจะมาถึง
เย็บตัวแรกยังไม่ผ่าน เย็บทั้งก้อนไม่ได้หัวหน้าต้องอนุมัติชิ้นแรกก่อน ยอดเย็บจึงเริ่มกรอกได้
QCส่งกลับแก้ต้องมีจำนวนและสาเหตุระบุสถานีต้นเหตุด้วย เพื่อดูย้อนได้ว่าปัญหาเกิดซ้ำที่จุดไหน
พักงานพักงานต้องมีสาเหตุเวลาพักจะแยกออกจากเวลาทำงาน เพื่อให้วัดคอขวดได้ถูก
ด่านวัตถุดิบ

รายการวัตถุดิบแบ่งตามฝ่าย

รายการด้านล่างเป็นตัวอย่าง ของจริงตั้งค่าแยกตามประเภทสินค้า (เสื้อ / ป้ายผ้า / กระเป๋า) และเส้นทางได้ในหน้าตั้งค่า

วัตถุดิบ (ตัวอย่าง)ฝ่ายที่เช็คใช้กับเส้นทาง
ผ้าตามสเปก (เช่น ผ้าไซลอน)แอดมินทั้งสองเส้นทาง
ไฟล์งานพร้อมพิมพ์แอดมินปกติ
ฟิล์ม DTF (สั่งแล้ว)แอดมินDTF
หมึก / กระดาษพิมพ์ฝ่ายผลิตปกติ
ด้ายสีตามสเปก / อุปกรณ์เย็บ (รางสอด, ตาไก่, ซิป)ฝ่ายผลิตทั้งสองเส้นทาง
ป้ายคอ / แท็ก / ถุงแพ็ค / ลังQCทั้งสองเส้นทาง
สิ่งที่ได้จากการกด

ตัวเลขที่ระบบคำนวณให้

ดูสด (Dashboard)
  • งานในแต่ละสถานี: รอคิว / กำลังทำ
  • ความคืบหน้าขั้นเย็บ (ยอดเย็บแล้ว / ยอดทั้งหมด)
  • งานที่ค้างรอวัตถุดิบ และรอฝ่ายไหน
  • งานที่รอฟิล์ม DTF และงานที่เลยวันคาดว่าจะได้รับ
  • งานรอผลตัวอย่าง
  • งานที่ติดปัญหา และงานเลยกำหนด
  • ยอดงานเสร็จวันนี้
รายงานย้อนหลัง
  • เวลาทำงานและเวลารอคิวเฉลี่ยของแต่ละสถานี (หาคอขวด)
  • จำนวนรอบตัวอย่างต่องาน
  • อัตราตัวแรกไม่ผ่าน แยกตามประเภทสินค้า
  • งานแก้จาก QC แยกตามสาเหตุและสถานีต้นเหตุ
  • เวลารอฟิล์ม DTF เทียบกับวันที่แอดมินแจ้ง
  • สาเหตุพักงานที่เจอบ่อย
  • % งานเสร็จทันกำหนด
