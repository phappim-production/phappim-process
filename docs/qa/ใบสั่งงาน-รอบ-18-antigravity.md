## ส่วน A — ของที่เพิ่มหลังรอบ 16 (ยังไม่มีใครกดแบบคนจริง)
1. **แก้ใบหลังรับงาน แบบระบบจำ (PR 185):** รับงาน → เดิน 2–3 สถานี → รายละเอียดงาน → "ส่งออก PDF ใบยืนยันอีกครั้ง / แก้ใบ" → เปิดในฟอร์ม → แก้ลูกค้า / ชื่องาน / จำนวน / เผื่อเสีย / กำหนดส่ง / สเปก → **บันทึกการแก้เข้างาน** → บอร์ด คิว ใบปะ ประวัติ กล่องจดหมาย (`spec_revised` ทุกฝ่าย) เปลี่ยนตามไหม · ลองเปลี่ยนสินค้า / ขึ้นตัวอย่าง (ต้องถูกบล็อก) · มีม็อคอัพฉบับอนุมัติแล้วระบบบอกจุดที่ยังเป็นค่าเก่าไหม · แก้ซ้ำหลายครั้ง · 2 แท็บแก้ใบเดียวกัน
2. **ปุ่ม "ไม่ใช้กับงานนี้" (PR 185):** ช่องบังคับที่ว่าง → กดแล้วไม่เตือน ไม่พิมพ์ ไม่ส่งเข้าสเปก · ช่องที่ระบบใช้ตั้งค่างานต้องกดไม่ได้ · ยกเลิกกลับมากรอกได้
3. **แบ่งงาน + แก้ใบ (PR 187):** แบ่ง 100 → 70 + 30 → แก้ใบจากงานแม่ และจากส่วนที่แบ่ง → จำนวนแต่ละส่วนคงเดิม · สเปกเปลี่ยนทุกส่วน · ใส่ยอดไม่ตรงต้องถูกปฏิเสธด้วยข้อความไทยที่บอกยอดที่ต้องใส่ · แบ่งซ้ำ 2–3 ชั้นที่ท้ายคิว แล้วรับงานใหม่ได้ · ออเดอร์หลายสินค้า `-0001` `-0002` ไม่ปนกัน
4. **ป้าย "ล่าช้า X วัน" (PR 189):** งานเลยกำหนด (ตั้งกำหนดส่งย้อนหลัง หรือเลื่อนเวลาเครื่อง) → บอร์ด การ์ด ภาพรวม รายละเอียดงาน รายงาน ใช้คำเดียวกัน · จำนวนวันนับวันทำงาน จ.–ส. ถูกต้อง (ข้ามอาทิตย์) · โหมดพม่า
5. **ใบยืนยัน PR 177–184:** ขนาด/จำนวนติดลบบล็อก PDF · ช่วง "28-34" ได้ · เปิดใบจากระบบแล้วส่งออก PDF ได้โดยไม่ต้องรีเฟรช (PR 184) · กระเป๋ากุ๊น/มาตรฐาน · ตารางขนาดเสื้อ/กางเกง · ถุงพับได้
6. **ม็อคอัพ (PR 181):** จุดชี้ใกล้ขอบภาพไม่โดนตัด · จอแคบข้อความไม่หาย · `/confirmation?…` เปิดได้แม้มี service worker

## ส่วน B — ครบระบบ: ทุกบทบาท × ทุกเส้นทาง (ทำตามคู่มือทีละขั้น · ถ่ายภาพทุกจุดที่ติด)
1. **ทุกเส้นทาง 9 เส้น** (รวมผลิตข้างนอกทั้งหมด · มีตัวอย่าง · ส่งออกต่างประเทศ) เดินครบจนจัดส่ง ด้วยคนที่จะกดจริง · หลังแต่ละขั้นตรวจบอร์ด ภาพรวม คิว กล่องจดหมาย ประวัติ ของทุกบทบาทว่าตรงกัน
2. **แอดมิน:** ใบยืนยัน 1 ใบต่อกลุ่มสินค้า (เสื้อ · กางเกง · ป้าย · กระเป๋า/ถุง · หมวก · หมอน · เหรียญ/โล่ · เจอร์ซีย์) → บันทึกเข้าระบบ → รับงาน → แนบ PDF → ฟิล์ม → ส่งออก/รับกลับ → แบ่งงาน → ผลตัวอย่าง → จัดส่ง / ยกเลิกจัดส่ง → ม็อคอัพ ทำ/แก้/อนุมัติเอง
3. **ฝ่ายผลิต 2 คนพร้อมกัน:** เริ่ม/เสร็จ/พัก · เริ่มก่อนคิว · แทรกงานด่วน · จักร (เลือก/เสีย/คืน) · รายงานเกินเวลา · อนุมัติ/ส่งกลับม็อคอัพ
4. **staff มือถือ 375 px โหมดพม่า:** สถานีเดียว / หลายสถานี / ยังไม่จับคู่ · รับทราบสเปก · ดูม็อคอัพ · แจ้งปัญหา · คนอ่านไทยไม่ออกทำงานได้ครบจากไอคอน สี เลขสถานี คำพม่าไหม
5. **QC + Packing โหมดพม่า:** ผ่าน · ส่งแก้ทุกสถานี (รวมผลิตข้างนอก) · ผ่านไม่ครบกดเสร็จไม่ได้ · ข้อความ error จากฐานข้อมูลเป็นพม่า
6. **ผู้บริหาร:** ภาพรวม · คิว · ยกเลิกงานทุกสถานะ (รวมงานที่แบ่งแล้ว · งานที่อยู่ข้างนอก) · รายงาน · ตรวจย้อนหลัง
7. **เจ้าของ:** ตั้งค่าทุกแท็บ · จับคู่สถานี · บัญชีผู้ใช้ (เปิด/ปิด · บัญชีที่ปิดต้องเข้าไม่ได้/อ่านไม่ได้) · ทำแทนทุกบทบาท
8. **ผู้ควบคุมเฟส 1 / เฟส 2:** เห็นและกดได้ตามเฟส
9. **สิทธิ์ผ่านหน้าจอ:** แต่ละบทบาทเปิด URL หน้าที่ไม่ใช่ของตัวเองตรงๆ (`#/…`) → ต้องเข้าไม่ได้หรือเห็นแค่ที่ควร
10. **คำบนจอ vs คู่มือ:** ปุ่ม/เมนูตรงกันไหม · ภาพคู่มือที่ล้าสมัย
