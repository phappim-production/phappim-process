# แผนอบรมใช้งานระบบ — วันอาทิตย์ 22 พ.ย. 2569

> รูปแบบ: แบ่งรอบตามบทบาท **รอบละ 30 นาที** (15 นาทีอธิบาย + 15 นาทีฝึกกดจริงบนแท็บเล็ตด้วยงานทดสอบ `TEST-`)
> เป้าหมาย: ทุกคนกดงานจริงเป็น ไม่ส่งเครื่องต่อโดยไม่ **ออกจากระบบ** และรู้ว่าเน็ตหลุดต้องทำอย่างไร

## รายละเอียดแผนอบรมรายบทบาท (30 นาที/รอบ)

### รอบที่ 1: ฝ่ายผลิต (30 นาที)
- **หัวข้อสอน (15 นาที):**
  1. ล็อกอิน · **กล่องจดหมาย** (กระดิ่งมุมขวาบน) · กฎเหล็ก **ออกจากระบบทุกครั้งเมื่อส่งเครื่องต่อ**
  2. ดูแท็บ **ต้องทำตอนนี้** vs **บอร์ด** vs **จักรเย็บ**
  3. วิธี **รับงาน** ใหม่จาก **ใบยืนยัน** · เลือกเส้นทาง 8 แบบ · เลือก **ขึ้นตัวอย่าง / ไม่ขึ้นตัวอย่าง** + แนบ PDF
  4. ติ๊ก **วัตถุดิบ** ฝั่งผลิต · เดิน **สถานี** และทำ **ขั้นย่อย** (รวม **รีดฟิล์ม** และ **ส่งปัก (ร้านนอก)**) · ปุ่ม **แจ้งว่ากดผิด** (บันทึกว่าผิดพร้อมเหตุผล ไม่ได้ย้อนสถานะงาน)
  5. เย็บ/จักร (**งานเย็บ**, **ตารางจอง**, **สถานะจักร**) และสังเกตป้าย **งานแก้** สีแดง
  6. **พักงาน** (พิมพ์สาเหตุ), **รายงานปัญหา** (เมื่อแถบแดง **เกินเวลามาตรฐาน**), และทำอย่างไรเมื่อ **เน็ตหลุด**
- **แบบฝึกกดจริง (15 นาที):**
  1. ล็อกอินด้วยบัญชีตัวเองบนแท็บเล็ต
  2. ลอง **รับงาน** ทดสอบ 1 ใบ (เลือกเส้นทาง + เลือกขึ้นตัวอย่าง/ไม่ขึ้นตัวอย่าง) + ติ๊ก **วัตถุดิบ** ฝั่งผลิต
  3. ลองกดจบ **สถานี** ก่อนติ๊ก **ขั้นย่อย** บังคับ (ดูข้อความเตือน) แล้วติ๊กครบและกดเสร็จ
  4. ลองกด **พักงาน** (พิมพ์สาเหตุ) แล้วกด **แก้แล้ว ทำต่อ**
  5. กด **ออกจากระบบ** แล้วส่งแท็บเล็ตให้เพื่อนข้างๆ ล็อกอินต่อ

---

### รอบที่ 2: แอดมิน (30 นาที)
- **หัวข้อสอน (15 นาที):**
  1. ล็อกอิน · **กล่องจดหมาย** · **ออกจากระบบ**
  2. ใช้หน้า **งานที่ต้องตาม** เพื่อเช็กงานรอฝั่งแอดมิน
  3. ติ๊ก **วัตถุดิบ** ฝั่งแอดมิน + บันทึกสั่งและรับฟิล์ม (รองรับ **DTF / DTG / ซิลค์สกรีน**)
  4. บันทึกผล **ขึ้นตัวอย่าง** (ผ่าน / ไม่ผ่านพร้อมระบุสิ่งที่ต้องแก้)
  5. ใช้ **ค้นหางาน** ดูรายละเอียดงาน/ไทม์ไลน์/เปิด PDF · **วางแผนรับงาน** · รับมือเมื่อ **เน็ตหลุด**
- **แบบฝึกกดจริง (15 นาที):**
  1. เปิดงานทดสอบ `TEST-` แล้วติ๊ก **วัตถุดิบ** ฝั่งแอดมิน
  2. ลองบันทึกสั่งฟิล์ม และกด **ได้รับฟิล์มแล้ว**
  3. ลองบันทึกผล **ขึ้นตัวอย่าง** แบบไม่ผ่าน (กรอกสิ่งที่ต้องแก้) แล้วบันทึกผ่าน
  4. ใช้ **ค้นหางาน** ค้นเลขที่ `TEST-` เพื่อดูสถานะ **รอบตัวอย่าง** และ **ไทม์ไลน์ทุกการกด**

---

### รอบที่ 3: ฝ่าย QC (30 นาที)
- **หัวข้อสอน (15 นาที):**
  1. ล็อกอิน · **กล่องจดหมาย** · **ออกจากระบบ**
  2. ดูแท็บ **ต้องทำตอนนี้** และ **บอร์ด**
  3. ติ๊ก **วัตถุดิบ** ฝั่ง QC
  4. เดิน **สถานี** **QC + Packing** (เช็ก **ขั้นย่อย** บังคับให้ครบ)
  5. วิธีส่ง **งานแก้** (ป้ายสีแดง) กลับ **สถานี** เย็บ + **พักงาน** / **รายงานปัญหา** + **เน็ตหลุด**
- **แบบฝึกกดจริง (15 นาที):**
  1. ติ๊ก **วัตถุดิบ** ฝั่ง QC บนงานทดสอบ
  2. เริ่ม **QC + Packing** แล้วลองส่ง **งานแก้** กลับไปเย็บ 5 ชิ้น พร้อมระบุสาเหตุ
  3. ตรวจงานแก้รอบที่กลับมาจากเย็บ แล้วกรอก **ขั้นย่อย** ครบเพื่อกด **QC + Packing เสร็จ**
  4. กด **ออกจากระบบ**

---

### รอบที่ 4: ผู้บริหาร (30 นาที)
- **หัวข้อสอน (15 นาที):**
  1. ล็อกอิน · **กล่องจดหมาย** · **ออกจากระบบ**
  2. อ่านหน้า **ภาพรวม** และ **งานที่ต้องตาม** (แยกสี แดง / ส้ม / ฟ้า / เขียว)
  3. ดู **บอร์ด** สด, **จักรเย็บ**, **ค้นหางาน**, และ **รายงาน**
  4. ย้ำสิทธิ์ "ดูได้อย่างเดียว" และวิธีอ่านแถบ **ขาดการเชื่อมต่อ**
- **แบบฝึกกดจริง (15 นาที):**
  1. เปิดหน้า **ภาพรวม** และ **งานที่ต้องตาม** แล้วลองกรองหางานติดปัญหา
  2. เข้า **บอร์ด** เพื่อดูว่างานทดสอบกำลังอยู่ **สถานี** ไหน
  3. เปิดหน้า **รายงาน** เพื่อดูตัวเลขสรุป

---

### รอบที่ 5: เจ้าของระบบ (30 นาที)
- **หัวข้อสอน (15 นาที):**
  1. ความปลอดภัยบัญชีเจ้าของระบบ (ห้ามล็อกอินค้างบนเครื่องหน้างาน)
  2. ภาพรวมทั้งระบบ, **กล่องจดหมาย**, **รายงาน**, และการตรวจงานค้างทุกเช้า
  3. วิธีแก้ไขเมื่อกดผิดด้วยปุ่ม **แจ้งว่ากดผิด** ใน **ไทม์ไลน์ทุกการกด** (บันทึกว่ารายการนั้นผิดพร้อมเหตุผล ไม่ได้ย้อนสถานะงาน · ถ้าต้องย้อนสถานะจริงให้เจ้าของระบบดำเนินการ) (ไม่แก้ตรงในฐานข้อมูล)
  4. การ **ตั้งค่า** และสร้างบัญชีใหม่ใน **Supabase → Authentication → Add user** + กำหนดบทบาทบนหน้าเว็บ + รับมือ **เน็ตหลุด**
- **แบบฝึกกดจริง (15 นาที):**
  1. ตรวจดูหน้า **ภาพรวม** และ **ค้นหางาน** จากงานทดสอบ `TEST-`
  2. ตรวจเช็กรายชื่อบัญชีผู้ใช้งานจริงทั้งหมดก่อนเปิดใช้จันทร์ที่ 23 พ.ย.
  3. ซ้อม **ออกจากระบบ** ทุกครั้งหลังใช้งาน
