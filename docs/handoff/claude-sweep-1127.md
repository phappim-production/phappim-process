- แผงลายเซ็นลูกค้า: โหลดไม่ได้มีปุ่มลองใหม่ (เดิมค้าง "กำลังโหลด") · บอกว่าลายเซ็นจะนับเป็นใบครั้งที่เท่าไร · ปิดหน้าต่างไม่ได้ระหว่างบันทึก · รูปเสียมีข้อความ · กรอบตัดพอดีรูป · เปลี่ยนงานแล้วแผงเริ่มใหม่ (`key`) · คำสั่งอ่านไม่สั่งโหลดรายละเอียดงานซ้ำ (`rpc(..., { read: true })`)
- เปิดจาก LINE บน Android: ปุ่ม "เปิดในเบราว์เซอร์" (LINE เปิดเบราว์เซอร์หลักของเครื่อง อาจไม่ใช่ Chrome) · จับ TikTok / WeChat เป็นแอปแชตด้วย
- ม็อคอัพ: ชี้ช่อง "ขนาดริม" ได้

## แก้ฟอร์มใบยืนยัน
- ใบแก้ของใบงานบริการล็อกช่องที่กำหนดขั้นตอนผลิต (ส่งกระดาษ/รีดลงผ้า · ผู้จัดหาฟิล์ม · หน่วย UV DTF) พร้อมบอกเหตุผล
- UV DTF ไม่พิมพ์เงื่อนไข "ของที่ลูกค้าส่งมา" (โรงงานผลิตเอง)
- ป้ายผ้า: ถามความกว้างพับริมครั้งเดียว (เดิมถามซ้ำ 2 ช่อง) · บังคับกรอก · ลูกค้าเห็น
- ส่งออก PDF ฉบับโรงงานแล้วรูปลายเซ็นหมดอายุ (เปิดใบนานเกิน 1 ชม.) → เตือนก่อน
- หารูปตัวอย่างตัวเลือกแบบไม่ชน `constructor` / `toString`
- **จัดหน้าภาพม็อคอัพใน PDF อัตโนมัติ** (เจ้าของเจอผ้าเช็ดหน้าหลายลาย ภาพใหญ่ไม่สวย): เดิมทุกภาพสูง 95 มม. 2 คอลัมน์ → 3 ลาย = 3 หน้า, 6 ลาย = 4 หน้า, แถวสุดท้ายว่างครึ่ง · ใหม่วัดพื้นที่ที่เหลือจริงหลังวาดใบ แล้วเลือก 1–4 คอลัมน์ ทุกภาพสูงเท่ากัน จัดกลาง แถวเต็มก่อน (4 ลาย = 2×2) · ไม่พอที่ใต้ภาพที่มีจุดกำกับ → ขึ้นหน้าใหม่พร้อมข้อตกลงและช่องเซ็น · ผลจริง (PDF ในเครื่อง): 1–4 ลาย = 2 หน้า · 6 ลาย + จุดกำกับ = 3 หน้า · 9 ลาย = 3 หน้า
