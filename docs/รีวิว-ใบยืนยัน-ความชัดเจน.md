ตรวจทุกช่องของ 38 สินค้า (322 ช่องไม่ซ้ำ) จาก `production-confirmation.html` · 24 พ.ย. 2569

**หลักการแก้**
- **ไม่เปลี่ยนข้อความตัวเลือกเดิม** (ค่าถูกเก็บในใบเก่าและงานที่รับแล้ว ถ้าเปลี่ยน ใบเก่าจะเปิดแล้วตัวเลือกหาย) → **เพิ่มคำอธิบายตัวเล็กใต้ตัวเลือก** แทน · คำอธิบายแสดงในฟอร์มอย่างเดียว ไม่พิมพ์ใน PDF

## 2. จุดที่ผิด / ไม่สอดคล้อง (แก้ได้เลย)

1. **"ลูกค้าส่งผ้ามาเอง (ตัด/เย็บอย่างเดียว)" อยู่ในสินค้าที่ไม่ใช่ผ้า**: เหรียญ · โล่ · ของพรีเมียม (แก้ว ร่ม Power bank) → เอาออกจาก 3 สินค้านี้
2. **หมวก: "ปีกตรง (Snapback)"** Snapback คือตัวปรับด้านหลัง ไม่ใช่ปีก → แก้คำอธิบายเป็น "ปีกตรง แบน" และให้ Snapback อยู่ที่ "ตัวปรับด้านหลัง: สแน็ปพลาสติก" (ไม่เปลี่ยนค่าเดิม เพิ่มคำอธิบายกันสับสน)
3. **ผ้าพันคอ / ผ้าเช็ดหน้า มี 2 ช่องที่พูดเรื่องเก็บขอบซ้ำกัน**: "รูปแบบการเย็บ (ม้วนริม 0.6/0.3 มม.)" กับ "การเก็บขอบ (โพ้งริม / พับริม / ตัดลุ่ย / ตัดเลเซอร์)" → ❓ ยืนยันว่าเลือกทั้งสองช่องจริงไหม ถ้าไม่ จะรวมเป็นช่องเดียว
4. **ชื่อผ้าเขียนไม่ตรงกันระหว่างสินค้า**: "ผ้า TC" กับ "TC (คอตตอน/โพลี)" · "TK" กับ "TK (โพลี 65 / ฝ้าย 35)" · "คอตตอน" กับ "ผ้าคอตตอน" กับ "คอตตอน 100%" → เพิ่มคำอธิบายเดียวกันทุกที่ (ไม่เปลี่ยนค่า)
5. **ชื่อช่องเดียวกันแต่เรียกต่างกัน**: "ชนิดผ้า" / "ผ้า" / "วัสดุ" · "ขนาด" / "ขนาดสำเร็จ" · "หมายเหตุการแพ็ค" / "หมายเหตุการแพ็ค / จัดส่ง" → ใช้ชื่อเดียวกัน
6. **ปลายแขน** เสื้อยืดใช้ "ลาแขนปกติ / จั๊มปลายแขน (ริบ)" แต่โปโลใช้ "ปลายแขนจั๊ม (ริบ) / ปลายแขนพับ" → เพิ่มคำอธิบายให้รู้ว่าหมายถึงอย่างเดียวกัน (ถ้ายืนยันข้อ 1)

## 3. ลำดับช่อง (ให้แอดมินกรอกไหลจากบนลงล่าง)

- ลำดับหัวข้อเดิมดีแล้ว: ผ้า → แบบ → ไซซ์/จำนวน → ลาย → การเย็บ → ป้าย → แพ็ค
- **ในหัวข้อ "แบบ" ของเสื้อ เรียงเหมือนกันทุกสินค้า**: แบบ/คอ → ผ้าขอบคอ → สีคอ → แขน → ปลายแขน → ทรง → กระเป๋า (ตอนนี้เสื้อยืดเริ่มที่ "ทรง" แต่เจอร์ซีย์เริ่มที่ "แขน" สลับกัน)
- ช่องที่ขึ้นกับอีกช่อง (เช่น สีคอ, สีสาบ, สีกุ๊น) อยู่ติดใต้ช่องแม่เสมอ (ส่วนใหญ่ถูกแล้ว)

## 4. ทำแล้วรอบนี้

- คำอธิบายตัวเล็กใต้ตัวเลือก 65 คำ (เฉพาะ ✅) · ไม่พิมพ์ใน PDF · ทดสอบว่าทุกคำตรงกับตัวเลือกจริง
- "ผ้าคอ" → **ผ้าขอบคอ** + "แถบผ้ารอบคอเสื้อ (ไม่ใช่ปก)" · "สีคอ" → **สีขอบคอ** (ฟอร์ม + หน้าม็อคอัพในระบบ + คำแปลพม่า)
- คำอธิบายช่อง: หน้าผ้า · สาบเสื้อ · รางสอด · ตาไก่ · กระหม่อม
- หัวข้อ 2 ข้อ 1 (เอา "ลูกค้าส่งผ้ามาเอง" ออกจาก โล่ · ของพรีเมียม · กระเป๋าสาน · เหรียญไม่มีอยู่แล้ว) · ข้อ 2 (คำอธิบาย Snapback) · ข้อ 4 (คำอธิบายผ้าเดียวกัน) · ข้อ 5 (หมายเหตุการแพ็ค)
- ลำดับช่อง "แบบ" ของเสื้อยืด · เสื้อกีฬา · เจอร์ซีย์ · โปโล · ชุดนักเรียน · เสื้อไว้ทุกข์: แบบ/คอ → ขอบคอ → แขน → ปลายแขน → ทรง

## 5. บั๊กที่พบและแก้แล้ว (ผู้ตรวจอิสระ · ทุกข้อมีทดสอบ)

1. ขนาดสำเร็จที่กรอกเอง (ตารางขนาด) **ไม่ถูกส่งเข้าระบบเลย** · PDF มี แต่งานในระบบไม่มี
2. เอาติ๊กชุดไซซ์ออก จำนวนของชุดนั้นยังถูกส่ง → ระบบแสดงแบบ/จำนวนเกิน
3. จำนวนติดลบบันทึกเข้าระบบได้ (ตรวจเฉพาะตอนแก้ใบ)
4. เปลี่ยนเป็นไม่ขึ้นตัวอย่าง วันนัดส่งตัวอย่างที่ซ่อนอยู่ยังบล็อกการส่งออก PDF และยังพิมพ์
5. เปลี่ยนเป็นไม่มีลาย "ตำแหน่งข้อความรายตัว" ยังพิมพ์และส่ง
6. จุดกำกับบนม็อคอัพอ้างช่องที่ถูกซ่อนได้ · "อื่นๆ" ใน PDF กับในระบบแสดงไม่ตรงกัน
7. บันทึกไฟล์ใบแก้แล้วเปิดใหม่ หลุดโหมดแก้ใบ → ระบบปฏิเสธพร้อมข้อความที่ชี้ผิดทาง
8. เลขที่ใบเดิมแต่คนละสินค้า **ทับใบเดิมเงียบ ๆ** → ตอนนี้ปฏิเสธและบอกให้ต่อท้ายเลข
9. รูปเยอะจนพื้นที่เบราว์เซอร์เต็ม บันทึกเข้าระบบไม่ได้ → เก็บสำเนาฟอร์มแบบไม่มีรูปแล้วลองใหม่
