# ติดตั้งแอป ภาพพิมพ์ 142 บนมือถือ / แท็บเล็ต

แอปนี้ไม่ต้องโหลดจาก Play Store หรือ App Store · ติดตั้งจากหน้าเว็บ **https://pp142.pages.dev** แล้วจะมีไอคอน **PP142 ผลิต** บนหน้าจอเหมือนแอปทั่วไป เปิดมาเต็มจอ ไม่มีแถบที่อยู่เว็บ

ในแอป: กดชื่อตัวเองมุมขวาบน → หน้าบัญชี → การ์ด **ติดตั้งแอปบนเครื่องนี้** จะบอกวิธีตามเครื่องที่ใช้อยู่ (ติดตั้งแล้วการ์ดนี้จะหายไปเอง)

## Android (Samsung, OPPO, Vivo ฯลฯ)

1. เปิด **Chrome** แล้วเข้า `pp142.pages.dev` · เข้าสู่ระบบ
2. กดชื่อตัวเองมุมขวาบน → กดปุ่ม **ติดตั้งแอป** → กด **ติดตั้ง**
3. ถ้าไม่มีปุ่ม (เคยกดยกเลิกไปแล้ว หรือใช้เบราว์เซอร์อื่น): กดเมนู **⋮** มุมขวาบนของ Chrome → **ติดตั้งแอป** (บางเครื่องเขียนว่า **เพิ่มลงในหน้าจอหลัก**) → **ติดตั้ง**
4. ปิด Chrome แล้วเปิดแอปจากไอคอน **PP142 ผลิต** บนหน้าจอหลัก

## iPhone / iPad

ต้องใช้ **Safari** (Chrome บน iPhone ก็ได้ถ้าเป็น iOS 16.4 ขึ้นไป แต่ Safari ง่ายที่สุด)

1. เปิด Safari แล้วเข้า `pp142.pages.dev`
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรชี้ขึ้น ด้านล่างจอ หรือข้างที่อยู่เว็บบน iPad) · ถ้าไม่เห็น ให้กด **⋯** ก่อน
3. เลื่อนลงแล้วกด **เพิ่มไปยังหน้าจอโฮม** (Add to Home Screen)
4. กด **เพิ่ม** มุมขวาบน → เปิดแอปจากไอคอน **PP142 ผลิต**

> iPhone ให้ใช้จากไอคอนเสมอ · ถ้าเปิดผ่าน Safari ธรรมดาแล้วไม่ได้เปิดนานเกิน 7 วัน iPhone จะลบการเข้าสู่ระบบทิ้ง ต้องเข้าใหม่

## หลังติดตั้ง

- **เข้าสู่ระบบครั้งเดียว** เครื่องจำไว้ ปิดแอปแล้วเปิดใหม่ไม่ต้องเข้าใหม่
- **เครื่องที่ใช้ร่วมกัน** (แท็บเล็ตประจำสถานี): กด **ออกจากระบบ** ก่อนส่งเครื่องให้คนต่อไปทุกครั้ง · ทุกการกดในระบบบันทึกชื่อคนที่เข้าสู่ระบบอยู่
- **หน้าจอสถานี / QC จะไม่ดับเอง** ระหว่างเปิดหน้าคิวงานอยู่ · ออกจากหน้านั้นหรือสลับไปแอปอื่น จอกลับมาดับตามปกติ (มือถือรุ่นเก่ามากอาจไม่รองรับ ให้ตั้งเวลาปิดหน้าจอในเครื่องให้นานขึ้นแทน)
- **อัปเดตเอง** ไม่ต้องติดตั้งใหม่ · มีรุ่นใหม่จะขึ้นแถบ "มีระบบรุ่นใหม่ · กดเพื่อโหลด"
- ต้องต่ออินเทอร์เน็ตตอนใช้งาน (ข้อมูลงานมาจากระบบกลางทุกครั้ง)

## ปัญหาที่เจอบ่อย

| อาการ | ทำอย่างนี้ |
|---|---|
| ไม่มีปุ่มติดตั้ง / ไม่มีเมนูติดตั้งแอป | ใช้ Chrome (Android) หรือ Safari (iPhone) · ถ้าติดตั้งไว้แล้ว ให้เปิดจากไอคอนบนหน้าจอหลัก |
| เปิดแล้วจอขาว หรือขึ้น "เปิดระบบไม่สำเร็จ" | กดปุ่ม **โหลดใหม่** บนจอ · ยังไม่หายให้แจ้งเจ้าของระบบ |
| ภาษาพม่า | กดปุ่มรูปโลก (มุมบน) สลับ ไทย / မြန်မာ ได้ (เฉพาะบัญชีพนักงานสถานีและ QC) |
| ลบแอป | กดค้างที่ไอคอน → ลบ / ถอนการติดตั้ง · ไม่กระทบข้อมูลงานในระบบ |
