### 1.2 ทำงานคนละโฟลเดอร์ (git worktree) · ห้ามสลับ branch ในโฟลเดอร์หลัก
AI หลายตัวในโฟลเดอร์เดียวกันสลับ branch ทับกันได้ (ไฟล์ของอีกคนหายจากจอ) จึงใช้ 1 worktree ต่อ 1 งาน ทุกโฟลเดอร์อยู่ข้างโฟลเดอร์หลัก:

```bash
git worktree add ../pp142-c2 -b codex/c2-settings main
```

| โฟลเดอร์ | branch | ใคร |
|---|---|---|
| `Phappim-Process` (โฟลเดอร์หลัก) | `main` และ branch ของ Claude | Claude เท่านั้น |
| `pp142-c1`, `pp142-c2`, `pp142-c4`, `pp142-c5` | `codex/c1-…` `codex/c2-…` `codex/c4-…` `codex/c5-…` | Codex |
| `pp142-c3`, `pp142-g1`, `pp142-g3` | `antigravity/c3-…` `antigravity/g1-…` `antigravity/g3-…` | Antigravity |

- Claude (หรือเจ้าของโปรเจกต์) สร้าง worktree ให้ก่อนเริ่มแต่ละงาน และ `git worktree remove` หลัง merge
- **แตก branch จาก `main` ในเครื่องหลังงาน A3–A5 merge แล้วเท่านั้น** (ข้อ 3) ไม่อย่างนั้นจะไม่เห็นชั้นข้อมูลจริงและหน้ารับงาน
- ติดตั้งแพ็กเกจในแต่ละ worktree เอง (`npm ci` ใน `app/` และ `supabase/tests/`) · ห้ามใช้ `node_modules` ร่วมโฟลเดอร์

### 1.3 ส่งงาน (แทนการเปิด PR)
