## ของใหม่ที่ต้องทดสอบ (PR 175 · ใบยืนยัน)
1. **แก้ใบหลังรับงาน:** รายละเอียดงาน (แอดมิน/เจ้าของ) → "ลูกค้าขอแก้ใบยืนยัน" → "เปิดใบยืนยันในฟอร์ม" → ฟอร์มเปิดข้อมูลจากงาน (รูปม็อคอัพจากระบบ · จุดชี้) → แก้ที่อยู่จัดส่ง + "แก้ไขครั้งที่" → ส่งออก PDF → กลับมาแนบ "เปลี่ยนเป็น PDF ใบใหม่" → ประวัติงานขึ้น "เปลี่ยน PDF ใบยืนยัน" · ข้อมูลสเปกงานในระบบไม่เปลี่ยน
   - งานที่ไม่ได้รับผ่านฟอร์ม → ขึ้นข้อความบอกเหตุผล · กด "บันทึกเข้าระบบ" ในฟอร์มที่เปิดจากงาน → ระบบปฏิเสธ (ใบนี้ส่งงานแล้ว) ไม่สร้างใบร่างซ้ำ / ไม่สร้างงานซ้ำ
   - บทบาทอื่น (ฝ่ายผลิต · QC · staff · ผู้บริหาร) ไม่เห็นปุ่มนี้ และเรียก `attach_confirmation_pdf` ตรงๆ ไม่ได้ · งานที่ยกเลิกแล้วเปลี่ยน PDF ไม่ได้
   - เปลี่ยน PDF ซ้ำหลายครั้ง · ไฟล์ผิดชนิด / ใหญ่เกิน · ลิงก์เปิด PDF ได้ไฟล์ล่าสุด
2. **ตารางกระเป๋า:** คอลัมน์ "กุ๊น" + ติ๊ก "มาตรฐาน" ที่ขนาด · ทุกสินค้าที่มีตารางกระเป๋า/ช่องใส่ของ · ติ๊กแล้วเอาออก · PDF แสดงถูก ("ไม่มีกุ๊น" ไม่พิมพ์)
3. **ขนาดที่ลูกค้ากำหนด:** กางเกงช้าง / มวยไทย = รอบเอว รอบสะโพก ความยาวขา · ชุดนอน / สครับ = เสื้อ + กางเกง · สินค้าอื่น = รอบอกบังคับเหมือนเดิม · เลือกตารางของลูกค้า/กำหนดเอง → ขนาด FS/PS ของโรงงานไม่ขึ้นทั้งฟอร์มและ PDF
4. **ถุงพับได้:** หัวข้อ "หูหิ้ว / สาย" + กุ๊นขอบหลายจุด + สีกุ๊น · ถุงผ้า: กุ๊นขอบ + "หูผ้ากุ๊นขอบ" · กุ๊นขอบขึ้นแม้เลือก "เย็บตามมาตรฐานโรงงาน"
5. **ใบเก่า:** เปิดไฟล์ JSON / ใบร่างที่บันทึกก่อน PR 175 (ตารางขนาดมี `chest` `length` `sleeve` · กระเป๋าไม่มี `piping`) → ข้อมูลไม่หาย ส่งออกได้ · บอกในรายงานถ้าค่าเก่าหายจากจอ/PDF

## ส่วน 0 — ทดสอบอัตโนมัติทั้งหมด (ใส่ตัวเลขในรายงาน)
1. `cd app && npm ci && npm run lint && npm test && npm run build` (build นี้ตรวจ typecheck อย่างเดียว)
2. `cd supabase/tests && npm ci && npm test` (ทุกชุด รวม live-check จำลอง)
3. `node --test tools/qa-r14/server.test.mjs` · ทดสอบ `workers/files` ถ้ารันได้
4. ชุดจำลองเดิม `tools/qa-r14/qa-part-{a,b,c}.mjs` + `tools/qa-r15/` → แยกข้อที่ไม่ผ่านว่าเป็นบั๊กจริงหรือสคริปต์ไม่ตรงหน้าจอใหม่
5. `node tools/qa-r14/confirmation-all.mjs <โฟลเดอร์นอก repo>` ครบ **38 สินค้า** × ขั้นต่ำ / เต็ม (เติมช่องใหม่ข้อ 2–4 ด้วย) · ไม่มี `undefined` `NaN` `null` `[object` ใน PDF · เงื่อนไข + ช่องเซ็นอยู่หน้าเดียวกัน · จำนวนหน้าเทียบรอบ 15

## ส่วน B — ทดสอบซ้ำทั้งระบบ
1. งานเดียวเดินครบ **9 เส้นทาง** ถึงจัดส่ง ด้วยบัญชีที่จะกดจริง · บอร์ด ภาพรวม คิว กล่องจดหมาย ประวัติ ตรงกันหลังแต่ละขั้น
2. **ตารางสิทธิ์ทุก RPC × ทุกบัญชีจำลอง** (แบบรอบ 13) บนรุ่นปัจจุบัน · ต่างจากรอบ 13 ตรงไหนให้ระบุ
3. ยกเลิกงานทุกสถานะ · งานข้างนอก · ม็อคอัพกำกับสเปก (ร่าง → อนุมัติ → ฉบับห้ามแก้) · จักรเย็บ · เครื่องเต็ม · จัดส่ง/ยกเลิกจัดส่ง
4. ภาษาพม่า: สคริปต์สแกนทุกจอ staff/QC ที่ 375 / 768 px หาไทยที่ไม่มีคำพม่าคู่ · error จากฐานข้อมูลทุกแบบที่ทำได้จากจอ → จดข้อความเต็มที่ยังไทยล้วน
5. ลองทำผิดในช่องใหม่ทั้งหมด: ติดลบ / ทศนิยม / ข้อความยาวมาก / อีโมจิ / `<script>` / วางจาก Excel
