# แผน: ใบยืนยันการผลิตแบบเฉพาะขั้น (เย็บอย่างเดียว · พิมพ์อย่างเดียว · รีดอย่างเดียว · DTF อย่างเดียว)

**เจ้าของขอ (26 พ.ย.):** "เรายังขาดใบยืนยันการผลิตแบบเฉพาะ เช่น เย็บอย่างเดียว พิมพ์อย่างเดียว รีดอย่างเดียว DTF อย่างเดียว · ให้ง่ายต่อการทำงานของแอดมิน และเข้าใจตรงกันกับฝ่ายผลิต"
**สถานะ:** ทำแล้ว (branch `claude/service-forms` · migration `20261207000000_service_routes`) · รายละเอียดที่ทำ [`handoff/claude-service-forms.md`](handoff/claude-service-forms.md)

## 1. ตอนนี้ระบบมีอะไร
- ฟอร์มมีสินค้า **"งานบริการ (ลูกค้าส่งวัสดุ / ชิ้นงานมาเอง)"** อยู่ 1 แบบรวม: ติ๊กบริการจากรายการ 10 อย่าง + ช่องข้อความอิสระ · ไม่มีช่องเฉพาะของแต่ละงาน (เช่น เย็บไม่มีตารางไซซ์/ด้าย · DTF ไม่มีตำแหน่งลายต่อชิ้น)
- **เส้นทางผลิตมี 9 แบบ** แต่ไม่มีเส้นทางที่ผ่านสถานีเดียว ยกเว้น "ตัดงานลูกค้า" (ตัด → QC) · งานบริการตอนนี้แอดมินต้องเลือกเส้นทางที่ใกล้เคียง ทำให้งานไปค้างสถานีที่ไม่ต้องทำ (เช่น งานเย็บอย่างเดียวต้องผ่านสถานีตัด)
- **สถานีเย็บต้องรู้ชนิดสินค้า** (สูตรจักรต่อสินค้า) · งานบริการไม่มีสูตรจักร → เย็บในโรงงานไม่ได้
- ข้อดีที่มีแล้ว: **ขั้นรอผลิต** (PR 231) เหมาะกับงานบริการมาก = แอดมินเช็คของที่ลูกค้าส่งมาครบ + ถ่ายรูปสภาพของก่อนรับเข้าไลน์ (หลักฐานถ้าของลูกค้ามีตำหนิมาก่อน)

## 2. ข้อเสนอ: แยกเป็น 4 ใบในหมวดใหม่ "งานบริการ (ลูกค้าส่งของมา)"
แอดมินเลือกใบตามงาน → แต่ละใบถามเฉพาะสิ่งที่งานนั้นต้องรู้ → เส้นทางผลิตตั้งให้อัตโนมัติ (ไม่ต้องเดา) → ฝ่ายผลิตเห็นชื่อบริการชัดบนการ์ดงาน

| ใบ | เส้นทางใหม่ (สถานี) | ลูกค้าส่งอะไรมา | ได้อะไรกลับ |
|---|---|---|---|
| **เย็บอย่างเดียว** | เย็บ → QC + Packing | ชิ้นส่วนที่ตัดแล้ว (+ ด้าย / ป้าย ถ้ามี) | ตัวสำเร็จ |
| **พิมพ์อย่างเดียว** | เลือกในใบ: **ส่งกระดาษ** = พิมพ์ → QC + Packing · **รีดลงผ้าลูกค้า** = พิมพ์ → รีด → QC + Packing | ไฟล์งาน (+ กระดาษ ถ้าลูกค้ามี · + ผ้า ถ้ารีดลงผ้า) | กระดาษพิมพ์แล้ว (ลูกค้ารีดเอง) หรือ ผ้าที่มีลายแล้ว |
| **รีดอย่างเดียว** | รีด → QC + Packing | กระดาษที่พิมพ์แล้ว + ผ้า / ชิ้นงาน | ผ้า / ชิ้นงานที่รีดลายแล้ว |
| **DTF อย่างเดียว** | รีดฟิล์ม → QC + Packing | เสื้อ / ชิ้นงาน (+ ฟิล์ม ถ้าลูกค้ามี) | ชิ้นงานที่รีด DTF แล้ว |

- ใบ "งานบริการ" แบบรวมเดิม **เก็บไว้** สำหรับงานอื่น (ตัดเลเซอร์ · เฟล็ก · ติดกระดุม ฯลฯ) · ใบเก่าที่บันทึกไว้เปิดได้เหมือนเดิม
- ตัดอย่างเดียว มีเส้นทาง "ตัดงานลูกค้า" อยู่แล้ว → ทำเป็นใบที่ 5 ได้ในรอบเดียวกัน (ถ้าเจ้าของต้องการ)

## 3. ช่องในแต่ละใบ
**ทุกใบมีเหมือนกัน:** ข้อมูลลูกค้า/ผู้ประสานงาน/การจัดส่ง (เหมือนใบปัจจุบัน) · **ของที่ลูกค้าส่งมา** (ชนิด · จำนวนที่ส่งมา · วันที่ส่งของ · ใครส่ง: ลูกค้าส่งมาเอง / ให้โรงงานไปรับ) · **ของเผื่อเสีย** (ลูกค้าส่งเผื่อมากี่ชิ้น) · **ส่งคืนแบบไหน** (ส่งคืนตามที่รับมา / พับใส่ถุง / ม้วน) · ไฟล์งาน + ภาพ (บังคับ 1 ภาพ = ม็อคอัพ หรือรูปชิ้นงานตัวอย่าง) · หมายเหตุถึงฝ่ายผลิต

| ใบ | ช่องเฉพาะ |
|---|---|
| เย็บอย่างเดียว | **สินค้าที่จะเย็บ** (เลือกจากรายการเสื้อผ้าเดิม → ใช้สูตรจักรของสินค้านั้น) · ตารางไซซ์ × จำนวนชุดชิ้นส่วน · ด้าย (ลูกค้าส่ง / โรงงานใช้ · สี) · วิธีเย็บ (มาตรฐานโรงงาน / ลูกค้ากำหนด = ใช้หัวข้อการเย็บเดิม) · ป้าย (ลูกค้าส่ง · ตำแหน่ง) · งานเสริม (ติดกระดุม ฯลฯ) |
| พิมพ์อย่างเดียว | **ได้อะไรกลับ** (ส่งกระดาษ / รีดลงผ้าลูกค้า → กำหนดเส้นทาง) · ถ้ารีดลงผ้า: ชนิดผ้า + จำนวนหลา · ชนิดงานพิมพ์ (ซับลิเมชั่นลงกระดาษ ฯลฯ) · ขนาดงาน (กว้าง × ยาว) · จำนวน (แผ่น / หลา ของกระดาษ) · สีเทียบ (ใช้ช่องเทียบสีเดิม) · กระดาษของใคร · พิมพ์กลับด้าน (mirror) หรือไม่ |
| รีดอย่างเดียว | ของที่จะรีดลง (ผ้าหลา / ชิ้นงาน · ชนิดผ้า) · จำนวน (หลา / ชิ้น) · ตำแหน่ง + ขนาดลายต่อชิ้น · อุณหภูมิ / เวลา (ถ้าลูกค้ากำหนด · ไม่กรอก = มาตรฐานโรงงาน) |
| DTF อย่างเดียว | ชิ้นงานลูกค้า (ชนิด · สี) + ตารางไซซ์ × จำนวน · ตำแหน่ง + ขนาดลายแต่ละจุด (ใช้ตัวช่วยวางลายเดิม) · ฟิล์ม: โรงงานสั่ง / ลูกค้าส่งมาเอง |

**ฉบับลูกค้า (PDF ที่ลูกค้าเซ็น):** แสดง บริการ · ของที่ลูกค้าส่งมา + จำนวน · จำนวนที่จะทำ · การส่งคืน · ม็อคอัพ · เงื่อนไข · ช่องเซ็น · **เพิ่มเงื่อนไขของงานบริการ 1 ข้อ** (ร่าง: "ของที่ลูกค้าส่งมาเสียหายระหว่างผลิต โรงงานรับผิดชอบไม่เกินค่าบริการของชิ้นนั้น · ควรส่งเผื่อเสีย 3–5%" — เจ้าของแก้ถ้อยคำ)

## 4. งานเดินในระบบอย่างไร
1. แอดมินกรอกใบบริการ → บันทึกเข้าระบบ → รับงาน: **เส้นทางผลิตตั้งตามใบให้เอง** (เปลี่ยนไม่ได้ · ถ้าผิดให้แก้ที่ใบ) · ไม่ขึ้นตัวอย่างเป็นค่าตั้งต้น
2. **รอผลิต:** ระบบใส่รายการวัตถุดิบตั้งต้นจากช่อง "ของที่ลูกค้าส่งมา" ให้ (แอดมินแก้/เพิ่มได้) → แอดมินนับของจริง ติ๊ก ถ่ายรูปสภาพของ → ปล่อยเข้าไลน์ (ของยังไม่มา = งานค้างที่รอผลิต ไม่ไปรอที่สถานี)
3. สถานีเดียวที่ต้องทำ → QC + Packing นับจำนวนที่ทำเสร็จเทียบจำนวนที่รับมา → จัดส่ง / ลูกค้ารับเอง
4. การ์ดงาน + ใบปะงาน + หน้ากำหนดส่งขึ้นชื่อบริการ เช่น **"เย็บอย่างเดียว · เสื้อยืด"** ฝ่ายผลิตเห็นทันทีว่าต้องทำแค่ขั้นไหน
5. DTF อย่างเดียว ที่โรงงานสั่งฟิล์ม ใช้ขั้นสั่ง/รับฟิล์มเดิม (สถานีรีดฟิล์มเริ่มไม่ได้จนได้รับฟิล์ม) · ลูกค้าส่งฟิล์มมาเอง = ไม่ต้องสั่ง (ฟิล์มอยู่ในรายการเช็คของตอนรอผลิตแทน)

| ทดสอบ | ฐานข้อมูล + หน้าเว็บ + เดินงานครบทั้ง 4 แบบในระบบจำลอง (รับ → รอผลิต → สถานีเดียว → QC → จัดส่ง) ที่ 375 / 768 / 1440 px |

## 6. เจ้าของตัดสินแล้ว (26 พ.ย.)
1. **รูปแบบใบ:** แยก 4 ใบ ในหมวดใหม่ "งานบริการ"
2. **พิมพ์อย่างเดียว:** มีทั้งสองแบบ ให้เลือกในใบ · ส่งกระดาษให้ลูกค้า (พิมพ์ → QC) / พิมพ์แล้วรีดลงผ้าของลูกค้า (พิมพ์ → รีด → QC)
3. **ฟิล์ม DTF อย่างเดียว:** เลือกได้ในใบ · โรงงานสั่ง (ใช้ขั้นสั่ง/รับฟิล์มเดิม) / ลูกค้าส่งมาเอง (ไม่ต้องสั่ง · ฟิล์มอยู่ในรายการเช็คของตอนรอผลิต)
4. **เวลาผลิต:** 10 / 15 / 20 วันทำงานเหมือนงานผลิตปกติ (นับจากวันปล่อยเข้าไลน์)

**ข้อที่ใช้ค่าตั้งต้นไปก่อน (เจ้าของแก้ได้ภายหลัง):** ผ้าใช้หน่วย **หลา** (ใบบริการเดิมเขียน "เมตร" → เปลี่ยนเป็นหลา) · บังคับภาพอย่างน้อย 1 ภาพทุกใบ · ไม่ขึ้นตัวอย่างเป็นค่าตั้งต้น (เลือกขึ้นได้) · ถ้อยคำเงื่อนไขความเสียหายในข้อ 3 รอเจ้าของแก้
