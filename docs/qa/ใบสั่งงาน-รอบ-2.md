## ข. เส้นทางใหม่และการเลือกขึ้นตัวอย่าง (รับงานใหม่ 4 งาน)
1. `TEST-G2-DTG` เส้นทาง DTG · ขึ้นตัวอย่าง: แอดมิน "บันทึกสั่งงาน DTG" → ติ๊กวัตถุดิบครบ → ขึ้นตัวอย่าง · เริ่มรีดฟิล์มก่อนรับของต้องถูกปฏิเสธ · "ได้รับงาน DTG แล้ว" แล้วเริ่มได้
2. `TEST-G2-EMB` เส้นทางปัก · ไม่ขึ้นตัวอย่าง: วัตถุดิบครบ → **เข้าผลิตจริงทันที** (ไม่มีขั้นตัวอย่างบนบอร์ดและแถบขั้นตอน) · ตัด → ส่งปัก: กดเสร็จก่อนกรอกจำนวนรับกลับต้องถูกปฏิเสธ · กรอกส่ง / รับกลับ / ตรวจ → ไปเย็บ
3. `TEST-G2-CUT` ตัดงานลูกค้า · ไม่ขึ้นตัวอย่าง: ตัด → QC + Packing → เสร็จ (ไม่ผ่านเย็บ)
4. `TEST-G2-SCR` ซิลค์สกรีน: เปิดหน้ารับงานแล้ว**ไม่เลือก**ขึ้นตัวอย่าง → ปุ่มรับงานต้องบอกว่ายังขาด · แอดมินตั้งวันนัดรับเป็นเมื่อวาน → กล่องจดหมายมี "งานสกรีน เลยกำหนด" (รอได้ถึง 5 นาที)
5. ฟอร์มใบยืนยัน (`production-confirmation.html` เปิดจากไฟล์ในเครื่อง): ช่องขึ้นตัวอย่างบังคับ · เลือก DTG / ปัก / ปัก + ซับ แล้วเส้นทางเปลี่ยนตาม · บันทึกไฟล์ .json แล้วแนบตอนรับงาน → เส้นทางและการเลือกตัวอย่างติดมาครบ

## ค. กล่องจดหมาย
- กระดิ่งขึ้นตัวเลขยังไม่อ่าน (จอเล็กแถบบน · จอใหญ่เมนูซ้าย)
- พักงาน / QC ส่งกลับแก้ / ตัวอย่างไม่ผ่าน → ข้อความขึ้นภายในไม่กี่วินาที โดยไม่รีเฟรช
- ผู้รับถูกต้อง: QC เห็น "งานส่งแก้" แต่ไม่เห็น "จักรเสีย" · ผู้บริหารเห็น "งานติดปัญหา"
- กดข้อความ → เปิดรายละเอียดงานนั้นทันที · "อ่านแล้วทั้งหมด" ใช้ได้ · บัญชีอื่นยังเห็นว่ายังไม่อ่าน

## ง. รายละเอียดงาน (S8)
- ไทม์ไลน์มีชื่อคนกด + เวลาไทย ตรงกับที่กดจริง
- "แจ้งว่ากดผิด" มีเฉพาะฝ่ายผลิต · ต้องกรอกเหตุผล · รายการเดิมถูกขีดฆ่าพร้อมเหตุผล ไม่หายไป · แอดมิน / QC / ผู้บริหาร ไม่มีปุ่มนี้
- ลิงก์ `https://pp142.pages.dev/#/board?job=<id>` (คัดลอก id จาก URL หลังกดข้อความในกล่องจดหมาย) เปิดแผงงานเองทันที · ปิดแผงแล้วรีเฟรชไม่เปิดซ้ำ
- **ยังไม่ต้องตรวจ** "เวลาที่ใช้ต่อสถานี" (Codex กำลังแก้ใน C6 · ตรวจหลัง Claude แจ้ง)
