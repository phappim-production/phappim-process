# วันที่ พ.ศ. / ค.ศ. ไม่ปนกัน (ตรวจหลังเปิดเวลาผลิต)

เจ้าของสั่ง 25 พ.ย.: ตรวจหาบั๊ก โดยเฉพาะวันที่อย่าสับสน พ.ศ. กับ ค.ศ.

## เจออะไร
1. กล่องจดหมาย "ครบกำหนดส่ง" และ "ฟิล์มเลยกำหนด" แสดงปี ค.ศ. (`27/11/2026`) ขณะที่ข้อความอื่นแสดง พ.ศ. (`27/11/2569`)
2. ช่องวันที่ของเบราว์เซอร์เก็บปี ค.ศ. ถ้าพิมพ์ปี พ.ศ. (2569) ลงไป ระบบรับเป็นปี ค.ศ. 2569 ได้ทุกช่อง (กำหนดส่ง ฟิล์ม รายงานล่าช้า ยืนยันตัวอย่าง ซ่อมจักร จองจักร ส่งข้างนอก) · หน้ารับงานแค่ถาม "ยืนยัน?" แล้วยังส่งได้ · ฟอร์มใบยืนยันพิมพ์ PDF เป็นปี 3112 ได้
3. หน้ารับงานถามยืนยันด้วยวันที่ดิบ `2026-11-30` · ข้อความหลังบันทึกสั่งฟิล์มก็แสดงวันที่ดิบ
4. หน้าวางแผนรับ ใส่วันที่ลูกค้าต้องการเป็นปี พ.ศ. แล้วขึ้น "ทันวันที่ลูกค้าต้องการ" ผิด

ข้อมูลจริงในฐาน (25 พ.ย.) ยังไม่มีวันที่ปีผิด
