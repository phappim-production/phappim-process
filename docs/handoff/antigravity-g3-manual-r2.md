# ส่งงาน G3 รอบ 2 (`antigravity/g3-manual-r2`)

## แก้หัวข้อไหนบ้าง
อัปเดตคู่มือทั้ง 5 บทบาทและแผนอบรมใน `docs/คู่มือ/` ตาม [`docs/codex/G3-รอบ-2.md`](../codex/G3-รอบ-2.md) และ Flow ล่าสุดหลัง PR 30–33:

1. **[`ฝ่ายผลิต.md`](../คู่มือ/ฝ่ายผลิต.md)**:
   - ลบหัวข้อ **รับงานใหม่** (ย้ายไปคู่มือแอดมิน) และลบหัวข้อ **ติ๊กวัตถุดิบ** / **ติ๊กขั้นย่อย**
   - อัปเดต **หน้าหลัก**: อธิบายปุ่มสถานีขนาดใหญ่ 3 กลุ่ม (**ก่อนผลิต / เฟส 1 / เฟส 2**) และเครื่องจำสถานีที่เลือกไว้
   - อัปเดต **เดินสถานี**: ทุกสถานีเหลือแค่ **เริ่ม** → **เสร็จ** + **พักงาน / ติดปัญหา** (ไม่มีเช็คลิสต์ขั้นย่อย) · คงเงื่อนไข **รีดฟิล์ม** (รอแอดมินกดรับก่อน) และ **ส่งปัก (ร้านนอก)**
   - เพิ่มหัวข้อ **ใบปะงาน + QR** (พิมพ์ A5 ติดกองงาน · ช่องวันที่/ผู้รับ/ลายเซ็นใช้คู่กระดาษ · สแกน QR เปิดงาน)
   - เพิ่มหัวข้อ **มีระบบรุ่นใหม่** (ปัดรีเฟรช / ปิดเปิดแอป / กดโหลดแถบ `มีระบบรุ่นใหม่`)
2. **[`แอดมิน.md`](../คู่มือ/แอดมิน.md)**:
   - เพิ่ม/ย้ายหัวข้อ **รับงานใหม่** (สิทธิ์เฉพาะแอดมินและเจ้าของระบบ · ขั้นตอนกด `บันทึกไฟล์` `.json` จากฟอร์มใบยืนยันรุ่นใหม่ + แนบ PDF + ตรวจเส้นทาง/จำนวน/ขึ้นตัวอย่าง · ไม่มีขั้น `"รอวัตถุดิบ"` ส่งเข้าแล้วขึ้นสถานีแรกทันที) และลบหัวข้อติ๊กวัตถุดิบ
   - เพิ่มหัวข้อ **พิมพ์ใบปะงาน + QR** และ **มีระบบรุ่นใหม่**
3. **[`QC.md`](../คู่มือ/QC.md)**:
   - ลบหัวข้อติ๊กวัตถุดิบและเช็คลิสต์ขั้นย่อย
   - อัปเดต **เดินสถานี QC + Packing** (ต้องบันทึกยอดผ่านครบตามจำนวนสั่งจึงจะกดเสร็จได้ · ชิ้นไม่ผ่านส่ง **งานแก้** กลับเย็บ) และเพิ่ม **มีระบบรุ่นใหม่**
4. **[`ผู้บริหาร.md`](../คู่มือ/ผู้บริหาร.md)**:
   - ขยายหัวข้อ **ดูหน้ารายงาน** (เวลาเฉลี่ยต่อสถานี, คอขวด, % ทันกำหนด, งานแก้, รายงานปัญหา, คลิกงานเกินกำหนดเปิดรายละเอียด) และเพิ่ม **มีระบบรุ่นใหม่**
5. **[`เจ้าของระบบ.md`](../คู่มือ/เจ้าของระบบ.md)**:
   - ขยายหัวข้อ **ดูหน้ารายงาน** และอัปเดตหัวข้อ **หน้าตั้งค่า** อธิบายครบทั้ง 7 แท็บ (`ผู้ใช้และบทบาท`, `สถานีและขั้นย่อย`, `เวลามาตรฐานของช่วง`, `แม่แบบวัตถุดิบ`, `รหัสสาเหตุ`, `จักรเย็บ`, `การแจ้งเตือน`) โดยคง `[รอภาพ]` ไว้ตามคำสั่งงาน
   - เพิ่ม **มีระบบรุ่นใหม่**
6. **[`แผนอบรม.md`](../คู่มือ/แผนอบรม.md)**:
   - เพิ่ม **ลำดับวันทดลองจริง (วันเสาร์ที่ 21 พ.ย. 2569)** (15 นาทีแรกสอนล็อกอิน/ออกจากระบบ/กล่องจดหมาย/มีระบบรุ่นใหม่ · ฝึกด้วยงาน `TEST-` · ใช้กระดาษคู่กับใบปะงานตลอดวัน)
   - ปรับเนื้อหาอบรมรายบทบาทให้ตรงกับ Flow ล่าสุด
