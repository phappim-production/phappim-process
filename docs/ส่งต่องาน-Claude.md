- ลงฐานข้อมูล**ก่อน merge** เสมอ (Cloudflare deploy ทันทีที่ merge · หน้าเว็บใหม่อ่านตาราง/ฟังก์ชันใหม่ ไม่มีจะโหลดไม่ขึ้น)

## Flow จริงในโรงงาน (ระบบทำตามนี้แล้ว)
1. แอดมินกรอก `/confirmation` → บันทึกเข้าระบบ → **รับงานใหม่** (PDF ที่ลูกค้าเซ็นไม่บังคับ แนบทีหลัง) → งานต่อท้ายคิว
2. ทุกหน้าเรียง**ตามคิว** ไม่ใช่กำหนดส่ง · งานด่วน = แทรกคิว (production / manager / owner · ต้องมีเหตุผล) · เริ่มงานที่ไม่ใช่คิวแรกได้แต่ต้องมีเหตุผล
3. คนหน้างานใช้**มือถือส่วนตัว**: หน้างาน → บอร์ด → เลือกสถานี (จำไว้) → หน้าคิวสถานี
4. แอดมินส่งออกได้ทุกสถานี พิมพ์/รีด/ตัด/เย็บ/ปัก ที่งานยังไม่เริ่ม · ส่งต่อบริษัทถัดไป · รับกลับ → สถานีถัดไป (งานแก้ → QC) · ระหว่างอยู่ข้างนอก trigger กันปุ่มของโรงงาน
5. ยังบังคับเดิม: รีดฟิล์มรอได้รับฟิล์ม · QC ผ่านครบจำนวน · เกินเวลามาตรฐานต้องรายงาน · ข้ามสถานีไม่ได้

## งานถัดไป (เรียงตามความสำคัญ)
1. **รอเจ้าของตัดสิน · นับเวลามาตรฐาน:** `private.work_days` นับ 1 วัน = 24 ชม. (จันทร์–เสาร์ รวมกลางคืน) ไม่ใช่ 08:00–18:00 · ถ้าจะเปลี่ยน ต้องแก้ฐานข้อมูล + ตั้ง `sla_days` ทุกสถานี/ช่วงใหม่ · แนะนำหลังเปิดใช้
2. **ปิดปัญหา:** QC พักงานที่ QC + Packing แล้ว QC กดทำต่อเองไม่ได้ ต้องให้ฝ่ายผลิต/ผู้บริหารกด (ตั้งใจ · PR 67) · งานเย็บที่พักยังเป็นของฝ่ายผลิต (`resume_sewing` จ่ายจักร)
3. **ก่อนอบรม ส. 21:** ข้อความคู่มือแก้แล้ว (PR 64) · ภาพหน้าจอใหม่ `img/r5-*.jpg` (คิวสถานี · ส่งออก · หน้าบัญชี · การ์ดภาพรวม) ใส่แล้ว (PR 66) · ยังไม่มีภาพการ์ด "งานที่ส่งออกข้างนอก" / กล่อง "อยู่ที่บริษัทภายนอก" (ตอนถ่ายไม่มีงานสถานะ `out`) · ภาพเก่าบางภาพ (บอร์ด · ต้องทำตอนนี้) ยังเป็นหน้าจอก่อนคิว · ผังระบบ artifact ยังไม่อัปเดต
4. **วันทดลอง ส. 21:** ทุกเครื่อง**ปิดแท็บทั้งหมดแล้วเปิดใหม่** (รีเฟรชเฉยๆ ไม่พอ · ยืนยันใน QA รอบ 4) · บั๊กระดับ 1 แก้ภายในวัน
5. **ก่อนเปิดใช้ อา. 22:** ยกเลิก/ลบงาน `TEST-` ทั้งหมด (รวม `TEST-R4-*` `TEST-R5-*` และงานแบ่ง `-2`) · **รับกลับรอบส่งออกของงานทดสอบก่อน** (trigger กันการยกเลิกงาน `out`) · ใบร่าง `confirmation_drafts` ทดสอบ · ไฟล์ PDF ทดสอบใน Storage · ข้อความกล่องจดหมาย · **อย่าลบบริษัทจริง 28 เจ้า** (ลบเฉพาะที่ AI สร้างตอนทดสอบ) · ปิดบัญชี `@pp142.test` · สร้างบัญชีทีมจริง
6. **CAP จักรต่องาน (ประชุม 18 พ.ย. · ทำหลังเปิดใช้ 22 พ.ย. · รอข้อมูลจากเจ้าของ):**
   - ตอนนี้ประมาณวันเสร็จนับหลายชุดจักร (`linesFor` ใน `proto/capacity.ts`) แต่ `start_sewing` จ่ายจริง 1 ชุด · ยังไม่มีเพิ่มจักรช่วย
   - สูตร: วันเย็บ = setup + จำนวนตัว ÷ (ตัวต่อวันต่อชุด × จำนวนชุด) · **setup = 5 นาที × จำนวนกระบวนการของสินค้า** ต่อชุด (เพิ่มชุดกลางทางก็เสีย setup)
   - **CAP** = จำนวนชุดน้อยสุดที่เสร็จทันวันต้องเย็บเสร็จ (นับย้อนจากกำหนดส่ง) → แสดง ชนิดจักร×ตัว · ช่าง · วันเสร็จ (ตาราง 1…สูงสุดชุด) ตอนรับงาน + รายละเอียดงาน
   - เริ่มเย็บด้วย CAP ชุด = **จักรหลัก** · จักรว่างเพิ่มได้ = **จักรช่วย** (เกิน CAP) · **งานใหม่ต้องใช้จักร → ระบบเสนอจักรช่วยที่ดึงคืนได้ (งานที่เผื่อเวลาเหลือมากสุดก่อน) → หัวหน้ากดยืนยัน** (เจ้าของเลือก 18 พ.ย. · ไม่ดึงอัตโนมัติ · ช่วงแรกบัญชีฝ่ายผลิตทุกบัญชีกดยืนยันได้ · แยกบทบาทหัวหน้าทีหลังเมื่อระบบชัดแล้ว) · จักรหลักไม่ถูกดึง เพราะ CAP คือขั้นต่ำที่ทันนัด · บันทึก event + แจ้งไลน์ที่ถูกดึง · คำนวณวันเสร็จงานเดิมใหม่
   - ใช้ "ตัวต่อวันต่อชุด" แทนนาทีต่อตัว (คนเย็บเร็วไม่เท่ากัน) · หลังเปิดใช้ 2–3 สัปดาห์ คำนวณค่าจริงจาก events เย็บ แสดงคู่ค่าตั้งไว้
   - **เจ้าของเปลี่ยนแนว 18 พ.ย.:** ไม่ผูกจักรกับชนิดสินค้า แต่ผูกกับ**ตัวเลือกที่ลูกค้าสั่ง** (ปก กระดุม ชายเสื้อ ป้าย …) → จักรของงาน = โครงพื้นฐาน + จักรของทุกตัวเลือกในใบยืนยัน · **ช่วงแรกฝ่ายผลิตเลือกจักรต่องานเอง** แล้วค่อยให้ระบบเสนอ · ใบเก็บข้อมูล `docs/ใบเก็บข้อมูล-จักรต่อตัวเลือก.pdf` (สร้างจาก `tools/sew-cap/build.mjs` · **ตารางเดียว ไม่แยกสินค้า**: รวมสเปกจาก 30 สินค้าเหลือ 138 สเปก ตัดสเปกที่ไม่เกี่ยวกับการเย็บ · 9 หน้า · มีใบบันทึกงานจริงที่ฝ่ายผลิตเลือกจักร · **ค่าร่างจักรสีเทา** จาก `tools/sew-cap/draft.mjs` = ความรู้ทั่วไป ไม่ใช่ของโรงงาน ให้หัวหน้าเย็บติ๊กทับ/ขีดฆ่า · ช่องตัวต่อชั่วโมงเว้นว่างให้หน้างานกรอก)
   - รอข้อมูล (เดิม): ต่อสินค้า → จำนวนกระบวนการ · ตัวต่อวันต่อชุด · ชุดสูงสุดต่องาน · ยืนยันสูตรจักร 1 ชุด (`product_machine_needs`) · setup เกิดครั้งเดียวต่อชุดหรือทุกครั้งที่ช่างสลับกระบวนการ
7. **รอเจ้าของ:** ผล `/spec-check` จากแอดมิน (ไฟล์ `.json`) → ตัด/เพิ่มตัวเลือกใน `production-confirmation.html` · เบอร์/ที่อยู่ "เบลสยามโกลเด้น" · Leaked password protection · เวลาเย็บต่อชิ้นสินค้าอื่น (`SEW_MINUTES` ใน `app/src/proto/capacity.ts`)
8. **ทำได้ถ้ามีเวลา:** หน้าแก้ข้อมูลบริษัทภายนอก (ตอนนี้เพิ่มได้จากฟอร์มส่งออกอย่างเดียว) · บทบาท "หัวหน้าฝ่ายผลิต" แยก (ตอนนี้ทุกบัญชีฝ่ายผลิตแทรกคิวได้) · ปุ่มย้อนสถานะงาน · ช่องเซ็น "ผู้ควบคุมงานรับงาน" ใน PDF ใบยืนยัน
