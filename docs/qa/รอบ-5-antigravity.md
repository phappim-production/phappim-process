## 2. บั๊กและข้อสังเกตที่พบ (ไม่พบบั๊กระดับ 1)

### บั๊ก #1: ปุ่ม `"บันทึกเข้าระบบ"` บน `/confirmation` เปิดแท็บซ้ำขึ้นข้อความ Error
- **ระดับ:** 2 (ใบร่างถูกบันทึกสำเร็จจริง แต่อีกแท็บที่เด้งขึ้นมาแสดงกล่องแดง `"ไม่พบใบยืนยันที่ส่งมาจากฟอร์ม"` ทำให้แอดมินตกใจคิดว่าบันทึกไม่ติด)
- **บทบาท / ขนาดจอ:** `admin@pp142.test` / `375x812` (ใน `production-confirmation.html` L1044–1045)
- **ขั้นตอนทำซ้ำ:** กรอกฟอร์มที่ `https://pp142.pages.dev/confirmation` แล้วกด `"บันทึกเข้าระบบ"`
- **ผลที่ได้:** แท็บหนึ่งนำทางไป `/#/board?confirmation=save` และบันทึก `TEST-R5-A` เข้าระบบสำเร็จ แต่มีอีกแท็บเปิดขึ้นมาชนกันและแย่งอ่าน/ลบ `pp142.confirmation.outbox` ไปแล้ว ทำให้แท็บที่สองขึ้น `"ไม่พบใบยืนยันที่ส่งมาจากฟอร์ม ให้กด \"บันทึกเข้าระบบ\" ในฟอร์มอีกครั้ง"`
- **ผลที่ควรเป็น:** ควรเปิด/สลับไปที่แท็บเดียวและบันทึกครั้งเดียวโดยไม่มีแท็บ error ซ้อนขึ้นมา

## 3. ข้อเสนอ "ใช้ยาก / งง" แยกตามบทบาท (สูงสุด 5 ข้อต่อบทบาท · เรียงตามผลกระทบ)

### มุมแอดมิน (`admin`)
1. **ปุ่ม `"บันทึกเข้าระบบ"` บน `/confirmation` เด้ง 2 แท็บแล้วอีกแท็บขึ้นข้อความแดงไม่พบใบ:** แอดมินที่เปิดฟอร์มจากมือถือจะสับสนว่าบันทึกข้อมูลเข้าหรือยัง ต้องปิดแท็บ error เองทุกครั้ง
2. **ฟอร์ม `/confirmation` มีช่องบังคับเยอะและขยับหน้าจอเมื่อกด `"ขึ้นตัวอย่าง"`:** บนมือถือ `375 px` ต้องกรอกและเลื่อนหน้าจอยาวมาก และการเปิด/ปิดช่อง `"ขึ้นตัวอย่าง"` แทรกช่องวันที่กลางฟอร์มทำให้ตำแหน่งหน้าจอขยับ
3. **ปุ่มแนบ PDF ทีหลังในรายละเอียดงานเป็นภาษาอังกฤษ `"Choose File No file chosen"`:** ขัดกับปุ่ม `"เลือกไฟล์"` ในหน้ารับงาน ทำให้พนักงานที่ไม่ถนัดภาษาอังกฤษอาจไม่รู้ว่าต้องกดตรงไหน
4. **ไม่เห็นล่วงหน้าจากรายชื่อบริษัทว่าเจ้าไหนยังไม่มีเบอร์โทร/ที่อยู่:** บางบริษัทในรายการ (เช่น `เบลสยามโกลเด้น`) ยังไม่มีเบอร์/แผนที่/ที่อยู่ ต้องกดเลือกทีละบริษัทจึงจะเห็นว่าไม่มีข้อมูลติดต่อ
5. **การรับฟิล์ม DTF ต้องกด 2 ขั้นเสมอ (`บันทึกสั่งฟิล์ม` ก่อนจึงจะเห็นปุ่ม `ได้รับแล้ว`):** กรณีแอดมินได้รับฟิล์มมาพร้อมกับตอนส่งใบงานหรือเพิ่งมาบันทึกทีหลัง ต้องใส่ ETA และกดสั่งก่อนหนึ่งรอบจึงจะกดรับฟิล์มได้

### มุมคนหน้างาน (`production` / `qc`)
1. **การ์ดบน `"บอร์ด"` และ `"ต้องทำตอนนี้"` ไม่ขึ้นสีส้ม/แดงเมื่อใกล้ครบ/เลยเวลามาตรฐาน:** คนหน้างานต้องกดเปิดรายละเอียดทีละงานจึงจะเห็นว่างานนั้นเกินเวลาแล้วและต้องส่งรายงานปัญหาก่อนกดเสร็จ
2. **แจ้งเตือนแบบลอยด้านล่าง (`fixed`) บนมือถือ `375 px` บังปุ่มการ์ดถัดไป:** หลังกด `"เริ่มก่อนคิว"` ข้อความสำเร็จสีเขียวลอยทับปุ่ม `"บันทึกและเริ่ม"` ของการ์ดถัดไปชั่วคราว ต้องรอหายหรือเลื่อนหน้าจอหลบ
3. **งานที่ส่งออกข้างนอกยังไปโผล่ใน `"จักรเย็บ" → "รอเย็บ"` ด้วยข้อความ `"งานนี้เริ่มเย็บไปแล้ว จักรไม่ว่าง"`:** ทำให้ช่างเย็บเข้าใจผิดว่าเป็นงานรอขึ้นจักรในโรงงาน
4. **กด `"ไม่ผ่าน"` / `"ตัวอย่างผ่าน"` หรือ `"ส่งรายงานปัญหา"` แล้วหน้าต่างรายละเอียดอยู่คนละตำแหน่งกับปุ่มยืนยัน:** บนจอ `375 px` กล่องยืนยันหรือปุ่ม `"QC + Packing เสร็จ"` หลุดพ้นกรอบจอต้องเลื่อนหาใหม่หลังกรอกด้านล่างเสร็จ
5. **ฝ่ายผลิตล็อกอินเข้ามาเจอแท็บ `"ต้องทำตอนนี้"` (รวมทุกสถานี) แทนแท็บ `"บอร์ด"`:** คนหน้างานที่ประจำเครื่อง/สถานีต้องกดสลับไปแท็บ `"บอร์ด"` ทุกครั้งที่เปิดแอปใหม่
