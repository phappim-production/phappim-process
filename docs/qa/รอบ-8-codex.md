## สิ่งที่ยังตรวจไม่ครบ

- **การแข่งพร้อมกันระดับ SQL** PGlite งานนี้ใช้หนึ่ง connection ชุดทดสอบยืนยันผลหลังคำสั่งต่อกัน การ retry ด้วย UUID เดิม และ invariants ยังไม่มีหลักฐาน PostgreSQL หลาย transaction สำหรับ + ตัวสุดท้ายพร้อมกัน, เย็บเสร็จชนลดจักร, หรือแจ้งเสียชนจัดจักร
- **สิทธิ์และหน้าแบบข้อมูลจริง** ตารางอ่านเป็นจำนวนแถวของ fixture แถว 0 ในตารางว่างใช้ยืนยันนโยบายอ่านไม่ได้เป็นรายตาราง การเพิ่มใช้ `DEFAULT VALUES` เพื่อวัดผลตอบกลับและมี Storage policy แยกที่ใช้แถวถูกต้อง การตั้งค่าของเจ้าของเปิดแก้โดยตรงตามกติกาเดิม การบังคับทุกตารางให้เขียนผ่าน RPC ต้องตีความแยกจากตารางงาน
- **เวลา SLA** ชุดเดิมจับคู่ธงส้ม/แดงกับผลบล็อกของ SQL ส่วน `private.work_days` ปัจจุบันนับทั้งวันจันทร์–เสาร์ (รวมหลัง 18:00) ตามข้อค้างในเอกสารส่งต่อ วันกำหนดส่งกับการเทียบเวลา 18:00 ใน Vitest ใช้เขตเวลาไทย ต้องตกลงเพิ่มเติมหากให้เปลี่ยนนโยบาย SLA ตามชั่วโมงกะ
- **การแสดงผล** รายการข้อความอังกฤษและปุ่มเล็กจาก DOM เป็นข้อมูลคัดกรอง ปุ่มเลือกไฟล์แบบ native ใช้ภาษาของ Chrome และขึ้นอังกฤษในภาพหลักฐาน ยังไม่ได้ตรวจการทับกันและการตัดข้อความทุกองค์ประกอบด้วยตา การบังคับสิทธิ์ตรวจแยกระหว่าง API matrix และปุ่มสำคัญใน Chrome
- **PDF ฟอร์ม** ใบปะงาน A5 ตรวจด้วย Chrome ได้ ส่วนฟอร์มตรวจจากหน้าเตรียมพิมพ์และ PDF ของ Chrome ยังไม่ได้วัดตำแหน่งบนกระดาษจากเครื่องพิมพ์จริง
- **การทดสอบความปลอดภัย** ตรวจนโยบายฐานจำลองและสแกน bundle ตามรูปแบบ key/JWT โดย build ด้วยค่าจำลอง จึงใช้ยืนยันเฉพาะ artifact ที่ทดสอบ
- **ฐานเปรียบเทียบ** `main` เดินต่อระหว่างทดสอบ ผลนี้ผูกกับจุดเริ่มของ worktree และ commit ที่ส่งงาน
