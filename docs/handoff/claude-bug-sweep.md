## รอบ 2 (เจ้าของสั่ง "แก้ไขให้เรียบร้อย")
- **ยกเลิกบางส่วนของงานที่แบ่งใบ เวลาผลิตไม่หดย้อนหลังแล้ว:** เดิมงาน 600 ชิ้น (15 วัน) แบ่ง 300 แล้วยกเลิกส่วนนั้น → เหลือ 10 วัน งานที่ทันอยู่กลายเป็นเกินทันที · ตอนนี้นับจำนวนของส่วนที่ยกเลิกด้วย (ตรงกับการแก้ใบยืนยันที่นับทั้งครอบครัวอยู่แล้ว) · migration `20261203000000_lead_split_cancel.sql` (แก้ `private.lead_state` ตัวเดียว) · หน้าตั้งค่าแท็บเวลาผลิตเขียนกฎนี้ไว้
- **ข้อความพักงาน:** "พักงานแล้ว · เวลาที่พักไม่นับเป็นเวลาทำงาน" → "พักงานแล้ว · เวลาผลิตทั้งงานยังนับต่อ แก้แล้วรีบทำต่อ" (ไทย + พม่า) ทั้งหน้าคิวสถานีและรายละเอียดงาน · คำอธิบายในคำศัพท์และคู่มือฝ่ายผลิตแก้ตาม · รายงานเวลาที่สถานียังไม่นับช่วงพักเหมือนเดิม
- ทดสอบ: `supabase/tests` 1898 + 106 (ใหม่: แบ่ง 300 + 300 แล้วยกเลิก ยัง 15 วัน · แก้ข้อทดสอบเดิมใน sweep-fixes ที่ล็อกกฎเก่า) · app build / lint / 569 + 186 · เบราว์เซอร์ qa-part-a A2 + A5 (ตรวจข้อความพักงานทั้ง 2 หน้า) ผ่าน
