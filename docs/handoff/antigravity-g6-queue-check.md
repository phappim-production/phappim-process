## ทดสอบอะไร (บน `https://pp142.pages.dev/`)
ทดสอบด้วยบัญชี `@pp142.test` ทั้ง 4 บทบาท (`admin`, `production`, `qc`, `manager`) โดยสร้างงานใหม่เฉพาะ `TEST-R4-A`, `TEST-R4-B`, `TEST-R4-C` (ไม่แตะงาน `TEST-` / `TEST-SIM-*` ของรอบก่อน):

- **ก่อนเริ่ม (PWA Cache รุ่นก่อน G5):** พบว่าเบราว์เซอร์ทดสอบค้าง Service Worker รุ่น 17 พ.ย. `15:55` (ก่อน G5) รีเฟรชแท็บเดิม 5 รอบยังเป็นรุ่นเก่า ([ภาพ](../qa/img/r4-ag-01-sw-cached-old.png)) · เมื่อ**ปิดแท็บเก่าทั้งหมดแล้วเปิดแท็บใหม่ 1 ครั้ง**โหลดรุ่นล่าสุดทันที
- **ข้อ 1 (`admin`):** รับงาน `TEST-R4-A` (28 พ.ย.) → `TEST-R4-B` (26 พ.ย.) → `TEST-R4-C` (20 พ.ย.) เส้นทาง `ไม่มีงานพิมพ์` · `ไม่ขึ้นตัวอย่าง` โดย**ไม่แนบ PDF** สำเร็จทั้ง 3 งานและเข้า `ตัดงาน` ทันที ([ภาพรับงาน](../qa/img/r4-ag-01-admin-receive.png) · [ภาพคิว](../qa/img/r4-ag-01-cut-station.png))
- **ข้อ 2 ★ (`production` 375 / 768 / 1440 px):** แผงเลือกสถานีและกล่องตัวเลขสรุปหายไป เหลือแถบ `"สถานี ตัดงาน · เปลี่ยนสถานี"` · `TEST-R4-A/B/C` ต่อท้ายคิวตามลำดับรับเข้า (`C` ไม่แซงแม้กำหนดส่งเร็วที่สุด) · ไม่ล้นด้านข้างทั้ง 3 ขนาดจอ ([375 px](../qa/img/r4-ag-02-queue-375.png) · [768 px](../qa/img/r4-ag-02-queue-768.png) · [1440 px](../qa/img/r4-ag-02-queue-1440.png))
- **ข้อ 3–6 (`production`):**
  - แทรกคิว `TEST-R4-C` ไม่ใส่เหตุผลกดไม่ได้ (`"ใส่เหตุผลก่อน"`) · ใส่ `"ลูกค้าเลื่อนวันส่ง R4"` แล้วขึ้นเป็น `คิว 1` ทันที ([ภาพ](../qa/img/r4-ag-03-rush-insert.png))
  - `TEST-R4-B` กด `"เริ่มก่อนคิว"` ใส่ `"ผ้างานคิวแรกยังไม่มา R4"` → ย้ายไป `"กำลังทำ"` และบันทึก `"เริ่มก่อนคิว ที่ตัดงาน"` + รายชื่อคิวที่ข้ามในไทม์ไลน์ ([ภาพ](../qa/img/r4-ag-04-skip-queue.png))
  - `TEST-R4-C` กด `"เริ่มตัดงาน"` → `"ตัดงานเสร็จ"` → `"ยืนยัน"` บนการ์ด ส่งต่อไป `เย็บงาน` และไทม์ไลน์มี `"แทรกคิวงานด่วน"` ครบ ([ภาพ](../qa/img/r4-ag-05-finish-card.png))
  - พัก `TEST-R4-B` (`"ใบมีดทื่อ R4"`) การ์ดขึ้นกรอบแดง + `"แก้แล้ว ทำต่อ"` ([ภาพ](../qa/img/r4-ag-06-hold-card.png)) และกดทำต่อบนการ์ดกลับเป็น `"กำลังทำ"` ได้
- **ข้อ 7–8 (`admin` / `qc`):** `admin` ดูอย่างเดียวไม่มีปุ่มสั่งงาน ([ภาพ](../qa/img/r4-ag-07-admin-readonly.png)) · `qc` ที่ `ตัดงาน` ไม่มีปุ่มเริ่ม ([ภาพ](../qa/img/r4-ag-08a-qc-other-station.png)) และที่ `QC + Packing` มีปุ่ม `"บันทึกผล QC / Packing"` บนการ์ดกำลังทำ ([ภาพ](../qa/img/r4-ag-08-qc-station.png))
- **ข้อ 9 ★ – 10 (`manager` 375 / 768 / 1440 px):** ตัวเลข `"สถานีตอนนี้"` ตรงกับหน้าคิวของสถานีจริง (`พิมพ์ 8`, `ตัด 8`, `เย็บ 12`, `QC + Packing 2`) · ไม่ล้นทั้ง 3 ขนาดจอ ([375 px](../qa/img/r4-ag-09-manager-375.png) · [768 px](../qa/img/r4-ag-09-manager-768.png) · [1440 px](../qa/img/r4-ag-09-manager-1440.png)) · กดการ์ดสถานีแล้วเปิดหน้าคิวอยู่บนสุดและรีเฟรชแล้วยังอยู่สถานีเดิม · `"งานที่ต้องตาม"` แสดง 8 งาน `"คาดไม่ทัน X วัน"` และกดเปิดถูกงาน ([ภาพ](../qa/img/r4-ag-10-follow-up.png))
- **ข้อ 11–13:** ซิงค์ 2 แท็บเมื่อแทรกคิว `TEST-R4-A` อัปเดตเองภายใน `1,348 ms` ([ภาพ](../qa/img/r4-ag-11-realtime-sync.png)) · กด `"เริ่มตัดงาน"` พร้อมกัน 2 แท็บ บันทึก 1 ครั้ง อีกแท็บขึ้น `"TEST-R4-A: สถานะงานเปลี่ยนไปแล้ว (สถานีนี้เริ่มไปแล้ว) กรุณาโหลดหน้าใหม่"` ([ภาพ](../qa/img/r4-ag-12-concurrent-start.png)) · ทุกบทบาทไม่มีคำว่า `"วัตถุดิบ"` ค้างและ console ไม่มี error (`0` errors)

## ข้อสังเกตที่พบ (ไม่พบบั๊กระดับ 1)
1. **ระดับ 2:** เบราว์เซอร์ที่ค้าง Service Worker รุ่นก่อน G5 ต้องปิดแท็บเก่าทั้งหมดแล้วเปิดใหม่ 1 ครั้งจึงจะรับรุ่นใหม่
2. **ระดับ 3:** `"สถานีตอนนี้"` รวมงานตัวอย่างในเลขสถานี (`พิมพ์ 8 / ตัด 8 / QC + Packing 2`) แต่ปุ่ม `"เลือกสถานี"` แยกงานตัวอย่างออกไป (`พิมพ์ 6 / ตัด 7 / QC + Packing 1`)
3. **ระดับ 3:** ป้ายการ์ดตัวอย่างที่ `QC + Packing` ขาดช่องว่าง (`"QC + Packingเสร็จ"`, `"ไม่มีงานรอที่QC + Packing"`) และแท็บ `sticky` ทับขอบการ์ดแรกบางช่วงขณะเลื่อน
4. **ระดับ 3:** แท็บ `"มุมมองภาพรวม"` บนจอ `375 px` ตัดคำว่า `"วางแผนรับงาน"` เป็น `"วางแผนรับ"` พร้อม scrollbar แนวนอน
5. รวมข้อเสนอ UX จากมุมคนหน้างานที่ไม่ถนัดเทคโนโลยี 5 ข้อไว้ในรายงาน [`รอบ-4-antigravity.md`](../qa/รอบ-4-antigravity.md) หัวข้อ 3 แล้ว
