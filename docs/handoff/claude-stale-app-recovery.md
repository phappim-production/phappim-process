สาเหตุ: แท็บที่ค้างไว้ยังโหลดไฟล์ของรุ่นเก่า ระหว่างที่ service worker รุ่นใหม่ลบแคชรุ่นเก่า · Cloudflare ตอบไฟล์ที่ไม่มีแล้วด้วยหน้า HTML (200) แทน 404 → ไฟล์หลักของแอปโหลดไม่ได้ → React ไม่เริ่มเลย ไม่มีอะไรแสดง (ErrorBoundary เดิมจับได้เฉพาะหลังแอปเริ่มแล้ว)

## แก้
- `app/index.html`: ระหว่างเปิดแสดง "กำลังเปิดระบบ… · ဖွင့်နေတယ်…" (ไม่ขาวตั้งแต่แรก) · ถ้าไฟล์ของแอปโหลดไม่ได้หรือพังก่อนแอปขึ้น → ล้าง service worker + แคชของแอปแล้วโหลดใหม่เอง 1 ครั้ง (กันวนด้วย sessionStorage นาทีละครั้ง) · ยังไม่ได้ → ขึ้นข้อความ + ปุ่ม "โหลดใหม่" ไทย/พม่า (กดแล้วล้างแคชและโหลดใหม่) · เน็ตช้าเกิน 30 วิ ขึ้นปุ่มอย่างเดียว ไม่ล้างแคชเอง
- `app/src/main.tsx`: ครอบทั้งแอปด้วย ErrorBoundary · ส่วนหัว/เมนู/กล่องจดหมายพังก็ไม่ขาว
- `tools/qa-r14/chrome.mjs`: รอจนข้อความกำลังเปิดระบบหายก่อนตรวจหน้า
