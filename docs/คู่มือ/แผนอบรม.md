# แผนอบรมและลำดับวันทดลองจริง

> **วันเสาร์ที่ 21 พ.ย. 2569:** ทดลองใช้งานจริง 1 ไลน์ (ซ้อมก่อนวันเปิดจริงและใช้ **ใบปะงาน** คู่กระดาษตลอดวัน)
> **วันอาทิตย์ที่ 22 พ.ย. 2569:** อบรมทบทวนรายบทบาท **รอบละ 30 นาที** (15 นาทีอธิบาย + 15 นาทีฝึกกดจริงบนแท็บเล็ตด้วยงานทดสอบ `TEST-`)
> เป้าหมาย: ทุกคนกดงานจริงเป็น ไม่ส่งเครื่องต่อโดยไม่ **ออกจากระบบ** และรู้ว่าเน็ตหลุดหรือมีระบบรุ่นใหม่ต้องทำอย่างไร

---

## ลำดับวันทดลองจริง (วันเสาร์ที่ 21 พ.ย. 2569)

1. **15 นาทีแรก (รวมทีมก่อนเริ่มงาน):**
   - สอน **ล็อกอิน** และกฎเหล็ก **ออกจากระบบทุกครั้งเมื่อส่งเครื่องต่อ**
   - สอนเปิดดู **กล่องจดหมาย** (กระดิ่งมุมขวาบน)
   - สอนปัดรีเฟรช / กดโหลดเมื่อเห็นแถบ **มีระบบรุ่นใหม่** หรือหน้าจอดูแปลก
2. **ซ้อมกดก่อนเดินงานจริง:**
   - ฝึกกดด้วยงานทดสอบ `TEST-` ให้คุ้นมือทุกบทบาท (แอดมินส่งงานเข้า + พิมพ์ **ใบปะงาน**, ฝ่ายผลิตเดิน **สถานี** เริ่ม → เสร็จ + พักงาน, QC ตรวจผ่าน/ส่งกลับแก้)
3. **ระหว่างเดินไลน์ทดลองตลอดวัน:**
   - **ใช้คู่กระดาษตลอดวัน**: แอดมินพิมพ์ **ใบปะงาน + QR** ขนาด A5 ติดไปกับกองงานทุกงาน
   - พนักงานเซ็นช่องวันที่/ผู้รับ/ลายเซ็นบนกระดาษ **ควบคู่กับ** การกด **เริ่ม** / **เสร็จ** ในระบบทันทีที่จบงานแต่ละ **สถานี**

## รายละเอียดแผนอบรมรายบทบาท (30 นาที/รอบ)

### รอบที่ 1: ฝ่ายผลิต (30 นาที)
- **หัวข้อสอน (15 นาที):**
  1. ล็อกอิน · **กล่องจดหมาย** (กระดิ่งมุมขวาบน) · กฎเหล็ก **ออกจากระบบทุกครั้งเมื่อส่งเครื่องต่อ** · แถบ **มีระบบรุ่นใหม่**
  2. ดูแท็บ **ต้องทำตอนนี้** vs **บอร์ด** (ปุ่มสถานีใหญ่ **ก่อนผลิต / เฟส 1 / เฟส 2** และเครื่องจำสถานีที่เลือก) vs **จักรเย็บ**
  3. เดิน **สถานี** แบบใหม่: กด **เริ่ม** → **เสร็จ** + **พักงาน / ติดปัญหา** (ไม่มีเช็คลิสต์ **ขั้นย่อย** แล้ว) · **รีดฟิล์ม** (รอแอดมินรับก่อน) · **ส่งปัก (ร้านนอก)** · ปุ่ม **แจ้งว่ากดผิด** (บันทึกว่าผิดพร้อมเหตุผล ไม่ได้ย้อนสถานะงาน)
  4. ใช้ **ใบปะงาน + QR** (พิมพ์ A5 ติดกองงาน · สแกน QR เปิดงาน · เซ็นกระดาษคู่)
  5. เย็บ/จักร (**งานเย็บ**, **ตารางจอง**, **สถานะจักร**) และสังเกตป้าย **งานแก้** สีแดง
  6. **พักงาน** (พิมพ์สาเหตุ), **รายงานปัญหา** (เมื่อแถบแดง **เกินเวลามาตรฐาน**), และทำอย่างไรเมื่อ **เน็ตหลุด**
- **แบบฝึกกดจริง (15 นาที):**
  1. ล็อกอินด้วยบัญชีตัวเองบนแท็บเล็ต และลองเลือกสถานีที่ตัวเองคุมใน **บอร์ด** แล้วรีเฟรชดูว่าเครื่องจำค่าไว้
  2. สแกน QR จากใบปะงานทดสอบ `TEST-` เพื่อเปิดงาน
  3. ลองเดิน **สถานี** (`เริ่ม` → `เสร็จ`) และลองกด **พักงาน** (พิมพ์สาเหตุ) แล้วกด **แก้แล้ว ทำต่อ**
  4. กด **ออกจากระบบ** แล้วส่งแท็บเล็ตให้เพื่อนข้างๆ ล็อกอินต่อ

---

### รอบที่ 2: แอดมิน (30 นาที)
- **หัวข้อสอน (15 นาที):**
  1. ล็อกอิน · **กล่องจดหมาย** · **ออกจากระบบ** · แถบ **มีระบบรุ่นใหม่**
  2. วิธี **รับงาน** ใหม่: กด **บันทึกไฟล์** (`.json`) และ PDF จากฟอร์มใบยืนยัน → แนบใน **รับงานใหม่** → ตรวจเส้นทาง 8 แบบ, จำนวน, และ **ขึ้นตัวอย่าง / ไม่ขึ้นตัวอย่าง** → กดรับงาน (งานเข้า **สถานี** แรกทันที ไม่มีขั้นรอวัตถุดิบ)
  3. พิมพ์ **ใบปะงาน + QR** ขนาด A5 ส่งให้หน้างาน
  4. บันทึกสั่งและรับงาน (**DTF / DTG / ซิลค์สกรีน**) และบันทึกผล **ขึ้นตัวอย่าง** (ผ่าน / ไม่ผ่านพร้อมระบุสิ่งที่ต้องแก้)
  5. ใช้ **ค้นหางาน** ดูรายละเอียดงาน/ไทม์ไลน์/เปิด PDF · **วางแผนรับงาน** · รับมือเมื่อ **เน็ตหลุด**
- **แบบฝึกกดจริง (15 นาที):**
  1. ทดลองเปิดฟอร์มใบยืนยัน กด **บันทึกไฟล์** แล้วนำไฟล์ `.json` มาแนบในหน้า **รับงานใหม่** (เช็กเส้นทาง/จำนวน/ขึ้นตัวอย่าง)
  2. เปิดงานทดสอบ `TEST-` ลองกด **พิมพ์ใบปะงาน** ดูตัวอย่าง A5
  3. ลองบันทึกสั่ง/รับฟิล์ม และบันทึกผล **ขึ้นตัวอย่าง** (ผ่าน / ไม่ผ่าน)
  4. ใช้ **ค้นหางาน** ค้นเลขที่ `TEST-` เพื่อดู **รอบตัวอย่าง** และ **ไทม์ไลน์ทุกการกด**

---

### รอบที่ 3: ฝ่าย QC (30 นาที)
- **หัวข้อสอน (15 นาที):**
  1. ล็อกอิน · **กล่องจดหมาย** · **ออกจากระบบ** · แถบ **มีระบบรุ่นใหม่**
  2. ดูแท็บ **ต้องทำตอนนี้** และ **บอร์ด**
  3. เดิน **สถานี** **QC + Packing**: กด **เริ่ม QC + Packing** → กรอกยอดผ่านให้ครบตามจำนวนสั่ง จึงจะกด **QC + Packing เสร็จ** ได้
  4. วิธีส่ง **งานแก้** (ป้ายสีแดง) กลับ **สถานี** เย็บ + **พักงาน** / **รายงานปัญหา** + **เน็ตหลุด**
- **แบบฝึกกดจริง (15 นาที):**
  1. เริ่ม **QC + Packing** บนงานทดสอบ แล้วลองส่ง **งานแก้** กลับไปเย็บ 5 ชิ้น พร้อมระบุสาเหตุ
  2. ตรวจงานแก้รอบที่กลับมาจากเย็บ กรอกยอดผ่านให้ครบจำนวนเพื่อกด **QC + Packing เสร็จ**
  3. กด **ออกจากระบบ**

---

### รอบที่ 4: ผู้บริหาร (30 นาที)
- **หัวข้อสอน (15 นาที):**
  1. ล็อกอิน · **กล่องจดหมาย** · **ออกจากระบบ** · แถบ **มีระบบรุ่นใหม่**
  2. อ่านหน้า **ภาพรวม** และ **งานที่ต้องตาม** (แยกสี แดง / ส้ม / ฟ้า / เขียว)
  3. ดู **บอร์ด** สด, **จักรเย็บ**, **ค้นหางาน**, และ **รายงาน** (เวลาเฉลี่ยต่อสถานี, คอขวด, % ทันกำหนด, งานแก้, กดงานเกินกำหนดเปิดดูรายละเอียด)
  4. ย้ำสิทธิ์ "ดูได้อย่างเดียว" และวิธีอ่านแถบ **ขาดการเชื่อมต่อ**
- **แบบฝึกกดจริง (15 นาที):**
  1. เปิดหน้า **ภาพรวม** และ **งานที่ต้องตาม** แล้วลองกรองหางานติดปัญหา
  2. เข้า **บอร์ด** เพื่อดูว่างานทดสอบกำลังอยู่ **สถานี** ไหน
  3. เปิดหน้า **รายงาน** ดูคอขวดและลองคลิกงานเกินกำหนดเพื่อเปิดรายละเอียด

---

### รอบที่ 5: เจ้าของระบบ (30 นาที)
- **หัวข้อสอน (15 นาที):**
  1. ความปลอดภัยบัญชีเจ้าของระบบ (ห้ามล็อกอินค้างบนเครื่องหน้างาน)
  2. ภาพรวมทั้งระบบ, **กล่องจดหมาย**, **รายงาน**, และการตรวจงานค้างทุกเช้า
  3. วิธีแก้ไขเมื่อกดผิดด้วยปุ่ม **แจ้งว่ากดผิด** ใน **ไทม์ไลน์ทุกการกด** (บันทึกว่ารายการนั้นผิดพร้อมเหตุผล ไม่ได้ย้อนสถานะงาน · ถ้าต้องย้อนสถานะจริงให้เจ้าของระบบดำเนินการ) (ไม่แก้ตรงในฐานข้อมูล)
  4. หน้า **ตั้งค่า** 7 แท็บ และการสร้างบัญชีใหม่ใน **Supabase → Authentication → Add user** + กำหนดบทบาทบนหน้าเว็บ + รับมือ **เน็ตหลุด** / **มีระบบรุ่นใหม่**
- **แบบฝึกกดจริง (15 นาที):**
  1. ตรวจดูหน้า **ภาพรวม**, **รายงาน**, และ **ค้นหางาน** จากงานทดสอบ `TEST-`
  2. ตรวจเช็กรายชื่อบัญชีผู้ใช้งานจริงทั้งหมดในหน้า **ตั้งค่า** ก่อนเปิดใช้
  3. ซ้อม **ออกจากระบบ** ทุกครั้งหลังใช้งาน
