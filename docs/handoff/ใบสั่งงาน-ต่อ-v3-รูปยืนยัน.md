## 3. งานที่ต้องทำต่อ (เรียงตามลำดับ)
1. **แก้หน้าสลับบัญชีในระบบจำลอง** (เจ้าของบอก "Login ไม่ผ่าน"): บน `127.0.0.1:5214` service worker ของ PWA เสิร์ฟหน้าแอปแทน `/__qa/switch` (navigateFallback) จึงเลือกบัญชีไม่ได้ · แก้โดยเพิ่ม `/^\/__qa\//` ใน `navigateFallbackDenylist` ใน `app/vite.config.ts` (ระบบจริงไม่มี `/__qa` จึงไม่กระทบ) แล้ว build ใหม่ · ถ้ายังเห็นของเก่า ให้ unregister service worker + ล้าง cache ในเบราว์เซอร์
2. **เปิดให้เจ้าของดูในเครื่อง** (ข้อ 4) แล้วปรับตามที่เจ้าของบอก
3. **ถามเจ้าของก่อน** แล้ว commit (แยก 2 commit ได้ถ้าแยกไฟล์ได้: รูปยืนยันงาน / หน้าตา v3) + เปิด PR · ห้าม merge โดยไม่ถาม
4. ขึ้นระบบจริงตามลำดับใน `docs/handoff/claude-station-photos.md`: migration จริง → deploy Worker → merge เว็บ → เจ้าของเปิดฟีเจอร์ในตั้งค่า
5. `tools/qa-r14/demo-v3.mjs`, `e2e-photos.mjs`, `demo-img/` ยังไม่ได้ commit · ถามเจ้าของว่าจะเก็บเข้า repo หรือไม่

**ยังไม่ได้ทำจากแบบ v3:** ฟอร์มใบยืนยันยังไม่ได้จัดหน้าตาตามแบบ (เปลี่ยนแค่สี) · ยังไม่ได้ลองบนมือถือจริงด้วยนิ้ว · ข้อความในต้นแบบ canvas บางคำ (ส่ง n รูป, ถ่ายใหม่ทั้งหมด, ต่อเน็ตก่อนถ่ายรูป) ยังไม่มีคำแปลพม่า แต่ในแอปจริงไม่ได้ใช้คำเหล่านี้

## 4. เปิดดูในเครื่อง (ระบบจำลอง ห้ามใช้ระบบจริง)
1. build แบบชี้ในเครื่อง:
   ```powershell
   $env:VITE_SUPABASE_URL='http://127.0.0.1:5214'; $env:VITE_SUPABASE_ANON_KEY='r14-local-anon-key'; $env:VITE_FILES_URL='http://127.0.0.1:5215'; npm.cmd --prefix app run build
   ```
2. ข้อมูลตัวอย่างทุกสถานะใหม่: `node tools/qa-r14/demo-v3.mjs` (เปิดเซิร์ฟเวอร์ + ใส่ข้อมูลให้เลย · ทำตามหลักนี้): เรียก `startLocalStack()` จาก `tools/qa-r14/server.mjs` → owner เรียก `set_station_photos_enabled(true, 15)` → รับงาน 5 งาน (route `cut_only` / `normal`) ใส่ `jobs.mockup_path` + วางไฟล์ใน `stack.r2Store` → รูปสถานีต้องวางใน `r2Store` **และ** insert `private.file_objects (kind 'station_photos')` ก่อนเรียก `submit_first_piece` (ไม่งั้นฐานข้อมูลปฏิเสธว่ารูปยังอัปโหลดไม่เสร็จ) → แอดมิน `decide_first_piece` ให้ไม่ผ่าน 1 งาน ผ่าน 1 งาน
3. เปิด `http://127.0.0.1:5214/__qa/switch` (ใช้ 127.0.0.1 ไม่ใช่ localhost) · บัญชีที่ควรดู: แอดมิน 1 (อนุมัติชิ้นแรก) · พนักงานตัด (มือถือ) · พนักงานหลายสถานี → พิมพ์ (ไม่ผ่าน) · เจ้าของ (ภาพรวม)
4. แถบแดง "ขาดการเชื่อมต่อ" ในระบบจำลอง = ไม่มี Realtime (ปกติของระบบจำลอง) · ฟอนต์ภายนอกถูกบล็อกตอนรัน QA
5. **`.claude/launch.json` ของ checkout หลัก** มีรายการชั่วคราว `qa-photos`, `v3-demo`, `design-preview` (ชี้ไฟล์ใน scratchpad) · ลบเมื่อไม่ใช้แล้ว
