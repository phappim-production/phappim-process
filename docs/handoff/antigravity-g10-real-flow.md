  - `1 พิมพ์` เต็ม `2/2` บล็อกงานที่ 3 · พักยกลงแล้วเริ่มงานอื่นได้ · `แก้แล้ว ทำต่อ` ตอนเครื่องเต็มงานกลับเข้าคิว
  - `2 รีด` กับ `4 รีดฟิล์ม` แยกเครื่องกัน เริ่มพร้อมกันได้
