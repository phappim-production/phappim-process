## ส่วน A — ม็อคอัพกำกับสเปก (ทำก่อน · ทุกข้อถ่ายภาพ + จดเวลา + บัญชีที่ใช้)

### เตรียมงาน (admin)
- กรอกใบยืนยัน `/confirmation` 3 ใบ แล้วรับงานเข้าระบบ:
  - **`TEST-R10-A`** เสื้อยืด · DTF · ติ๊กตำแหน่ง **หน้าอกซ้าย** (ไม่ใส่เทคนิค ใส่ขนาด) + **กลางหลัง** (ใส่เทคนิค + ขนาด + หมายเหตุ) · ใส่ คอเสื้อ / สีคอ / แขน
  - **`TEST-R10-B`** เสื้อกีฬา · ปกติ ซับลิเมชั่น · ไม่ขึ้นตัวอย่าง (ไว้ทดสอบแก้ฉบับหลังเริ่มผลิต)
  - **`TEST-R10-C`** เส้นทาง ปัก หรือ ไม่มีพิมพ์ (ไว้ทดสอบว่าพนักงานสถานีที่งานไม่ผ่าน มองไม่เห็น)

### A1. อัปโหลดภาพ + ตรวจไฟล์
1. รายละเอียดงาน `TEST-R10-A` → **ม็อคอัพกำกับสเปก** → **เริ่มทำม็อคอัพกำกับสเปก**
2. อัปโหลด **ภาพหลักแบบหน้า + หลังในภาพเดียว** (แบบที่โรงงานใช้จริง · PNG) และวางจุดบนทั้งสองตัว · ภาพเพิ่ม ด้านหลัง (JPG) · ด้านซ้าย (WEBP) · เห็น **ตัวอย่างภาพก่อนบันทึก** ทุกครั้ง
3. ต้องถูกปฏิเสธพร้อมข้อความไทย: GIF · PDF · ข้อความเปลี่ยนนามสกุล · ภาพเกิน 5 MB
4. อัปโหลดภาพมุมเดิมซ้ำ = แทนภาพเดิม · ลบภาพ 1 มุม → Callout บนภาพนั้นหายด้วย
5. ภาพแนวนอน / ภาพเล็กมาก / ภาพใหญ่ใกล้ 5 MB แสดงถูกสัดส่วน ไม่ยืด
6. บันทึกร่าง → ดาวน์โหลดภาพจากหน้าเว็บ (คลิกขวา บันทึกภาพ) เทียบกับต้นฉบับ: **ขนาดพิกเซลเท่าเดิม ไม่ถูกย่อ**

### A2. Callout เพิ่ม / แก้ / ลบ / เรียง
1. กดบนภาพ = จุดใหม่ เลขเรียง 1, 2, 3 … · กดที่จุดหรือกล่อง = เลือก (แผงขวาเปลี่ยนตาม)
2. ลากจุด · ลากกล่องข้อความ · เส้นโยงตามไป · **ลากแล้วต้องไม่เกิดจุดใหม่**
3. ลบจุดกลาง (เช่นจุด 2 จาก 4) → เลขเรียงใหม่ไม่เว้น · ▲▼ เปลี่ยนลำดับ
4. จุดหลายจุดบนภาพเดียว (อย่างน้อย 10 จุด) · จุดบนภาพหลัง/ซ้าย แสดงเฉพาะในมุมนั้น
5. **ย้อน / ทำซ้ำ** (ปุ่มและ Ctrl+Z / Ctrl+Y) ทุกการกระทำ: เพิ่ม ลาก ลบ เปลี่ยนชื่อ ผูกสเปก · พิมพ์ในช่องแล้วกด Ctrl+Z ต้องไม่ย้อนทั้งหน้า
6. ลากจุด/กล่องไปนอกภาพ → ต้องติดขอบ ไม่หลุดออกนอกภาพ
7. ยังไม่บันทึกแล้วปิดแท็บ / รีเฟรช → เบราว์เซอร์เตือน

### A3. บันทึก / โหลด / ความแม่นของตำแหน่ง
1. บันทึกร่าง → รีเฟรช → ทุกจุด ทุกกล่อง ทุกสเปก กลับมาที่เดิม (ถ่ายภาพก่อน/หลังวางซ้อนกันเทียบ)
2. เปิดฉบับเดียวกันที่ **375 / 768 / 1440 px** และแท็บเล็ตจริง → จุดอยู่บนตำแหน่งเดียวกันของลายเสื้อ (เช่น อกซ้ายยังอยู่ที่อกซ้าย)
3. ซูม 50% → 300% และ Ctrl+ล้อเมาส์ → จุดไม่เลื่อนจากลาย · เลื่อนดูภาพตอนซูมได้ (นิ้ว/เมาส์)
4. ซูมเบราว์เซอร์ (Ctrl + / −) และหมุนแท็บเล็ต แนวตั้ง ↔ แนวนอน → จุดไม่เลื่อน

### A4. ผูกสเปก
1. **อ้างข้อมูลจากใบยืนยัน**: รายการมีเฉพาะช่องที่กรอกไว้ · หน้าอกซ้ายต้องขึ้น **DTF · ขนาด ซม.** (เทคนิคมาจากเทคนิคเดียวของใบ) · ค่าตรงกับใบยืนยัน
2. **+ สร้างสเปกใหม่จากจุดนี้** → รหัส S-01 · กรอกทุกช่อง (ชื่อ ประเภท ตำแหน่ง รายละเอียด กว้าง สูง หน่วย สี รหัสสี วัสดุ วิธีผลิต ไฟล์ Artwork หมายเหตุ สถานี)
3. ใช้สเปก S-01 ซ้ำกับอีกจุด → แก้ที่จุดหนึ่ง อีกจุดเปลี่ยนตาม (ไม่ต้องกรอกซ้ำ) · ลบสเปก → จุดไม่ค้างอ้างของที่ลบ
4. ขนาด 0 / ติดลบ / ตัวอักษร · รหัสสเปกซ้ำ · ชื่อจุดว่าง → บันทึกไม่ได้ ข้อความบอกว่าต้องแก้อะไร
5. ส่งอนุมัติขณะยังมีจุดไม่มีสเปก → ปุ่มกดไม่ได้และบอกเหตุผล

### A5. สิทธิ์ (ทุกบทบาท · ทั้งปุ่มและการพิมพ์ URL ตรง)
1. **production / manager / qc**: เปิด `#/mockup?id=<งาน>` → ไม่มีปุ่มเริ่ม / อัปโหลด / บันทึก / ส่งอนุมัติ
2. **qc**: ฉบับที่ยังไม่อนุมัติ → เห็นแค่ "ยังไม่อนุมัติ" ไม่เห็นภาพ/จุด
3. **admin**: ไม่มีปุ่มอนุมัติ ขึ้นว่าแอดมินอนุมัติเองไม่ได้
4. **staff** (ถ้ามีบัญชี): เปิด `#/artwork?id=…` ต้องขึ้นว่าบทบาทเปิดหน้านี้ไม่ได้ · เห็นเฉพาะจุดของสถานีตัวเอง · งาน `TEST-R10-C` (ไม่ผ่านสถานีของ staff) ต้องไม่เห็นม็อคอัพ
5. ล็อกอินบัญชีหนึ่ง เปิดหน้าทิ้งไว้ → ออกจากระบบในอีกแท็บ → กดบันทึกในแท็บแรก ต้องไม่สำเร็จ

### A6. อนุมัติ / ส่งกลับ / ฉบับใหม่
1. admin **ส่งอนุมัติ** → สถานะ **รออนุมัติ** · admin แก้ไม่ได้แล้ว
2. production **ส่งกลับ** (เหตุผลว่างต้องกดไม่ได้) → admin เห็นแถบแดงพร้อมเหตุผล → แก้ → ส่งใหม่
3. production **อนุมัติ** (ใส่หมายเหตุ) → ขึ้น **ใช้ผลิต: ฉบับ 1 · อนุมัติ <เวลา> โดย <ชื่อ>** · ไทม์ไลน์ของงานมี "อนุมัติม็อคอัพกำกับสเปก ฉบับ 1"
4. หลังอนุมัติ: ไม่มีปุ่มแก้ฉบับ 1 ทุกบทบาท · admin **สร้างฉบับแก้ไข** (เหตุผลว่างกดไม่ได้) → ฉบับ 2 คัดลอกภาพ/จุด/สเปกมาครบ · หน้าดูสเปกยังเป็นฉบับ 1 + แถบส้ม "มีฉบับแก้ไข 2 …" (ดูด้วยบัญชี qc ด้วย)
5. **ทิ้งฉบับร่าง** ได้ · ฉบับ 1 ยังใช้ผลิตอยู่
6. `TEST-R10-B`: อนุมัติฉบับ 1 → **เริ่มงานที่สถานีแรก** (production) → สร้างฉบับ 2 → ส่ง → production อนุมัติ **ต้องกดไม่ได้** ("งานเริ่มผลิตแล้ว ต้องให้ผู้บริหารหรือเจ้าของอนุมัติ") → manager อนุมัติได้ → ฉบับ 1 เป็น **ถูกแทนที่** ในประวัติฉบับ
7. แก้ใบยืนยันของงานหลังอนุมัติ (ถ้าระบบมีทางแก้) → ฉบับที่อนุมัติยังแสดงค่าเดิม + แถบเตือนใบยืนยันถูกแก้

### A7. ฉบับที่อนุมัติแก้ไม่ได้ (ทางหน้าเว็บ)
- ทุกบทบาท: ฉบับอนุมัติ / ถูกแทนที่ ไม่มีช่องให้แก้ · ลากจุดไม่ได้ · กดบนภาพไม่เพิ่มจุด · พิมพ์ฉบับเก่าจากประวัติฉบับได้และค่าไม่เปลี่ยน

### A8. หน้าดูของหน้างาน + รับทราบ
1. production: **ดูเฉพาะสถานี** เปลี่ยนสถานี → จุดที่เห็นเปลี่ยนตาม · กดจุด → แผงขวาแสดงสเปกเต็ม · ไม่มีปุ่มแก้
2. **รับทราบสเปกฉบับ n · สถานี…** → ขึ้นเขียว + รายชื่อ "รับทราบแล้ว" มีชื่อ สถานี เวลา · กดซ้ำไม่เกิดรายการซ้ำ
3. qc: สถานีถูกล็อกที่ QC + Packing · รับทราบได้
4. ฉบับใหม่อนุมัติแล้ว → ต้องรับทราบใหม่ (ของฉบับเก่าไม่นับ)

### A9. ใบกำกับงานพิมพ์ (PDF)
1. **พิมพ์ / PDF** → A4 แนวนอน และ A3 แนวนอน → **บันทึกเป็น PDF** ทั้ง 2 ขนาด (`r10-ag-artwork-A4.pdf` / `-A3.pdf`) + พิมพ์กระดาษจริงถ้ามีเครื่องพิมพ์
2. มีครบ: เลขใบ ลูกค้า งาน จำนวน กำหนดส่ง · ฉบับ · สถานะ · วันที่อนุมัติ · ผู้อนุมัติ · ภาพหน้า + หลัง · จุด + เส้นโยง + เลข · ตารางสเปก · ตารางสเปกเพิ่มเติม
3. **ตำแหน่งจุดบนกระดาษตรงกับหน้าแก้ไข** (วางภาพหน้าจอเทียบ) · ตัวหนังสืออ่านได้ชัดบน A4 · ภาพไม่ล้นหน้า · ตารางยาวขึ้นหน้าใหม่ไม่ตัดกลางแถว
4. ฉบับร่างพิมพ์แล้วมีลายน้ำ "ร่าง · ห้ามใช้ผลิต"

### A10. แก้พร้อมกัน
- เปิดร่างเดียวกัน 2 เบราว์เซอร์ (บัญชี admin เดียวกัน 2 เครื่อง หรือ Chrome + Chrome โหมดไม่ระบุตัวตน) → เครื่อง 1 บันทึก → เครื่อง 2 แก้แล้วบันทึก **ต้องถูกปฏิเสธ** ("มีคนบันทึก… โหลดใหม่") · ข้อมูลของเครื่อง 1 ไม่หาย · กดโหลดใหม่แล้วเห็นของเครื่อง 1

### A11. เน็ต / ความเร็ว / ผิดพลาด
1. ปิดเน็ต (DevTools → Offline) แล้วกดบันทึก / อัปโหลด / อนุมัติ → ข้อความไทยบอกให้ต่อเน็ต · งานที่ยังไม่บันทึกไม่หาย
2. `#/mockup?id=ไม่มีจริง` และ `#/mockup?id=` ว่าง → ขึ้น "ไม่พบงานนี้" ไม่จอขาว
3. จับเวลาโหลดหน้าม็อคอัพ / บันทึกร่าง 10 จุด / อนุมัติ (บนเน็ตโรงงานหรือมือถือ 4G)
4. Console ไม่มี error สีแดงตลอดการทดสอบ (แนบภาพถ้ามี)

### A12. เข้าถึงไฟล์โดยไม่มีสิทธิ์ (พิมพ์ URL ในช่องที่อยู่เท่านั้น)
1. คลิกขวาภาพม็อคอัพ → คัดลอกที่อยู่ภาพ → **ออกจากระบบ** → เปิดที่อยู่นั้น: จดว่ายังเปิดได้หรือไม่ (ลิงก์ชั่วคราวมีอายุ 12 ชม. = คาดว่ายังเปิดได้จนหมดอายุ · จดไว้เป็นข้อสังเกต)
2. ตัดส่วน `?token=…` ออกจากที่อยู่ภาพ แล้วเปิด → **ต้องเปิดไม่ได้**
3. เปลี่ยน `/sign/` ในที่อยู่เป็น `/public/` แล้วเปิด → **ต้องเปิดไม่ได้**
