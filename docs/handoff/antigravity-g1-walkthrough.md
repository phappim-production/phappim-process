## ทดสอบอะไร (ผลจริง)
- ทดสอบบน `http://localhost:5174/` (จาก commit `7d7b92c` เชื่อมต่อฐานข้อมูลจริง) ด้วยบัญชีทดสอบ `@pp142.test` 4 บทบาท (`production`, `admin`, `qc`, `manager`)
- สร้างงานทดสอบ `TEST-N1` (ปกติ), `TEST-D1` (DTF), `TEST-P1` (ไม่พิมพ์) พร้อมอัปโหลด PDF
- เดินงาน `TEST-N1` ครบตั้งแต่รับงาน → ติ๊กวัตถุดิบ 3 ฝ่าย → ตัวอย่างไม่ผ่านรอบ 1 → ตัวอย่างผ่านรอบ 2 → พิมพ์/รีด/ตัด → เย็บ (รายงานปัญหา/พักงาน/เย็บต่อ/เย็บเสร็จ) → QC ส่งกลับแก้ 5 ตัว → เย็บแก้ → QC ผ่านถึง `เสร็จ / พร้อมส่ง` → ค้นหา SC และลองเปิด PDF
- ทดสอบกติกาบล็อก: ขึ้นตัวอย่างก่อนติ๊กวัตถุดิบครบ, จบสถานีก่อนติ๊กขั้นบังคับ, รีด DTF ก่อนได้รับฟิล์ม, สิทธิ์ `admin`/`manager` ดูได้อย่างเดียว, กด `เริ่มตัดงาน` พร้อมกัน 2 แท็บ (รับครั้งเดียว 204 / อีกแท็บได้ 400 พร้อมข้อความไทย)
- ทดสอบ Realtime 2 แท็บ (บัญชีเดียวกัน): อีกแท็บอัปเดตใน ~162–174 ms หลัง RPC เสร็จ
- ทดสอบหน้าจอ 375 / 768 / 1440 px (Login, Admin, Manager, Production, QC): ไม่มีหน้าล้นด้านข้าง, ปุ่มหลัก ≥ 48 px, ตัวอักษรหลัก ≥ 16 px (`17px`), console error = 0

## บั๊กที่เจอ (นอกขอบเขต G1 — ให้ Claude / ทีมโค้ดแก้ต่อ)
รายละเอียดเต็มและภาพหน้าจออยู่ใน [`docs/qa/รอบ-1.md`](../qa/รอบ-1.md):
1. **[ระดับ 1]** กด `เปิด PDF ใบยืนยัน` ได้ signed URL `200 OK` แต่ไม่เปิดแท็บ/ไม่ดาวน์โหลดและไม่มีข้อความแจ้ง
2. **[ระดับ 2]** ประวัติและหมายเหตุที่ตัวอย่างไม่ผ่านรอบ 1 ไม่แสดงในรายละเอียดงาน
3. **[ระดับ 2]** การ์ด KPI ไม่อัปเดตทันทีหลังรับงานใหม่
4. **[ระดับ 2]** แถวขั้นย่อยแบบ `กรอกค่า` ในแผงรายละเอียดบีบข้อความไทยแนวตั้ง 1–3 ตัวอักษรต่อบรรทัด
5. **[ระดับ 2]** กด `ออกจากระบบ` ค้าง URL ที่ `#/system` และ request logout ถูก abort (`net::ERR_ABORTED`)
6. **[ระดับ 3]** `QC + Packing` รอบ `ขึ้นตัวอย่าง` กดเสร็จได้โดยไม่บังคับติ๊กขั้นที่เขียนว่า `ต้องทำก่อนกดเสร็จ`
7. **[ระดับ 3]** ป้าย `"งานแก้"` ไม่แสดงบนการ์ดแท็บ `ต้องทำตอนนี้` และ `จักรเย็บ`
8. **[ระดับ 3]** คำซ้ำ `"ฝ่ายฝ่ายผลิต"`, เว้นวรรคหายก่อน `แล้ว`/`เสร็จ`, ข้อความภายใน `(S8)` / `.json` โผล่หน้าจอ
