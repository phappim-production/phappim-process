# ระบบทดสอบถาวร (`tools/qa-suite`)

รันในเครื่องเท่านั้น (`127.0.0.1:5244` / `5245`) · ฐาน PGlite + R2 จำลองจาก `tools/qa-r14` · ไม่แตะระบบจริง · ไม่เพิ่ม dependency
ต้องใช้ Node 24 ขึ้นไป (อ่านไฟล์ `.ts` ของหน้าเว็บตรงๆ: `proto/leadTime.ts` · `auth/menus.ts` · `auth/access.ts`)

## คำสั่ง

```powershell
node tools/qa-suite/run.mjs --quick                       # ก่อนเปิดทุก PR · ~2 นาที (รวม build)
node tools/qa-suite/run.mjs --full --seed 101             # ก่อนขึ้นจริงงานใหญ่ · ~10 นาที
node tools/qa-suite/run.mjs --only sim --seed 7 --days 20 --skip-build
node tools/qa-suite/prove.mjs                             # พิสูจน์ว่าชุดทดสอบยังจับบั๊กได้ · ~15 นาที
```

| ตัวเลือก | ความหมาย |
|---|---|
| `--quick` / `--full` | เร็ว: 5 วัน · 3 บทบาท · 2 ขนาดจอ · สุ่ม 6 สินค้า · เต็ม: 20 วัน · 10 บัญชี · 375/768/1440 · ทุกสินค้า · รวม `selftest` |
| `--only <ส่วน>` | `security` · `sim` · `confirmation` · `ui` · `selftest` |
| `--seed <n>` · `--days <n>` | seed เดิม = เหตุการณ์เดิม · จำนวนวันที่จำลอง |
| `--mutate <id>` | ใส่บั๊กทดสอบจาก `checks/mutations.mjs` ลงฐานจำลอง (ใช้กับ `prove.mjs`) |
| `--skip-build` | ข้าม build เมื่อ `app/dist` build ชี้ `127.0.0.1:5244` ไว้แล้ว |
| `--out <dir>` · `--compare <report.json>` | ที่เก็บผล (ค่าเริ่มต้น `%TEMP%\qa-suite\…`) · เทียบกับรอบก่อน |

ล้ม = exit code 1 · `report.md` บอกทุกข้อที่เจอ คำสั่งรันซ้ำ และ 15 ขั้นสุดท้ายก่อนล้ม · `actions.jsonl` = ทุกขั้นของการจำลอง

## แต่ละส่วนตรวจอะไร
- **security** · E1 ทุก RPC ใน `pg_proc` อยู่ใน `checks/rpc-policy.mjs` (และกลับกัน) · E2 anon เรียก RPC ไม่ได้ · E3 ด่าน `private.require_role` ใน SQL ตรงกับตาราง (เปิดสิทธิ์กว้างขึ้นใน SQL = ล้มจนกว่าจะแก้ตาราง) · E4–E5 เรียกทุก RPC ด้วยพารามิเตอร์ครบ × 14 บัญชี (รวมบัญชีปิด / ไม่มีบทบาท / anon) · E6 งานจริงที่สถานี: staff ต่างสถานี / ยังไม่จับคู่ / ผู้ควบคุมงานต่างเฟส ต้องได้ 42501 · E7 RLS ทุกตาราง + view เป็น `security_invoker` · E8 policy เขียนตรงมีเฉพาะตารางตั้งค่าและผูก `is_owner` · E10 เขียน/แก้/ลบ `jobs` `events` `job_materials` ตรงผ่าน REST ด้วยแถวที่ข้อมูลครบ ต้องไม่เปลี่ยนข้อมูล · E9 XSS
- **sim** · จำลองโรงงานทีละวัน: **เลื่อนวันจริง** (`lib/clock.mjs` ถอยทุกช่องวันที่ในฐาน 1 วันต่อรอบ เพราะเปลี่ยน `now()` ของฐานไม่ได้) → เวลาผลิตเดิน เลยกำหนด ต้องรายงานสาเหตุ กล่องจดหมายเตือนจริง · รับงานทุกเส้นทาง + ใบงานบริการ 5 แบบ + ตัวอย่าง/Develop · รอผลิต: เพิ่มวัตถุดิบพร้อมวันที่ เลื่อนวัน ติ๊ก ถ่ายรูป ปล่อย · ส่งออกจากรอผลิต · แบ่งงาน · ฟิล์ม · ปัญหา/เย็บต่อ · QC · จัดส่ง · 2 คนกดปล่อยพร้อมกัน · กดผิดกฎต้องถูกปฏิเสธ · **ทุกคำสั่งต้องสำเร็จ** ยกเว้นเครื่อง/จักรเต็ม · หลังทุกขั้นรันข้อตรวจข้อมูล B1–B11 (`checks/invariants.mjs`)
- **ข้อตรวจข้อมูล** · B1 events ไม่ถูกแก้/ลบ · B2 phase/สถานี/สถานะสอดคล้อง · B3 คิวไม่ซ้ำ · B4 จำนวน + QC ไม่เกิน · B5 `job_sla_flags` = `proto/leadTime.ts` (วันครบ ส้ม แดง · นับจากวันปล่อย · งานแบ่งใช้จำนวนทั้งครอบครัว) · B6 เครื่อง/จักร · B7 ใบแก้ · B8 วัตถุดิบ (ปล่อยแล้วต้องติ๊กครบ + มีรูป ยกเว้นส่งออกจากรอผลิต) · B9 ไฟล์อยู่ใน R2 + ไม่มี base64 · B10 จดหมายไม่ซ้ำ · B11 เกินเวลาผลิต / รอผลิตเกิน 2 วันทำงาน ต้องมีจดหมาย · `selftest` ทำข้อมูลเสียทีละข้อแล้วต้องจับได้ครบ 11 ข้อ
- **confirmation** · ใช้ `validate()` ของฟอร์มเอง: ปกสำเร็จต้องมีสีปก · ผ้าเพิ่มต้องมีจำนวน > 0 + หน่วย · กรอกค่าทดสอบทุกช่องข้อความของทุกสินค้า แล้วเทียบ **ฉบับลูกค้าต้องไม่มีช่องภายใน** / ฉบับโรงงานต้องมีครบ · เลขที่ใบซ้ำกับงานที่รับแล้ว · วันที่ infinity
- **ui** · ทุกเมนูของแต่ละบทบาทจาก `auth/menus.ts` + ลิ้นชักงาน × ขนาดจอ: กว้างเกินจอ ของล้นขวา หน้าเลื่อนทั้งหน้า NaN/undefined จอขาว error อังกฤษ console error (ตรวจก่อนว่าตัวจับ console ทำงาน) · บทบาท staff/QC/ผู้ควบคุมงาน: ปุ่มหลัก ≥ 48 px · ทุกหน้าที่ `canOpenPage` ไม่ให้ ต้องขึ้น "เปิดหน้านี้ไม่ได้" · ออฟไลน์

## เพิ่ม / แก้
- RPC ใหม่ → เพิ่มใน `checks/rpc-policy.mjs` (`gate` = อาร์กิวเมนต์ของ `require_role` ตัวแรก หรือ `scope`)
- กฎใหม่ → ข้อตรวจใน `checks/invariants.mjs` + กรณีใน `runInvariantSelfTests` · ขั้นใหม่ใน `parts/sim.mjs` ใช้ `must()` (ห้ามปล่อยผลเรียกทิ้ง) และ `rejected()` สำหรับกรณีที่ต้องถูกปฏิเสธ
- บั๊กที่แก้แล้ว → เพิ่มใน `checks/mutations.mjs` (ใส่บั๊กกลับ + ข้อความที่ต้องจับได้) แล้วรัน `prove.mjs --only <id>`

## ข้อจำกัด
- ฐานจำลองเป็น PGlite การเชื่อมต่อเดียว · "กดพร้อมกัน" ถูกเรียงคิวในเครื่อง ไม่ใช่ transaction ชนกันจริง (ใช้ `tools/load-test/race.mjs` กับ Postgres จริง)
- ไม่มี Realtime · ไม่ได้ตรวจภาพ PDF / ฟอนต์จริง · ไม่ได้ตรวจคำแปลพม่า (ใช้ `app/src/i18n/lang.test.ts`)
- เลื่อนวันด้วยการถอยข้อมูล: ข้อความในกล่องจดหมายที่มีวันที่ในคีย์ (`mat:<id>:<วันที่>`) ใช้วันที่จริงวันเดียว จึงเห็นจดหมายรายวันซ้ำไม่ได้
