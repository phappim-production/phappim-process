## 1. ขั้นย่อยของแต่ละสถานี
สัญลักษณ์: **[บังคับ]** ต้องติ๊กก่อนกดเสร็จ · **[ตัวเลข]** ต้องกรอกค่า · **[อนุมัติ]** ต้องมีคนอนุมัติ · **[ล็อก]** รอเงื่อนไข

| สถานี | ขั้นย่อยตอนนี้ | ถูกต้อง? / แก้เป็น |
|---|---|---|
| พิมพ์งาน | เตรียมไฟล์ → เตรียมเครื่อง → พิมพ์ → ตรวจงานพิมพ์ [บังคับ] | ☐ ถูก ☐ แก้: |
| รีดงาน | ตั้งอุณหภูมิ → รีด → ตรวจสีและการติด [บังคับ] | ☐ ถูก ☐ แก้: |
| ตัดงาน | วางแพทเทิร์น → ตัด → คัดแยกชิ้นและนับ [ตัวเลข] | ☐ ถูก ☐ แก้: |
| **รีด DTF (ร่าง)** | ได้รับฟิล์ม [ล็อก] → ตั้งอุณหภูมิ → วางฟิล์มตามตำแหน่ง → รีด → ลอกฟิล์ม → ตรวจการติด [บังคับ] | ☐ ถูก ☐ แก้: |
| **งานปัก (ร่าง)** | เตรียมไฟล์ปัก/ตั้งเครื่อง/เตรียมด้าย → ปักชิ้นทดสอบ [อนุมัติ] → ปักทั้งก้อน → ตรวจงานปัก [บังคับ] | ☐ ถูก ☐ แก้: |
| **ซิลค์สกรีน (ร่าง)** | ทำบล็อก → ผสมสี → สกรีนชิ้นทดสอบ [อนุมัติ] → สกรีนทั้งก้อน → อบ/รีดให้สีติด → ตรวจ [บังคับ] | ☐ ถูก ☐ แก้: |
| เย็บงาน | จ่ายงานเข้าเย็บ [บังคับ] → ตัวแรก [อนุมัติ] → เย็บทั้งก้อน [ตัวเลข ยอดสะสม] → เก็บงานปลายไลน์ [บังคับ] | ☐ ถูก ☐ แก้: |
| QC + Packing | ตรวจ ผ่าน/ไม่ผ่าน [ตัวเลข] → นับ [ตัวเลข] → พับ/แพ็ค → ติดป้าย → ลงลัง [บังคับ] | ☐ ถูก ☐ แก้: |
