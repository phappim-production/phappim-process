## ยังไม่ได้แก้ / ให้เจ้าของตัดสิน
- **ยกเลิกส่วนที่แบ่งใบ ทำให้เวลาผลิตงานแม่หดย้อนหลัง:** งาน 600 ชิ้น (15 วัน) แบ่ง 300 แล้วยกเลิกส่วนนั้น → เหลือ 300 = 10 วัน งานที่ทันอยู่กลายเป็น "เกิน" ทันที ต้องรายงานก่อนปิดงาน · กฎตอนนี้ "ส่วนที่ยกเลิกไม่นับ" ตั้งใจไว้ตอนทำเวลาผลิต จึงไม่เปลี่ยนเอง
- **ข้อความ "พักงานแล้ว · เวลาที่พักไม่นับเป็นเวลาทำงาน":** จริงสำหรับเวลาที่สถานี แต่เวลาผลิตทั้งงาน (10/15/20 วัน) ยังนับช่วงพัก · จะเปลี่ยนคำไหม
- ใบแก้ "ครั้งที่เดียวกัน" ที่ 2 แท็บกดพร้อมกันยังทับกันได้ (ข้อ 3 กันเฉพาะเมื่อมีใบครั้งใหม่กว่า)
- ยังไม่ยืนยัน: ฟอร์มหลายแท็บใช้พื้นที่เก็บเดียวกัน (แท็บที่บันทึกล่าสุดชนะ) · ลิงก์รูปจากระบบหมดอายุ 1 ชม. ถ้าเปิดฟอร์มค้างนาน · วันที่ "infinity" ผ่านได้ถ้าเรียก API ตรง (หน้าเว็บส่งไม่ได้) · QC ส่งรายงานล่าช้าได้ทุกสถานี · `decide_first_piece` ล็อกงานแม่/ลูกคนละตัว (ฟีเจอร์รูปยังปิด)
- ประเด็น UX 8 จุดจาก B1 ไม่ใช่หน้าล้นจริง: ลิ้นชักรายละเอียดงานวัดระหว่างแอนิเมชันเลื่อนเข้า · แถบสถานีบนบอร์ดตั้งใจยื่นชนขอบจอ (หน้าไม่เลื่อนข้าง)
