## รายการตรวจ
| ข้อ | บทบาท | ทำ | ต้องเห็น |
|---|---|---|---|
| 1 ★ | admin (มือถือ) | กรอก `/confirmation` → **บันทึกเข้าระบบ** (ลองทั้ง Chrome มือถือ และเบราว์เซอร์อื่นถ้ามี) | **มีแท็บระบบเปิดขึ้น 1 แท็บ** · ไม่มีกล่องแดง "ไม่พบใบ" · ถ้าแท็บระบบไม่เปิด ต้องเห็นลิงก์ "กดเปิดหน้าระบบ" · กดแล้วไม่เกิดแท็บซ้ำ |
| 2 | production · qc | ล็อกอินใหม่ | **เปิดมาเจอบอร์ด** · เลือกสถานีแล้วออก-เข้าใหม่ → เข้าหน้าคิวสถานีเดิม |
| 3 | production | พัก `TEST-R6-A` ที่หน้าคิว (มีสาเหตุ) | การ์ดแดง "พักงาน" · ฝ่ายผลิตเห็นปุ่ม "แก้แล้ว ทำต่อ" |
| 4 | admin · qc | เปิด `TEST-R6-A` ที่หน้าคิว / รายละเอียดงาน | **ไม่มีปุ่ม "แก้แล้ว ทำต่อ"** · เห็น "รอผู้บริหารหรือฝ่ายผลิตกด" · ภาพรวมแอดมินขึ้น "ติดปัญหา · รอผู้บริหารแก้" |
| 5 ★ | manager | หน้าคิวสถานี / รายละเอียดงาน `TEST-R6-A` → **แก้แล้ว ทำต่อ** | ผู้บริหารกดได้ · งานกลับสถานะเดิม · ประวัติบันทึกชื่อผู้บริหาร |
| 6 | qc | `TEST-R6-C` ถึง QC + Packing → เริ่ม → พักงาน | QC **กดทำต่อเองไม่ได้** (เห็นข้อความรอใคร) · production หรือ manager กดได้ |
| 7 | admin → production | ส่ง `TEST-R6-B` ไป**เย็บข้างนอก** → ฝ่ายผลิตเปิด **จักรเย็บ → รอเย็บ** | **`TEST-R6-B` ไม่อยู่ในรอเย็บ** · อยู่ส่วน "ส่งออกข้างนอก" ของหน้าคิวเย็บ |
| 8 | **ประสานกับ Claude** | เมื่อ `TEST-R6-A` กำลังทำที่สถานีใดก็ได้ แจ้งเจ้าของโปรเจกต์ → Claude ย่อเวลามาตรฐานสถานีนั้นชั่วคราว (เตือนที่ ~24 นาที · เกินที่ ~29 นาที เพราะระบบนับ 1 วัน = 24 ชม.) | **การ์ดบนบอร์ด / หน้าคิว / ต้องทำตอนนี้ เปลี่ยนเป็นส้มแล้วแดงเอง ไม่ต้องรีเฟรช** (ภายใน 5 นาที) · ภาพรวมผู้บริหารขึ้น "เกินเวลามาตรฐาน · ยังไม่ส่งรายงานปัญหา" · แถบในรายละเอียดบอกเป็นชั่วโมง ไม่ใช่ "0.0" · รายงานแล้วกดเสร็จได้ · **แจ้ง Claude คืนค่าทันที** |
| 9 | admin | แนบ PDF ใบยืนยันทีหลัง (ไฟล์ PDF ทดสอบ) | ปุ่ม **"เลือกไฟล์"** ภาษาไทย · เลือกไฟล์เดิมซ้ำได้ |
| 10 ★ | production | เย็บในโรงงาน: เริ่มเย็บ → รายงานปัญหาแบบพัก → ดูแท็บ **จักรเย็บ → งานเย็บ** | **ไม่มีแถบเลื่อนแนวนอนที่ 375 px** · "เย็บต่อ" ใช้ได้ |
| 11 | production | กด "เริ่มก่อนคิว" แล้วกดปุ่มการ์ดถัดไปทันทีขณะข้อความเขียวยังขึ้น | **กดปุ่มใต้ข้อความเขียวได้** ไม่ถูกบัง |
| 12 ★ | ทุกบทบาท | **ซ้อมวันจริง 30 นาที**: admin รับงาน → production เดินพิมพ์ถึงเย็บ → qc ผ่านครบ → manager ดูภาพรวม/รายงาน · 2 คนใช้ production พร้อมกันคนละเครื่อง | ไม่มีขั้นที่ติด · ตัวเลขภาพรวมตรงหน้าคิว · จดทุกจุดที่ช้า/งง |
