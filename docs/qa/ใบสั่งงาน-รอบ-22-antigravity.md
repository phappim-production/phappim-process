## ⛔ ห้ามแตะระบบจริงเด็ดขาด
ระบบใช้งานจริงอยู่ มีงานจริงและทีมจริง · **ห้ามเปิด เรียก หรือล็อกอิน** `pp142.pages.dev` · `*.supabase.co` · `*.workers.dev` · R2 จริง · ห้ามใช้บัญชีของระบบจริง · ห้ามอ่านโฟลเดอร์ `.pp142-r2` · ทุกอย่างรันบน `127.0.0.1` เท่านั้น

- build แบบ loopback ทุกครั้ง (`npm run build` เฉยๆ จะชี้ระบบจริง):
  ```powershell
  npm.cmd --prefix app ci; npm.cmd --prefix supabase\tests ci; npm.cmd --prefix workers\files ci
  $env:VITE_SUPABASE_URL = 'http://127.0.0.1:5254'
  $env:VITE_SUPABASE_ANON_KEY = 'r14-local-anon-key'
  $env:VITE_FILES_URL = 'http://127.0.0.1:5255'
  ```

2. แต่ละข้อมี: รหัส `R22-xx` · ระดับ · บทบาท · ขนาดจอ · ขั้นตอนทำซ้ำแบบสั้นที่สุด (คนอื่นทำตามได้) · ผลที่เห็น · ผลที่ควรเป็น (อ้างคู่มือ / `api-workflow.md` / `AGENTS.md`) · ภาพหน้าจอหรือ log · ถ้าทำซ้ำด้วยสคริปต์ได้ ใส่คำสั่ง 1 บรรทัด
3. **ห้ามอ้างผลที่ไม่ได้ตรวจจริง:** ห้ามเขียน "ผ่าน 100%" หรือ "ครอบคลุมทุกอย่าง" · ทุกส่วนให้ทำตาราง **ตรวจอะไร · ด้วยวิธีไหน (มือ / สคริปต์) · ผล** · ส่วนที่ไม่ได้ทำให้เขียนว่าไม่ได้ทำและเพราะอะไร
4. ข้อที่ล้มเพราะสคริปต์ล้าสมัย ไม่ใช่บั๊กของระบบ ให้แยกตาราง
5. **ไม่ต้องรายงานซ้ำ (รู้แล้ว):** ระบบจำลองไม่มี Realtime (แถบขาดการเชื่อมต่อ / console error WebSocket) · ฐานจำลองเป็นการเชื่อมต่อเดียว (กดพร้อมกันถูกเรียงคิว) · ระบบไม่มีเวลาส่ง (มีแต่วันที่) และสรุปส่งไลน์ไม่มี "หักตัวอย่าง / คงเหลือ" · งานที่รับโดยไม่ใช้ฟอร์มสรุปส่งไลน์ไม่ได้ · ไม่มีปุ่มย้อนสถานะงาน · รายงานแผนกยังเป็นทั้งโรงงาน · กล่องจดหมายไม่ส่งถึง `staff` · `staff` เย็บไม่ได้ · R20-05 · สูตรจักรของหมวก/หมอนยังไม่มี (เจ้าของเลื่อนไปหลังใช้งาน) · ฟอนต์ Noto ใน PDF · สี "รอคิว" · การ์ดงานบนมือถือสูง ~670 px · ฟอร์มเสื้อพละเตือนเลือกชนิดปกเมื่อเลือกคอปก (ตั้งใจ) · ข้อจำกัดใน `docs/ส่งต่องาน-Claude.md` หัวข้อ "เรื่องค้าง / ข้อจำกัดที่รู้"
