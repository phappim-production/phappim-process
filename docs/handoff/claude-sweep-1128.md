## ยังไม่ได้ทำ / ต้องถามเจ้าของ
- **งานแก้ที่ QC ส่งกลับรีดฟิล์ม ของงานที่บริษัทภายนอกรีดรอบแรก** เริ่มรีดที่โรงงานไม่ได้ ("ยังไม่ได้รับฟิล์ม") จนกว่าแอดมินบันทึกสั่ง + ได้รับฟิล์ม · ถามเจ้าของ: บริษัทจัดฟิล์มเองหรือโรงงานส่งฟิล์มให้ (ตัดสินแล้วค่อยแก้ `start_station`)
- งานที่อยู่ข้างนอกที่รีดฟิล์มแต่ยังไม่บันทึกสั่งฟิล์ม ยังขึ้น "ยังไม่ได้สั่งฟิล์ม" (คำถามเดียวกับข้อบน)
- `attach_confirmation_pdf` ไม่ตรวจว่าไฟล์อยู่โฟลเดอร์ของงานนี้ (แอดมินเรียก RPC ตรงแนบไฟล์ของงานอื่นที่มีจริงได้) · หน้าเว็บตั้งชื่อถูกเสมอ · ไม่แก้รอบนี้เพราะชุดทดสอบเก่า 3 ชุดใช้ไฟล์ร่วม ความเสี่ยงต่ำ
- ยังไม่ยืนยัน: ใบแก้เปลี่ยนจำนวนตอนงานอยู่ข้างนอก จำนวนในรอบส่งออกยังเป็นเลขเดิม · งานอยู่ข้างนอกที่รีดฟิล์มกด "เริ่ม" ได้ข้อความเรื่องฟิล์มแทน "อยู่ที่บริษัทภายนอก" (ถูกบล็อกอยู่แล้ว)
- ใบ Artwork ที่ QC เปิดได้ยังไม่มีภาษาพม่า · `lang.test.ts` ไม่จับข้อความที่ส่งผ่าน prop / มาจาก Worker
- อ่านฐานจริง (นับจำนวน) ไม่ได้ในรอบนี้: ระบบสิทธิ์ปฏิเสธ `execute_sql` · ข้อที่ควรดูเมื่อมีสิทธิ์: งาน UV DTF ที่หน่วยไม่ตรงใบ (ใบแก้จะถูกปฏิเสธ) · งานที่ส่งรีดฟิล์มออกไปแล้ว
