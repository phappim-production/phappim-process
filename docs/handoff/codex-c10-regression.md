## งานค้างสำหรับ Claude

- **ระดับ 1** คำขอเสร็จจากสถานีเก่าข้ามสถานีที่กำลังทำ ยอด QC เดิมซ้ำปิดงานก่อนตรวจครบ และคำสั่งแบ่งงานเดิมซ้ำสร้างใบลูกเกิน แจ้งเจ้าของโปรเจกต์ในแชตแล้ว

- การแก้โค้ดหน้าเว็บและ migration อยู่ในงานของ Claude รอบนี้ส่งทดสอบที่ล้มพร้อมผลจริงเพื่อใช้ตรวจหลังแก้ นอกใบสั่งงานพบว่าทดสอบเวลา queue.test.ts เกินเกณฑ์ 300 ms หนึ่งครั้งเมื่อรันพร้อม build/PGlite และผ่านเมื่อรันแยก ส่วน advisory ของ `npm ci` ยังไม่ได้ตรวจรายละเอียด
