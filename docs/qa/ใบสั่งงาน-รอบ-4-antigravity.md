## ทำไม
18 พ.ย. เจ้าของสั่ง "งานเรียงตามคิว อย่ามั่วคิวเด็ดขาด · งานด่วนให้แทรกงาน" (PR 52) และปรับหน้าจอให้คนหน้างานใช้มือถือส่วนตัว (PR 52 · 53) · ต้องมีคนลองเหมือนผู้ใช้จริงทุกบทบาทก่อนวันทดลอง ส. 21

## สิ่งที่เปลี่ยน (อ่านก่อน)
- **คิว:** ทุกงานเรียงตามลำดับที่แอดมินรับเข้า ไม่ใช่ตามกำหนดส่ง · งานเลยกำหนดเป็นสีแดงแต่ **ไม่แซงคิว**
- **หน้างาน → บอร์ด → กดสถานี** = หน้าคิวของสถานี: "กำลังทำ" (ปุ่ม เสร็จ / แก้แล้ว ทำต่อ) + "คิวรอเริ่ม" (ป้าย คิว 1, 2, 3…) · คิว 1 ได้ปุ่มใหญ่ "เริ่ม…" · คิวอื่น "เริ่มก่อนคิว" (ต้องใส่เหตุผล) · "แทรกเป็นคิวแรก (งานด่วน)" (ต้องใส่เหตุผล)
- **ใครแทรกคิวได้:** ฝ่ายผลิต · ผู้บริหาร · เจ้าของ · **แอดมิน / QC ไม่ได้** · เริ่มก่อนคิว: ฝ่ายผลิต (QC เฉพาะ QC + Packing)
- **ภาพรวม (แอดมิน/ผู้บริหาร):** การ์ด "สถานีตอนนี้" ต่อสถานี (กดแล้วไปคิวสถานีนั้น) · "งานที่ต้องตาม" มี "คาดไม่ทัน X วัน"
- PDF ที่ลูกค้าเซ็นไม่บังคับแล้ว (รับงานได้โดยไม่แนบ) → ไม่ติดปัญหาอัปโหลดแบบรอบ 3
