# แผน: รูปชิ้นแรก + รูปงานเสร็จ ทุกสถานี

เป้าหมาย: จับงานผิดตั้งแต่ชิ้นแรก ก่อนทำทั้งล็อต และมีรูปหลักฐานทุกสถานีให้ย้อนดูได้ว่าผิดที่ไหน

## 1. กติกาที่เจ้าของตัดสินแล้ว (24 พ.ย.)

| เรื่อง | ตัดสิน |
|---|---|
| ล็อกชิ้นแรก (ต้องรออนุมัติก่อนทำทั้งล็อต) | พิมพ์งาน · รีดงาน · รีดฟิล์ม DTF · ตัดงาน · ปัก · ซิลค์สกรีน |
| ไม่ล็อกชิ้นแรก | เย็บงาน · QC + Packing |
| รูปงานเสร็จ | **ทุกสถานี** อย่างน้อย 1 รูป ถึงจะกด "เสร็จ" ได้ ไม่ต้องรออนุมัติ |
| ผู้อนุมัติชิ้นแรก | แอดมิน · ผู้จัดการ |
| รอนานเกิน 15 นาที | เด้งเตือนผู้จัดการ + ฝ่ายผลิตในกล่องข้อความ (ไม่ปล่อยผ่านเอง) |

## 2. ลำดับงานที่สถานี

```
กดเริ่ม ─▶ ทำชิ้นแรก ─▶ ถ่ายรูปชิ้นแรก ─▶ [รออนุมัติ]
                                          ├─ ผ่าน ─▶ ทำทั้งล็อต ─▶ ถ่ายรูปงานเสร็จ ─▶ กดเสร็จ
                                          └─ ไม่ผ่าน + เหตุผล ─▶ แก้ แล้วถ่ายชิ้นแรกใหม่
```

สถานีที่ไม่ล็อกชิ้นแรก: กดเริ่ม ─▶ ทำงาน ─▶ ถ่ายรูปงานเสร็จ ─▶ กดเสร็จ

- ใช้กับทั้งงานตัวอย่างและงานผลิตจริง และ **งานส่งแก้ (rework) ต้องผ่านชิ้นแรกใหม่ด้วย**
- ทุกรอบที่เข้าสถานี (visit) นับใหม่ รูปรอบก่อนใช้แทนไม่ได้
- ระหว่างรออนุมัติ **หยุดนับเวลา SLA** ของสถานี (เหมือนตอนพักงาน) พนักงานจะไม่โดนเกินเวลาเพราะรอแอดมิน
- งานที่ "กำลังทำ" อยู่ตอนเปิดใช้ ไม่โดนกฎใหม่ (กฎนับเฉพาะรอบที่กดเริ่มหลังเปิดใช้) กันงานค้างกลางสาย

## 3. ฐานข้อมูล (migration ใหม่ 1 ไฟล์)

- ตาราง `station_checks` : งาน · สถานี · รอบ (visit) · ชนิด (`first_piece` / `finish`) · รูป (path ใน R2) · สถานะ (`pending` / `approved` / `rejected` / `recorded`) · เหตุผลที่ไม่ผ่าน · ใครส่ง/ใครตัดสิน/เวลา · เขียนผ่าน RPC เท่านั้น
- คอลัมน์ `stations.first_piece_check` (เปิด/ปิดต่อสถานี ตั้งค่าได้ในหน้าตั้งค่า) + วันเวลาเปิดใช้ฟีเจอร์
- RPC ใหม่
  - `submit_first_piece(job, paths, note)` — พนักงานสถานี (supervisor/qc) · ต้องกดเริ่มแล้ว · ส่งซ้ำได้หลังไม่ผ่าน
  - `decide_first_piece(check, approve, reason)` — แอดมิน/ผู้จัดการ · ไม่ผ่านต้องมีเหตุผล
  - `add_finish_photos(job, paths)` — พนักงานสถานี
- แก้ `finish_station` : ปฏิเสธถ้า (ก) สถานีล็อกชิ้นแรกแต่ยังไม่ได้อนุมัติ "ชิ้นแรกยังไม่ได้รับอนุมัติจากแอดมิน รออนุมัติก่อนกดเสร็จ" (ข) ไม่มีรูปงานเสร็จ "ถ่ายรูปงานเสร็จอย่างน้อย 1 รูปก่อนกดเสร็จ"
- ทุกการกระทำบันทึกใน `events` : `first_piece_sent` · `first_piece_ok` · `first_piece_rejected` · `finish_photo`
- เวลา SLA : นับช่วงรออนุมัติเป็นเวลาหยุด (เพิ่มเข้า `sla_state` แบบเดียวกับ `hold_days`)
- กล่องข้อความ : ส่งชิ้นแรก → แจ้งแอดมิน/ผู้จัดการ · ไม่ผ่าน → แจ้งสถานี · `inbox_scan()` เด้งเตือนเมื่อรอเกิน 15 นาที (นับเฉพาะเวลาทำงาน)
- ทดสอบใน `supabase/tests/run.mjs` ทั้งกรณีผ่านและถูกปฏิเสธ ของทุกกฎข้างบน

## 4. ที่เก็บรูป (R2 ที่ใช้อยู่)

- เพิ่มชนิดไฟล์ `station_photos` ใน `check_file_upload` / `file_read_allowed` · ให้ supervisor/qc อัปโหลดได้ (ตอนนี้แอดมินเท่านั้น)
- path : `<job>/<station>/<visit>/<สุ่ม>.jpg`
- ย่อรูปในเครื่องก่อนส่ง (ด้านยาว ~1600 px, JPEG) ไม่เพิ่ม dependency · รูปละ ~300 KB ส่งผ่านเน็ตมือถือได้เร็ว
- แก้ Worker `workers/files` ให้รับชนิดใหม่ แล้ว deploy Worker ใหม่

## 5. หน้าจอ

1. **หน้าสถานี (พนักงาน, ภาษาพม่า+ไทย)** การ์ดงานที่กำลังทำมี 2 ขั้น: "ถ่ายรูปชิ้นแรก" → สถานะ รออนุมัติ (ส้ม) / ผ่าน (เขียว) / ไม่ผ่าน + เหตุผล (แดง) · "ถ่ายรูปงานเสร็จ" · ปุ่มกดเสร็จบอกเหตุผลถ้ายังกดไม่ได้ · ปุ่มถ่ายรูปเปิดกล้องหลังทันที สูง ≥ 48 px
2. **คิวอนุมัติชิ้นแรก (แอดมิน/ผู้จัดการ)** อยู่บนสุดของหน้างานแอดมิน + ตัวเลขบนกระดิ่ง · เรียงตามเวลารอ (เกิน 15 นาที = แดง)
3. **หน้าอนุมัติ** รูปชิ้นแรกวางข้างม็อคอัพของงาน (สเปกจากหน้าม็อคอัพ) · ปุ่ม "ผ่าน" / "ไม่ผ่าน" (ต้องพิมพ์หรือเลือกเหตุผล)
4. **ประวัติงาน** แสดงรูปทุกสถานีเรียงตามเวลา
5. **ตั้งค่า** เปิด/ปิดล็อกชิ้นแรกต่อสถานี

## 6. ลำดับทำ + ส่งมอบ

1. migration + ทดสอบฐานข้อมูล
2. Worker รับชนิดไฟล์ใหม่ + ทดสอบ Worker
3. หน้าสถานี + คำแปลพม่า
4. คิว/หน้าอนุมัติของแอดมิน + ประวัติ + ตั้งค่า
5. ทดสอบครบวงจรในเครื่อง (375 / 768 / 1440 px) ด้วยบัญชีทดสอบในเครื่อง ไม่แตะเว็บจริง
6. อัปเดตคู่มือ (ฝ่ายผลิต / แอดมิน / ผู้บริหาร / แผนอบรม)
7. เปิด PR → เจ้าของอนุมัติก่อน merge → ลง migration จริง + deploy Worker → เปิดใช้

## 7. ค่าที่ใช้ไปก่อน (เจ้าของเปลี่ยนได้)

- สถานี **"สั่งผลิตข้างนอก"** ยกเว้น ไม่ต้องส่งรูป (ไม่มีพนักงานในสถานี · แอดมินรับของกลับเข้า QC ซึ่งต้องถ่ายรูปงานเสร็จอยู่แล้ว)
- เหตุผล "ไม่ผ่าน" เลือกจากรายการ (สีเพี้ยน · ตำแหน่งผิด · ขนาดผิด · ผิดแบบ / ผิดไฟล์ · งานไม่เรียบร้อย) + พิมพ์เพิ่มได้ · พนักงานพม่าเห็นเหตุผลที่เลือกเป็นภาษาพม่า
- นอกเวลางาน / วันอาทิตย์ ใช้ผู้อนุมัติชุดเดิม (แอดมิน + ผู้บริหาร) · เตือนเมื่อรอเกิน 15 นาที นับเวลาจริง
