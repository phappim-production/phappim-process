### ข้อสังเกต #2: ตัวเลขบนการ์ด `"สถานีตอนนี้"` (หน้าภาพรวม) ไม่เท่ากับปุ่ม `"เลือกสถานี"` (หน้าบอร์ด) เมื่อมีงานตัวอย่าง
- **ระดับ:** 3 (สับสนเมื่อสลับดูระหว่างหน้าภาพรวมกับหน้าเลือกสถานี)
- **บทบาท / ขนาดจอ:** `manager@pp142.test`, `production@pp142.test` / ทุกขนาดจอ

## 3. ข้อเสนอการใช้งาน: จุดที่ "ใช้ยาก / เข้าใจยาก" สำหรับคนหน้างานที่ไม่ถนัดเทคโนโลยี (เรียงตามผลกระทบ)

1. **ป้ายแจ้งเตือนหลังกดปุ่มอยู่บนสุดของหน้า — เลื่อนลงมาล่างๆ แล้วมองไม่เห็นว่ากดติดหรือกดชนกัน**
   - เมื่อคนหน้างานเลื่อนจอ `375 px` ลงมาที่ `"คิวรอเริ่ม"` (คิว 2–5) หรือการ์ดล่างๆ แล้วกด `"แก้แล้ว ทำต่อ"` / `"เริ่มตัดงาน"` แล้วเกิดกดชนกับเพื่อน ป้ายผลลัพธ์/แจ้งเตือนสีเขียว-แดงจะโผล่ด้านบนสุดเหนือ `"กำลังทำ"` ([ภาพ](img/r4-ag-12-concurrent-start.png)) คนหน้างานที่เลื่อนจออยู่ด้านล่างจะไม่เห็นว่าเกิดอะไรขึ้นจนกว่าจะเลื่อนกลับขึ้นบนสุด (ควรเด้งแจ้งเตือนใกล้ปุ่มที่กด หรือเลื่อนจอ/แสดง toast ด้านล่างให้เห็นทันที)
2. **หน้าเลือกสถานีไม่เลื่อนกลับขึ้นบนสุดหลังกดเลือกสถานี (ต่างจากตอนกดมาจากหน้าภาพรวม)**
   - เมื่อฝ่ายผลิตเลื่อนลงไปกดปุ่มสถานีที่อยู่ล่างๆ ในหน้า `"เลือกสถานี"` (เช่น `ตัด` หรือ `QC + Packing`) หน้าคิวของสถานีนั้นยังค้างตำแหน่งเลื่อนเดิมกลางหน้า ทำให้ไม่เห็นแถบ `"สถานี ตัดงาน · เปลี่ยนสถานี"` อยู่บนสุด (ควรเลื่อนกลับบนสุดอัตโนมัติเหมือนตอนกดจาก `"สถานีตอนนี้"` ของหน้าภาพรวม)
3. **งานที่ถูกกด `"เริ่มก่อนคิว"` ไม่มีป้ายบอกบนการ์ดว่าแซงคิวมา และต้องเข้าหน้ารายละเอียดเพื่อกด `"พักงาน"`**
   - หลังกด `"เริ่มก่อนคิว"` การ์ด `TEST-R4-B` ใน `"กำลังทำ"` แสดงแค่ `"กำลังทำ"` (เหตุผลดูได้เฉพาะในไทม์ไลน์) ส่วนการกด `"พักงาน / ติดปัญหา"` ต้องเปิดหน้ารายละเอียดงานแล้วกดปิดกลับมา ต่างจากปุ่ม `"…เสร็จ"` และ `"แก้แล้ว ทำต่อ"` ที่กดบนการ์ดได้เลย
4. **ตัวเลข `"สถานีตอนนี้"` กับ `"เลือกสถานี"` นับงานตัวอย่างคนละแบบ**
   - หน้าภาพรวมนับรวมงานตัวอย่างเข้าไปในสถานี (`ตัด 8`) แต่หน้าเลือกสถานีนับแยกเป็น `"ขึ้นตัวอย่าง"` (`ตัด 7`) ทำให้เวลาฝ่ายบริหารโทรถามหน้างานว่ามีกี่งานในสถานี ตัวเลขที่เห็นบนหน้าจออาจไม่ตรงกัน
5. **ฟอร์ม `"เริ่มก่อนคิว"` / `"แทรกเป็นคิวแรก"` บนการ์ดล่างๆ ขยายชนขอบเมนูด้านล่าง และแท็บภาพรวม `375 px` ตัดคำ**
   - เมื่อเปิดช่องใส่เหตุผลบนการ์ดท้ายๆ ของหน้าจอ `375 px` ปุ่มยืนยัน/ยกเลิกจะไปอยู่ชิดแถบเมนูด้านล่าง ต้องไถจอลงเพิ่มอีกนิดก่อนกด และบนหน้าภาพรวม 375 px แท็บ `"วางแผนรับงาน"` ถูกซ่อนอยู่หลังแถบเลื่อนแนวนอน
