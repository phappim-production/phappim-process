## ต้องทำ
### ก. ฐานข้อมูล (migration)
1. `public.owner_list_users()` → `table(user_id uuid, email text, created_at timestamptz, name text, role text, active boolean)` · `security definer` · `set search_path = ''` · **owner เท่านั้น** (ใช้ `private.require_role('owner')` · คนอื่น error ภาษาไทย) · รวมผู้ใช้ใน `auth.users` ที่ยังไม่มี profile ด้วย (name/role เป็น null)
2. revoke จาก `public, anon` · grant execute ให้ `authenticated`
3. ทดสอบใน `settings.mjs`: owner เห็นผู้ใช้ทุกคนรวมคนที่ยังไม่มี profile · production เรียกแล้วถูกปฏิเสธ · anon เรียกไม่ได้ · owner แก้ `stations.sla_days` ได้ · production แก้ไม่ได้ (แถวไม่เปลี่ยน) · owner ปิด kind ใน `inbox_settings` ได้ · production ปิดไม่ได้

### ค. พฤติกรรมที่ต้องมี
- **ล็อกอินและสิทธิ์เข้าหน้า A2 ทำไว้แล้วใน `App.tsx` ห้ามทำซ้ำ:** ยังไม่ล็อกอิน → `App.tsx` แสดงหน้าล็อกอินเอง · ไม่ใช่ owner → `App.tsx` แสดง "หน้านี้สำหรับเจ้าของระบบ" และไม่ render `SettingsPage` เลย (`canOpenPage` ใน `app/src/auth/access.ts`) · ดังนั้นหน้าตั้งค่า**ไม่ต้อง**ตรวจบทบาทเอง และห้ามเขียน hook อ่าน `profiles` ของตัวเองซ้ำ
- ต้องรู้ `user_id` ของตัวเอง (เพื่อห้าม owner ปิด/ลดบทบาทตัวเอง) → อ่านจาก `supabase.auth.getSession()` ครั้งเดียวในหน้า · ป้ายชื่อบทบาทภาษาไทยใช้ `ROLE_LABELS` จาก `app/src/auth/access.ts` (import ได้ ห้ามแก้ไฟล์นั้น)
- สิทธิ์จริงบังคับที่ฐานข้อมูล (RLS + `private.require_role`) · หน้าเว็บซ่อนปุ่มอย่างเดียวไม่พอ
- แก้แล้วกด **บันทึก** ทีละรายการ (ไม่บันทึกอัตโนมัติ) · ระหว่างบันทึกปุ่มกดซ้ำไม่ได้ · สำเร็จ = แจ้งสั้นๆ · ผิดพลาด = ข้อความภาษาไทยจาก error · มีการแก้ค้างแล้วจะออกจากแท็บ → ถามยืนยัน
- แสดง**คำเตือน**บนแท็บสถานี: "แก้ขั้นย่อยมีผลกับงานที่อยู่ในสถานีนั้นทันที (ขั้นที่เพิ่มใหม่จะต้องติ๊กก่อนกดเสร็จ)"
- ใช้ส่วนประกอบกลาง (`Card`, `CardHeader`, `Pill`, `TONE`, ไอคอนใน `icons.tsx`) · ปุ่มหลักสูง ≥ 48 px · ใช้ได้ที่ 375 px
- ไม่มีข้อมูล / กำลังโหลด / ผิดพลาด ครบทุกแท็บ
