# QA รอบ 16 · Codex C17

ตรวจวันที่ 23 พฤศจิกายน 2569 จากฐาน `9ccb539` บน `codex/c17-full-qa` รวม PR 175 และการปรับคอลัมน์ตามชนิดเสื้อ/กางเกงใน `7af1650`

## สรุปสั้น

- **ระดับ 1 · ใบเก่าของกางเกงช้างและกางเกงมวยไทยทำค่าขนาดหายจากจอและ PDF** ทั้งที่ไฟล์ JSON และใบร่างในเบราว์เซอร์ยังเก็บค่าเดิมครบ
- แอดมินและเจ้าของเปิดใบจากงานที่รับแล้ว แก้ที่อยู่และเลขครั้ง แทน PDF ได้สองครั้ง และดาวน์โหลดฉบับล่าสุดตรงกับไฟล์ที่แนบทุกไบต์
- การบันทึกจากฟอร์มกลับเข้าเลขที่ใบเดิมถูกปฏิเสธ สเปกเดิมคงอยู่ งานและใบร่างเดิมมีอย่างละ 1 รายการ
- พิมพ์ PDF สังเคราะห์ **76 ฉบับจาก 38 สินค้า** ข้อตกลงและช่องเซ็น 3 ช่องอยู่หน้าเดียวกันทุกฉบับ
- lint และ build ผ่าน ทดสอบแอป **593 ข้อ** ฐานข้อมูลจำลอง **1,606 ข้อ** และ Worker **17 ข้อ** ผ่าน
- ยืนยัน R15-01 ถึง R15-04 และพบขอบเขต R15-01 เพิ่มในช่องขนาดกางเกงใหม่
- ทดสอบเฉพาะ Chrome โปรไฟล์ชั่วคราว, PGlite และ Worker ในหน่วยความจำบน loopback

## 0. สภาพแวดล้อมและชุดทดสอบเดิม

ตั้ง `VITE_SUPABASE_URL=http://127.0.0.1:5214` และ `VITE_FILES_URL=http://127.0.0.1:5215` ก่อน build ตรวจ JS 13 ไฟล์และฟอร์ม HTML ก่อนเปิด Chrome และก่อนส่งงาน พบปลายทาง loopback ทั้งคู่ พบ URL `pp142.pages.dev` 1 จุดในข้อความสำหรับสร้าง QR ใบปะงาน โดยปลายทาง QR ไม่ถูกเปิด Chrome ใช้โปรไฟล์ใหม่ บล็อก HTTPS และการแก้ชื่อโฮสต์ภายนอก พบคำขอนอก loopback ที่ไม่ใช่ Google Fonts 0 รายการจากชุดที่เก็บการจราจร คำขอ Google Fonts ถูกบล็อก ตรวจ service worker แยกในกรณีทดสอบแถบอัปเดต พอร์ตชั่วคราวเป็น IP เดิมและตัวจำลองเปลี่ยนเฉพาะเลขพอร์ตที่เสิร์ฟในหน่วยความจำ

- หน้าคำศัพท์ · DOM พบคำอธิบายไทย «เริ่มทำงานคิวแรก», «ต้องใส่สาเหตุ เวลาที่พักไม่นับ», «ส่งต่อสถานีถัดไป», «หัวหน้ากดหลังแก้ปัญหา», «ของเสีย เครื่องเสีย ของไม่ครบ», «ติดปัญหา รอหัวหน้า», «ต้องรายงานก่อนกดเสร็จ», «ส่งบริษัทภายนอกทำ», «เรียกด้วยเลขใบงาน เช่น SC690001» และ «ลำดับงาน» ในหน้าคู่คำพม่า–ไทย จึงเก็บไว้เป็นผลสแกนแยกจากข้อความผิดพลาด
