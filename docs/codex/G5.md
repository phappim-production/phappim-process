## ทำไม
บั๊ก #2 รอบ 2 (กระดิ่งที่หัวเมนูซ้ายจอ 1440 px ถูกตัด) **ไม่ใช่บั๊กของโค้ดปัจจุบัน** · commit `3039d7a` ย้ายกล่องจดหมายเข้าเมนูซ้ายแล้ว · ที่เห็นคือ**หน้าเว็บรุ่นเก่าที่ค้างในเครื่อง** (PWA service worker) ซึ่งหายเมื่อรีโหลด
ตอนนี้ `vite.config.ts` ใช้ `registerType: 'autoUpdate'` แต่ตรวจหารุ่นใหม่เฉพาะตอนเปิดหน้า · แท็บเล็ตหน้างานเปิดค้างทั้งวัน → **หลัง Claude deploy แก้บั๊กวันทดลอง (ส. 21) แท็บเล็ตจะยังใช้รุ่นเก่า** · และถ้าโหลดใหม่อัตโนมัติกลางการกรอกฟอร์ม ข้อมูลที่พิมพ์จะหาย

## ขอบเขต
- `app/vite.config.ts` (เฉพาะตัวเลือก `VitePWA`) · `app/tsconfig.app.json` (เฉพาะ `types` ถ้าต้องเพิ่ม `vite-plugin-pwa/react`)
- ไฟล์ใหม่ `app/src/components/AppUpdate.tsx` (+ ไฟล์ช่วย/ทดสอบใน `app/src/components/`)
- `app/src/App.tsx` **เฉพาะ** วางคอมโพเนนต์แถบแจ้งรุ่นใหม่ (ไม่เกิน ~5 บรรทัด)
- **ห้ามเพิ่ม dependency** · ใช้ `virtual:pwa-register/react` ของ `vite-plugin-pwa` ที่มีอยู่แล้ว (ใช้ `workbox-window` ที่ติดตั้งมาด้วยแล้ว) · ไม่มี migration · ห้ามแก้ไฟล์อื่น

## ต้องทำ
1. เปลี่ยนเป็น `registerType: 'prompt'` แล้วลงทะเบียนเองด้วย `useRegisterSW` (ปิดการฉีดสคริปต์อัตโนมัติถ้าซ้ำ)
2. **ตรวจหารุ่นใหม่เป็นระยะ:** ทุก 10 นาที และทุกครั้งที่กลับมาที่แท็บ (`visibilitychange` → visible) · เรียก `registration.update()` · ไม่มีเน็ตให้ข้ามเงียบๆ
3. **มีรุ่นใหม่ → แถบแจ้งด้านล่างจอ** (ไม่บังปุ่มหลักและแถบเมนูล่างจอมือถือ): "มีระบบรุ่นใหม่ · กดเพื่อโหลด" + ปุ่ม "โหลดรุ่นใหม่" สูง ≥ 48 px → `updateServiceWorker(true)` · สีจาก theme (`bg-brand` / `TONE`) ไม่ใส่ hex
4. **โหลดเองอัตโนมัติเมื่อปลอดภัย:** ถ้ามีรุ่นใหม่ค้างเกิน 2 นาที และไม่มีกล่องโต้ตอบ/ฟอร์มเปิดอยู่ (`document.querySelector('[role=dialog]')` ไม่มี) และผู้ใช้ไม่ได้พิมพ์ (ช่องที่ focus ไม่ใช่ input/textarea/select) → โหลดรุ่นใหม่เอง · นอกนั้นรอให้กดปุ่ม · แยกตัวตัดสินใจ "โหลดเองได้ไหม" เป็น pure function แล้วทดสอบ
5. ตอนพัฒนา (`npm run dev`) ไม่ต้องทำงาน · ข้อความไทยทั้งหมด · ปุ่มบอกสถานะระหว่างโหลด

## ทดสอบ
- Vitest: ตัวตัดสินใจโหลดเอง (มี dialog / กำลังพิมพ์ / ยังไม่ถึง 2 นาที / ปลอดภัย) · ช่วงเวลาตรวจ
- ลองจริงแบบ production: `npm run build && npm run preview` → เปิดหน้า → แก้ข้อความเล็กน้อยในเครื่อง (ไม่ commit) → build ใหม่ → กลับมาที่แท็บ → แถบขึ้น → กดแล้วได้รุ่นใหม่ · ลองกรณีเปิดหน้ารับงานค้างไว้ → ต้องไม่โหลดเอง · ภาพหน้าจอ 375 / 768 / 1440 px
- ชุดทดสอบเดิมผ่านทั้งหมด (Vitest 143 · node:test 112 · DB 493) · lint ไม่มี warning ใหม่
