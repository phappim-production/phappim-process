# ใบยืนยันฉบับโรงงานประหยัดกระดาษ (28 พ.ย. · เจ้าของขอ)

เจ้าของ: "ส่วนที่ส่งให้ฝ่ายผลิต อยากให้จัดเรียงให้ประหยัดเหมือนกัน ลดการใช้กระดาษ แต่ข้อมูลต้องชัดเจน"

## เปลี่ยนอะไร (`production-confirmation.html`)
- คลาส `cmp` ใช้ทั้งสองฉบับ (กริด 3 คอลัมน์ ตาราง/หัวข้อ/ข้อตกลง/ช่องเซ็นแบบย่อ) · `cust` เฉพาะลูกค้า · `fac` เฉพาะโรงงาน
- ฉบับโรงงานยังแบ่งหัวข้อตามเดิม · จำนวนรวม + เผื่อเสียอยู่ในกริดแรก (เดิมเป็นแถบแยก)
- ภาพม็อคอัพ `fd-mock` ต่อจากรายละเอียด (เดิม `d-mockpage` บังคับขึ้นหน้าใหม่) · ภาพที่มี/ไม่มีจุดกำกับอยู่ในกริดเดียว สูงเท่ากัน (ภาพมีจุดกำกับใช้สัดส่วนรวมขอบว่างรอบภาพ)
- จุดกำกับบนภาพในใบ = เลข + ชื่อจุด · รายละเอียดอยู่ในตาราง (`coDocHTML` คืนเฉพาะตาราง)
- `fitFactoryPage` ลอง 5 แบบ × ตัวอักษรปกติ/ย่อ (ต่อจากรายละเอียด · ข้อตกลงไปหน้าถัดไป · ภาพล้นไปหน้าถัดไป · ขึ้นหน้าใหม่ ±ข้อตกลง) แล้วเลือกหน้าน้อยสุด → ไม่ย่อตัวอักษร → ภาพใหญ่สุด · ภาพมีจุดกำกับสูง ≥ 50 มม. · ไม่มี ≥ 40 มม.
- `factoryPages` จำลองการตัดหน้า (ก้อนห้ามตัด: section · แถวภาพ · แถวตาราง · ข้อตกลง · หัวข้อติดกับก้อนถัดไป) ใช้ทั้งเลือกแบบและข้อความ "ประมาณ … หน้า" · ตรงกับ PDF จริงทุกกรณีที่ลอง
- `smallestGrid` / `applyGrid` ใช้ร่วมกับฉบับลูกค้า · ลบ `fitMockups` เดิม
- เงื่อนไขฉบับโรงงาน 2 คอลัมน์
