## ขั้นตอน (ทำตามลำดับ · ทุกขั้นถ่ายภาพหน้าจอ + จดเวลา + บัญชีที่ใช้)

### 1. ใบยืนยัน + PDF จริง (บัญชี admin)
1. เปิด `/confirmation` กรอกใบ **`TEST-R9-A`** (เสื้อยืด · DTF · ขึ้นตัวอย่าง) และ **`TEST-R9-B`** (เสื้อกีฬา · ปกติ ซับลิเมชั่น · ไม่ขึ้นตัวอย่าง) · ใส่รูปม็อคอัพจริง · **ส่งออก PDF** → บันทึกไฟล์เป็น PDF จริง (`docs/qa/img/r9-ag-TEST-R9-A.pdf`)
2. **บันทึกเข้าระบบ** → หน้าระบบ **รับงานใหม่** เลือกใบจากรายการ · เลือกเส้นทาง · **แนบ PDF** ที่ส่งออกจากข้อ 1 (ทำ 1 ใบตอนรับงาน · อีกใบแนบทีหลังจากรายละเอียดงาน)
3. เปิดรายละเอียดงาน → **เปิด PDF ใบยืนยัน** ได้ ไฟล์ถูกใบ · รูปม็อคอัพขึ้นบนการ์ด
4. (ถ้ามีเวลา) **`TEST-R9-C`** เส้นทาง ปัก หรือ พิมพ์+ปัก เพื่อทดสอบส่งออกบริษัทภายนอก → รับกลับ

### 2. ใบปะงานจริง (บัญชี admin)
1. รายละเอียดงาน → **พิมพ์ใบปะงาน** ทั้ง 2–3 งาน · พิมพ์ A5 กับเครื่องพิมพ์จริง (หรือ "บันทึกเป็น PDF" ถ้าไม่มีเครื่องพิมพ์ · เก็บ `r9-ag-label-*.pdf`) · ตรวจไม่ล้นหน้า ข้อความครบ รูปม็อคอัพขึ้น
2. **สแกน QR ด้วยมือถือจริง** (บัญชี production) → เปิดรายละเอียดงานถูกงาน (QR ชี้ไป **เว็บจริง** pp142.pages.dev เสมอ แม้พิมพ์จาก localhost) · ถ้ายังไม่ล็อกอิน ล็อกอินแล้วยังเปิดงานนั้น
3. ใช้ใบปะงาน + สแกน QR ตลอดการเดินงานข้อ 3–5 (ทุกสถานีเปิดงานจาก QR อย่างน้อย 1 ครั้ง)

### 3. ฟิล์ม + ตัวอย่าง (บัญชี admin + production)
- `TEST-R9-A`: สั่งฟิล์ม → รีดฟิล์มกดเริ่มไม่ได้จนกว่าจะ **ได้รับฟิล์ม** → เดินตัวอย่าง → แอดมินบันทึกผล **ไม่ผ่าน** 1 รอบ → รอบ 2 **ผ่าน** → เข้าผลิตจริง

### 4. เดินทุกสถานี (บัญชี production · QC สำหรับ QC + Packing)
ทุกสถานีของทั้ง 2–3 งาน: เปิดจาก **แถบสถานี 1–7** · ตรวจหัวสถานี "สถานีที่ n จาก 7" · ป้าย **เครื่อง x/y** · กด **เริ่ม → เสร็จ** · ระหว่างทาง:
1. **เครื่องเต็ม:** ที่พิมพ์ (2 เครื่อง) เริ่มงานจนเต็ม → งานที่ 3 ปุ่มเริ่มต้องเปลี่ยนเป็นเหตุผลบอกงานที่ใช้เครื่อง · **พักงาน** 1 งาน (ยกลง) → เริ่มงานใหม่ได้ · กด **แก้แล้ว ทำต่อ** ตอนเครื่องเต็ม → งานกลับเข้าคิว
2. **รีดกับรีดฟิล์มคนละเครื่อง:** มีงานกำลังรีดฟิล์ม → หน้ารีดยังเริ่มได้
3. **เย็บ:** กด **เริ่มเย็บ** → ผังจักร ระบบเลือกตัวว่างให้ → เปลี่ยนเป็นจักรที่กำหนดเอง → **เริ่มเย็บด้วย …** · **จัดการจักร** เพิ่ม 1 ตัว / คืน 1 ตัว / คืนจนไม่ครบ (ต้องถูกปฏิเสธพร้อมเหตุผล) · แจ้งจักรเสีย 1 ตัว → ซ่อมเสร็จ · **เย็บเสร็จ** คืนจักรทุกตัว
4. **ส่งงานเกินเวลา / รายงานปัญหา:** ถ้าการ์ดขึ้นส้ม/แดงให้ลองส่งรายงานปัญหา (ไม่ต้องรอให้เกินจริงถ้าไม่เกิน)
5. **QC + Packing (บัญชี qc):** บันทึกผ่านไม่ครบ → กดเสร็จไม่ได้ · **ส่งแก้** 2 ชิ้นกลับเย็บ → เย็บแก้ → QC ผ่านครบ → **เสร็จ**

### 5. ผู้บริหาร (บัญชี manager)
- เมนูตรงตาม `docs/แบบเมนูตามบทบาท.md` · **รายการรออนุมัติ**: เห็นงานพัก · รายงานเกินเวลา · การแทรกคิว/ข้ามคิว พร้อมเหตุผล → กด **รับทราบ** แล้วรายการหายไป · **แทรกงานด่วน** 1 ครั้ง (ใส่เหตุผล) แล้วเห็นในรายการรออนุมัติ

### 6. ทุกบทบาท
- ล็อกอินทุกบัญชีทดสอบ · เมนูตรงตามแบบ · ทุกเมนูเปิดได้ · หน้าไม่มีสิทธิ์ขึ้นข้อความ · มือถือ 375 px แถบล่างไม่เกิน 5 ปุ่ม + "เพิ่มเติม"
- **ประวัติการทำงาน** (บัญชี qc): เห็นสิ่งที่กดวันนี้ · **แจ้งปัญหา** (บัญชี qc): แจ้งงานที่ QC + Packing → งานพัก

### 7. พนักงานสถานี (ถ้าเจ้าของตั้งบัญชีทดสอบเป็น `staff` + จับคู่สถานีตัดให้)
- กดเริ่ม/เสร็จ/พักงานที่ตัดได้ · สถานีอื่นปุ่มกดไม่ได้และบอกเหตุผล · แจ้งปัญหาได้เฉพาะงานที่ตัด
