# ส่งงาน G3 (`antigravity/g3-manual`)

## เปลี่ยนอะไร
- สร้างคู่มือใช้งานภาษาไทยแยกตามบทบาท 5 ไฟล์ใน `docs/คู่มือ/` (`ฝ่ายผลิต.md`, `แอดมิน.md`, `QC.md`, `ผู้บริหาร.md`, `เจ้าของระบบ.md`) และ [`docs/คู่มือ/แผนอบรม.md`](../คู่มือ/แผนอบรม.md)
- เพิ่มภาพหน้าจอขนาดแท็บเล็ต `768 px` (`768x900`) จำนวน 20 ภาพใน `docs/คู่มือ/img/` ถ่ายจาก `https://pp142.pages.dev` ด้วยบัญชี `@pp142.test` และงาน `TEST-` เท่านั้น
- **อัปเดตตามรีวิวรอบแรก:**
  - ลบ `docs/ใบมอบหมายงานฝึกงาน-ทดลองระบบผลิต.pdf` ออกจาก branch (อยู่นอกขอบเขต)
  - อัปเดตหน้า **รับงาน** (เลือกเส้นทาง 8 แบบ + ต้องเลือก "ขึ้นตัวอย่าง / ไม่ขึ้นตัวอย่าง" ไม่มีค่าตั้งต้น) และผลหลังติ๊ก **วัตถุดิบ** ครบทั้ง 3 ฝ่าย
  - อัปเดตชื่อ **รีดฟิล์ม** (ใช้กับ DTF / DTG / ซิลค์สกรีน) และเพิ่มวิธีใช้งานสถานี **ส่งปัก (ร้านนอก)**
  - แก้คำอธิบายแถบแดงที่บังคับ **รายงานปัญหา** เป็น **เกินเวลามาตรฐาน**, ป้าย **งานแก้** สีแดง, **พักงาน** พิมพ์สาเหตุ, แก้คำพิมพ์ผิด, และวิธีสร้างบัญชีใน **Supabase → Authentication → Add user** (หน้าเว็บกำหนดบทบาทได้อย่างเดียว)
  - เติมภาพจริงแทน `[รอภาพ]` สำหรับ **กล่องจดหมาย** (กระดิ่งมุมขวาบน — ใส่ในทุกบทบาท), รายละเอียดงาน `TEST-N1` (**รอบตัวอย่าง**, **เวลาที่ใช้ต่อสถานี**, **ไทม์ไลน์ทุกการกด**), ปุ่ม **แจ้งว่ากดผิด**, และปุ่มเปิด PDF + ลิงก์สำรอง `"ถ้าไฟล์ไม่เปิดขึ้นมา กดที่นี่"`

- **อัปเดตตามรีวิวรอบ 2:**
  - แก้คำพิมพ์ผิด `"งาาน"` → `"งาน"` ใน `ฝ่ายผลิต.md`
  - แยกชื่อปุ่มสั่ง/รับตามประเภทงาน: DTF (`บันทึกสั่งฟิล์ม DTF` / `ได้รับฟิล์ม DTF แล้ว`), DTG (`บันทึกสั่งงาน DTG` / `ได้รับงาน DTG แล้ว`), สกรีน (`บันทึกสั่งงานสกรีน` / `ได้รับงานสกรีนแล้ว`)
  - อธิบาย **รายงานปัญหา** ให้ตรงระบบ (ฟอร์มขึ้นเองเมื่อใกล้/เกินเวลามาตรฐาน, ปัญหาทั่วไปใช้ **พักงาน / ติดปัญหา**, ช่องพิมพ์ `ต้องการความช่วยเหลือจากใคร (ถ้ามี)`)
  - อธิบาย **แจ้งว่ากดผิด** (แค่บันทึกว่ารายการนั้นผิดพร้อมเหตุผล ไม่ได้ย้อนสถานะงาน · ถ้าต้องย้อนสถานะจริงให้แจ้งเจ้าของระบบ) และจำกัดสิทธิ์เฉพาะ **ฝ่ายผลิต** และ **เจ้าของระบบ** (ไม่มีในคู่มือ QC และแอดมิน)

## ทดสอบอะไร (ผลจริง)
- เปิด `https://pp142.pages.dev` ที่ขนาดจอ `768x900` ด้วยบัญชีทดสอบ 4 บทบาท (`production@pp142.test`, `admin@pp142.test`, `qc@pp142.test`, `manager@pp142.test`) และงาน `TEST-N1`
- ตรวจคำศัพท์ให้ตรงตาม `docs/แผน-1-สัปดาห์.md` หัวข้อ 6 และตรวจความครบถ้วนของภาพหน้าจอทุกบทบาท

## ยังไม่ได้ทำ
- ภาพหน้าจอสำหรับ **หน้าตั้งค่า** ใน `เจ้าของระบบ.md` (ยังใส่ `[รอภาพ]` ไว้ตามคำสั่งงาน เพื่อรอ C2)

## บั๊กที่เจอนอกขอบเขต
