## ทำไม
ภาพหน้าจอจาก G3 แสดงว่ารายละเอียดงาน `TEST-N1` ที่เสร็จแล้วยังขึ้น "QC + Packing 40 นาที (ยังทำอยู่)"
สาเหตุ: view `public.station_visits` เอาเวลาจบจาก event `station_done` อย่างเดียว แต่รอบที่จบด้วยวิธีอื่น**ไม่มี** `station_done`:
- QC ส่งกลับแก้ (`send_rework` → event `rework` แล้วงานย้ายสถานี)
- สถานีสุดท้ายของรอบตัวอย่าง (`finish_station` → event `sample_sent`)
- สถานีสุดท้ายของผลิตจริง (`finish_station` → event `done`)

ผลคือรอบเหล่านี้ `done_at` ว่างตลอดไป · **รายงาน C4 ใช้ view นี้คิดเวลาต่อสถานี จึงต้องแก้ก่อน**

## ต้องทำ
### ก. view `station_visits` (migration)
- `create or replace view public.station_visits with (security_invoker = true)` คอลัมน์เดิม ลำดับเดิม ชนิดเดิม (`job_id, station_code, phase, visit, started_at, done_at, rework`) · ห้ามเปลี่ยนชื่อหรือเพิ่มคอลัมน์ก่อนคอลัมน์เดิม
- `done_at` = เวลา `station_done` ของรอบนั้น ถ้าไม่มี ให้ใช้เวลาของ event แรกของงานเดียวกันที่เกิด**หลัง** `started_at` และจบรอบนั้น: `rework` · `sample_sent` · `done` · หรือ `station_start` ของรอบอื่น (visit มากกว่า)
- รอบที่ยังทำอยู่จริง (ยังไม่มี event จบ) `done_at` ต้องว่างเหมือนเดิม
- `hold` / `resume` ระหว่างรอบ**ไม่ใช่**การจบรอบ
- ระวัง: event ภายในรอบ (`substep_done`, `qc_result`, `sew_count`, `hold`) มี `payload.visit` เดียวกัน ห้ามนับเป็นจุดจบ

### ข. ทดสอบฐานข้อมูล `history.mjs` (เดินงานจริงผ่าน RPC แบบ `e2e.mjs` / `routes.mjs`)
- จบปกติด้วยกดเสร็จ → `done_at` = เวลา `station_done`
- QC ส่งกลับแก้ → รอบ QC นั้นมี `done_at` · รอบงานแก้ที่สถานีต้นเหตุเริ่มใหม่
- สถานีสุดท้ายของรอบตัวอย่าง → `done_at` = เวลา `sample_sent`
- สถานีสุดท้ายของผลิตจริง → `done_at` = เวลา `done`
- รอบที่ยังทำอยู่ → `done_at` ว่าง · พักงานแล้วทำต่อในรอบเดียวกัน → ยังว่าง
- **ชุดทดสอบเดิมทุกข้อยังผ่าน** (ตอนนี้ 483 ข้อ)

### ค. หน้าเว็บ
1. `history.ts` · `eventLine`: ข้อความที่ใช้คำว่า "ชิ้น" (`received` · `qc_result` · `rework`) ใช้หน่วยของงาน (`ตัว` / `ใบ` / `ผืน` ...) · ส่งหน่วยเข้า `Names` หรือพารามิเตอร์ใหม่ · `JobHistory.tsx` ส่ง `job.unit` · เพิ่มทดสอบใน `history.test.mjs`
2. `JobActions.tsx`: ข้อความ `ได้รับ{label}แล้ว` (ปุ่ม) และ `บันทึกได้รับ...แล้ว · เริ่มรีดฟิล์มได้` (แจ้งผล) ต้องเว้นวรรคหลังคำอังกฤษ เช่น "ได้รับฟิล์ม DTF แล้ว" · ใช้ `spaced()` จาก `app/src/proto/format.ts` · ข้อความไทยล้วน ("ได้รับงานสกรีนแล้ว") ห้ามมีช่องว่างเกิน
### ง. เมนูซ้ายจอใหญ่ (`App.tsx`)
- กระดิ่งในหัวเมนูทำให้ "ติดตามการผลิต" ตกเป็น 3 บรรทัด · แก้ให้ไม่เกิน 2 บรรทัดที่ 1024 และ 1440 px (เช่น ลดขนาดโลโก้หรือช่องว่าง) โดยกระดิ่งยังอยู่ที่เดิม ปุ่มยังสูง ≥ 48 px
