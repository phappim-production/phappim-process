- เพิ่มชุด QA สำหรับ route `outside`, สิทธิ์การเดินงาน การส่งออก งานแก้ ตัวอย่าง แบ่งงาน ยกเลิก คิว และความเข้ากันได้กับ 8 เส้นทางเดิม
- เพิ่ม Vitest, API จำลองและ Chrome QA พร้อมภาพหลักฐานและผลตรวจรายข้อใน [รายงานรอบ 12](../qa/รอบ-12-codex.md)
- เพิ่ม 2 บรรทัดใน `supabase/tests/run.mjs` เพื่อเรียก C14 ก่อน `flowRouteTests` โดยให้ชุด cleanup เดิมอยู่ท้ายสุด
