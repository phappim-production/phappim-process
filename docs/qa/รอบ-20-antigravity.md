  - **ที่พบ:** [แอดมิน.md](../../docs/คู่มือ/แอดมิน.md#L59) บรรทัด 59 ยังเขียนว่า *"ระบบไม่มีขั้นรอวัตถุดิบแล้ว ส่งงานเข้าแล้วงานจะขึ้น สถานี แรกทันที"* ทั้งที่ข้อ 3.1 ด้านล่างเพิ่งเพิ่มขั้นรอผลิต
  - **ผลที่ควรเป็น:** แก้บรรทัด 59 ให้ตรงกับข้อ 3.1 ว่ารับงานแล้วจะค้างที่คอลัมน์ **รอผลิต** ก่อนปล่อยเข้าไลน์
- **`R20-02` [ระดับ 2] คู่มือฝ่ายผลิตและเจ้าของระบบยังอธิบายลำดับคิวผิดหลัง PR 231:**
  - **ที่พบ:** [ฝ่ายผลิต.md](../../docs/คู่มือ/ฝ่ายผลิต.md#L70) และ [เจ้าของระบบ.md](../../docs/คู่มือ/เจ้าของระบบ.md#L104) ยังเขียนว่าทุกหน้าเรียงตาม *"ลำดับที่แอดมินรับงานเข้า"* แต่ระบบจริงหลัง PR 231 เรียงตาม **วันปล่อยเข้าไลน์** (`release_job`)
  - **ผลที่ควรเป็น:** อัปเดตคำอธิบายเป็นเรียงตามลำดับที่แอดมินกด **ปล่อยเข้าไลน์**
- **`R20-03` [ระดับ 2] คู่มือหลายเล่มยังไม่ครบและยังมีคำเก่า:**
  - **ที่พบ:** `audit-manuals.mjs` พบ `QC.md`, `ผู้บริหาร.md`, `แผนอบรม.md` ยังไม่มีเนื้อหาขั้นรอผลิต และ `แอดมิน.md`, `ฝ่ายผลิต.md`, `แผนอบรม.md` ยังมีคำว่า `"ซิลค์สกรีน"`
  - **ผลที่ควรเป็น:** อัปเดตคู่มือทุกบทบาทและแผนอบรมให้ตรงหน้าจอจริง

### ระดับ 3 และข้อสังเกต (3 ข้อ)
- **`R20-04` [ระดับ 3] เอกสาร `docs/api-workflow.md` บรรทัด 31 ยังไม่อัปเดต:**
  - **ที่พบ:** ตาราง `receive_job` ยังเขียน *"สร้างงาน → ปล่อยเข้าสถานีแรก/ขึ้นตัวอย่างทันที"* ขัดแย้งกับหัวข้อ "รอผลิต" ด้านล่าง
- **`R20-05` [ระดับ 3 / ไม่แน่ใจว่าตั้งใจหรือไม่] พนักงานที่ยังไม่จับคู่สถานี (`staff_empty`) ขอลิงก์ดูรูปวัตถุดิบได้:**
  - **ที่พบ:** `file_read_allowed` ให้สิทธิ์อ่าน bucket `mockups` (รวม `job_material_photos`) สำหรับทุกบัญชีที่ล็อกอิน (`my_role() is not null`) ต่างจาก `station_photos` ที่กัน `staff_empty` ไว้ (`not private.staff_without_station()`)
  - **หมายเหตุ:** ให้เจ้าของ/ผู้พัฒนาตัดสินใจว่าต้องการปิดสิทธิ์ดูรูปวัตถุดิบ/ม็อคอัพสำหรับ `staff_empty` ด้วยหรือไม่
- **`R20-06` [ระดับ 3] กด Enter รัวในช่องเพิ่มรายการวัตถุดิบขณะ `busy` ไม่มีตัวกันซ้ำใน `add()`:**
  - **ที่พบ:** ใน `MaterialsCheck.tsx` ฟังก์ชัน `add()` ไม่ได้ตรวจ `if (busy) return` (ปุ่ม `<button>` ถูก disable แล้ว แต่การกด Enter/submit form ระหว่างโหลดอาจส่งซ้ำหรือตกหล่นได้)

## 7. จุดที่คนหน้างานอาจงง
- แอดมินที่อ่านคู่มือหัวข้อ 3 อาจเข้าใจผิดว่างานเข้าโรงงานทันทีแล้วไม่เห็นงานในคิวสถานี ทั้งที่งานค้างอยู่ที่ **รอผลิต**
- ฝ่ายผลิตอาจสับสนเรื่องคิวของงานที่รับมาก่อนแต่ปล่อยทีหลัง (คิวต่อท้ายตามวันปล่อย ไม่ใช่วันรับงาน)
