## บั๊กและข้อสังเกตที่พบ (ไม่พบบั๊กระดับ 1)
1. **บั๊ก #1 (ระดับ 2):** ปุ่ม `"บันทึกเข้าระบบ"` บน [`production-confirmation.html`](../../production-confirmation.html#L1044-L1045) เปิดแท็บซ้ำอีกแท็บที่ขึ้น error `"ไม่พบใบยืนยันที่ส่งมาจากฟอร์ม"` (แม้แท็บแรกบันทึกสำเร็จ)
2. **ข้อสังเกต #2 (ระดับ 2):** [`private.work_days`](../../supabase/migrations/20261117000001_workflow.sql#L134) หารเวลาด้วย `86400` วิ (24 ชม./วัน) ทำให้ `sla_days = 0.02` ใช้เวลาเตือนจริง ~23 นาที / เลยเวลา ~29 นาที และ [`JobActions.tsx`](../../app/src/pages/JobActions.tsx#L404) ปัด `0.017`/`0.021` เป็น `"ใช้ไป 0.0 จาก 0.02 วันทำงาน"`
3. **ข้อสังเกต #3 (ระดับ 3):** งานที่ส่งออกข้างนอกยังแสดงใน `"จักรเย็บ" → "รอเย็บ"` ด้วยข้อความ `"งานนี้เริ่มเย็บไปแล้ว จักรไม่ว่าง"`
4. **ข้อสังเกต #4 (ระดับ 3):** การ์ดบน `"บอร์ด"` และ `"ต้องทำตอนนี้"` ไม่แสดงกรอบ/ป้ายส้ม-แดงเมื่อ `station_warn`/`station_over` เป็นจริง
5. **ข้อสังเกต #5 (ระดับ 3):** [`AttachPdf`](../../app/src/pages/JobActions.tsx#L149) ในรายละเอียดงานยังแสดง `"Choose File No file chosen"` เป็นภาษาอังกฤษ
6. **ข้อสังเกต #6 (ระดับ 3):** แท็บ `"จักรเย็บ" → "งานเย็บ"` บนจอ `375 px` มีแถบเลื่อนแนวนอนเล็กน้อยเมื่อมีงานพักเย็บ
7. รวมข้อเสนอ `"ใช้ยาก/งง"` มุมแอดมิน 5 ข้อ + มุมคนหน้างาน 5 ข้อไว้ใน [`รอบ-5-antigravity.md`](../qa/รอบ-5-antigravity.md) หัวข้อ 3 แล้ว
