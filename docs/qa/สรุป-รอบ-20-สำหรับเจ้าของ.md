# สรุปผลตรวจระบบรอบ 20 สำหรับเจ้าของระบบ (ครบระบบ · ขั้นรอผลิต · หลัง PR 233)

> **ตรวจเมื่อ:** 26 พ.ย. 2569 · **วิธีตรวจ:** ทดสอบบนระบบจำลองในเครื่องเท่านั้น (`127.0.0.1:5234` / `5235`) ไม่ได้เปิด แตะ หรือแก้ข้อมูลในระบบจริงของโรงงานเลย

---

## 1. ภาพรวมและคำตอบสำคัญ: "ขั้นรอผลิต" พร้อมใช้งานจริงหรือไม่?

- **ระบบหลักทั้งหมด (ฟอร์มใบยืนยันฉบับลูกค้า, เวลาผลิตทั้งงาน, รับทราบใบแก้, หน้ากำหนดส่งลูกค้า, เดินครบทุกเส้นทาง):** 🟢 **พร้อมใช้งานจริงต่อเนื่อง** — ชุดทดสอบอัตโนมัติทั้งหมด (หน่วยย่อย 604 + พฤติกรรม 200 + ฐานข้อมูล 1,972 + 106 + ระบบจำลองทุกชุด) ผ่านครบ ข้อมูล 300+ งานยังเปิดได้เร็วมาก (ไม่ถึง 1 วินาที)
- **ฟีเจอร์ใหม่ล่าสุด "ขั้นรอผลิต (เช็ควัตถุดิบ + ถ่ายรูปก่อนปล่อยเข้าไลน์)":** 🟢 **พร้อมใช้งานจริง ไม่พบบั๊กระดับ 1**
  - งานทุกแบบ (ไม่ขึ้นตัวอย่าง, ขึ้นตัวอย่าง, Develop, DTF/DTG/สกรีน, ผลิตข้างนอก) ค้างที่ **รอผลิต** จริง พนักงานสถานี/QC ไม่เห็นในคิวตัวเอง และ **เวลาผลิต 10/15/20 วันยังไม่เริ่มนับ** จนกว่าแอดมินจะกดปล่อย
  - ระบบล็อกไม่ให้ปล่อยถ้ายังไม่มีรายการ ยังติ๊กไม่ครบ หรือยังไม่มีรูปวัตถุดิบ และ **ห้ามใช้รูปม็อคอัพของงานมาแทนรูปวัตถุดิบ**
  - **สิ่งที่แอดมินต้องระวัง:**
    1. ถ้ารับงานแล้วลืมเช็ควัตถุดิบ งานจะค้างอยู่หน้า **รอผลิต** ไม่เข้าคิวสถานี (ระบบจะส่งข้อความเตือนเข้ากล่องจดหมายแอดมินเมื่อค้างเกิน 2 วันทำงาน)
    2. **คิวของงานนับตามวันที่กดปล่อยเข้าไลน์** ไม่ใช่วันที่รับงาน (งานที่รับมาก่อนแต่ของยังไม่ครบแล้วปล่อยทีหลัง จะไปต่อท้ายคิว)

## 2. ความพร้อมแยกตามบทบาท

| บทบาท | สถานะ | หมายเหตุสำคัญสำหรับเจ้าของ |
|---|---|---|
| **แอดมิน** | 🟢 **พร้อม** *(ระวังคู่มือ `R20-01`)* | ขั้นรอผลิต, รับทราบใบแก้, ฉบับลูกค้า, ส่งออก/แบ่งงาน ทำงานครบ · ต้องบอกแอดมินให้อ่านข้อ 3.1 เพราะหัวข้อ 3 ในคู่มือยังมีประโยคเก่าหลงอยู่ |
| **ฝ่ายผลิต** | 🟢 **พร้อม** *(ระวังคู่มือ `R20-02`)* | ดูรายการ/รูปวัตถุดิบได้ (แก้ไม่ได้) · รับทราบใบแก้ก่อนกดเสร็จ · คู่มือยังเขียนว่าคิวเรียงตามวันรับงาน (ความจริงเรียงตามวันปล่อย) |
| **พนักงานสถานี (พม่า)** | 🟢 **พร้อม** | ไม่เห็นงานที่ยังไม่ปล่อยในคิวตัวเอง · ดูแบบอ่านอย่างเดียวในหน้าทั้งโรงงานได้ (พม่าครบ) · หน้าจอ 375 px ไม่ล้น |
| **ฝ่าย QC (พม่า)** | 🟢 **พร้อม** | กดเสร็จไม่ได้หากเกินเวลาผลิตแล้วยังไม่ส่งรายงานสาเหตุ · หน้าจอ 375 px ไม่ล้น |
| **ผู้บริหาร / เจ้าของระบบ** | 🟢 **พร้อม** | ยกเลิกงานระหว่างรอผลิตได้, ตั้งค่า 6 แท็บ, ภาพรวม/กำหนดส่งลูกค้า/รายงานตรงกันทุกหน้า |

## 3. บั๊กและจุดที่ต้องแก้ (ภาษาเข้าใจง่าย · ไม่พบบั๊กระดับ 1)

### ระดับ 2 — ควรแก้ไขเพื่อไม่ให้ทีมหน้างานสับสน
1. **คู่มือแอดมินยังมีประโยคเก่าขัดแย้งกันเอง (`R20-01`):** หัวข้อ 3 ยังเขียนว่า *"ระบบไม่มีขั้นรอวัตถุดิบแล้ว"* ทั้งที่ข้อ 3.1 เพิ่งเพิ่มขั้นรอผลิต — **กระทบ:** แอดมินใหม่อาจงง — **ระหว่างรอแก้:** ยึดตามข้อ 3.1 เป็นหลัก
2. **คู่มือฝ่ายผลิตและเจ้าของระบบยังเขียนว่าคิวเรียงตาม "วันรับงาน" (`R20-02`):** ความจริงหลังมีขั้นรอผลิต คิวจะเรียงตาม **วันที่แอดมินกดปล่อยเข้าไลน์** — **กระทบ:** ฝ่ายผลิตอาจสงสัยลำดับคิว — **ระหว่างรอแก้:** ชี้แจงหัวหน้างานให้ทราบตรงกัน
3. **คู่มือบางเล่มยังไม่ครบและยังมีคำว่า "ซิลค์สกรีน" (`R20-03`):** คู่มือ QC, ผู้บริหาร, แผนอบรม ยังไม่มีเรื่องขั้นรอผลิต — **กระทบ:** การอบรมพนักงานใหม่ — **ระหว่างรอแก้:** ใช้คู่มือแอดมินข้อ 3.1 อธิบายประกอบ

### ระดับ 3 — ความเรียบร้อย (3 ข้อ)
4. **เอกสารทางเทคนิค (`api-workflow.md`)** ยังมีข้อความเก่าของฟังก์ชันรับงาน 1 จุด (`R20-04`)
5. **พนักงานที่ยังไม่จับคู่สถานี** ยังขอดูรูปวัตถุดิบ/ม็อคอัพผ่านระบบไฟล์ได้ (`R20-05`) — รอเจ้าของตัดสินใจว่าต้องการปิดสิทธิ์นี้หรือไม่ (รูปจากสถานียังปิดกันอยู่แล้ว)
6. **การกด Enter รัวๆ** ในช่องเพิ่มรายการวัตถุดิบขณะระบบกำลังบันทึก อาจทำให้รายการที่พิมพ์ติดๆ กันตกหล่นได้ (`R20-06`) — แนะนำให้พิมพ์ทีละรายการแล้วรอขึ้นแถบเขียวก่อนพิมพ์ต่อ

## 4. สิ่งที่ต้องบอกทีม
- **แอดมิน:** รับงานเข้าแล้วงานจะไปรอที่คอลัมน์ **รอผลิต** ก่อนเสมอ ต้องเช็ควัตถุดิบ ติ๊กครบ และถ่ายรูปวัตถุดิบจริงอย่างน้อย 1 รูป แล้วกด **ปล่อยเข้าไลน์การผลิต** งานจึงจะเข้าคิวและเริ่มนับเวลาผลิต 10/15/20 วัน
- **ฝ่ายผลิต:** คิวงานเรียงตาม **ลำดับการปล่อยเข้าไลน์** · หากพบงานที่แก้ไขใบยืนยันหลังรับงาน ให้กด **รับทราบใบแก้** ก่อนจึงจะกดเสร็จสถานีได้
