# ส่งงาน codex/c12-real-flow

เพิ่มการทดสอบ C12 สำหรับ flow ตั้งแต่รับงานจนจบ เปิดจำนวนเครื่องตาม migrations ครบในธุรกรรม PGlite และ rollback หลังทดสอบ เพิ่ม Vitest และสคริปต์ Chrome กับ API จำลองบน loopback ตรวจเมนู สถานี เครื่อง จักรเย็บ และใบปะงาน แทรกคำสั่งเรียกชุด C12 สองบรรทัดก่อน flowRouteTests ใน run.mjs

- **ผลทดสอบ** ฐานข้อมูล 1,023 ผ่าน (C12 28) · Vitest 361 ผ่าน (C12 15) · node:test 119 ผ่าน · lint และ build ผ่าน โดย Vite แจ้งเตือน entry chunk เกิน 500 kB เหมือนก่อนเพิ่มทดสอบ และ npm ci ของ app รายงานช่องโหว่ระดับ moderate 4 รายการในชุดแพ็กเกจเดิม
- **ผล Chrome** 30 กรณีผ่านที่ 375 / 768 / 1440 px ไม่พบหน้าล้นหรือ console error พิมพ์ใบปะงานออก PDF A5 หน้าเดียว ถอด QR ได้และเปิดรายละเอียดงานเดียวกันที่ loopback
- **กรณีที่ตั้งใจให้ล้ม** BUG: หัวคอลัมน์ “กำลังทำ” รวมงานพัก จึงแสดง 3 งานทั้งที่หัวสถานีแสดงกำลังทำ 2 งาน จัดเป็นระดับ 3 และส่งต่อ Claude ตรวจ โค้ดหน้าเว็บและ migrations อยู่นอกขอบเขตใบสั่งงาน
- **ยังไม่ได้ทดสอบ** แข่งเริ่มงานจากสองเซสชันเพื่อชิงเครื่องสุดท้าย เนื่องจาก PGlite ชุดนี้ใช้หนึ่งเซสชัน ยังไม่ได้สแกน QR จากใบพิมพ์จริงด้วยมือถือ
- **ขอบเขตการรัน** ใช้ฐานข้อมูลในหน่วยความจำ บัญชีจำลอง และ API บน loopback ไม่มีการ push หรือเปิด PR
