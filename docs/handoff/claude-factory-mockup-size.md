# ภาพม็อคอัพในใบยืนยันฉบับโรงงานใหญ่ขึ้น (28 พ.ย. · เจ้าของขอ)

เจ้าของ (ภาพใบสายคล้องคอ ฉบับโรงงาน ภาพม็อคอัพเล็กท้ายหน้า 1): "ภาพ Mockup ที่จะส่งให้ผลิต ต้องชัดหน่อยสิ อันนี้เล็กเกิน"

## สาเหตุ
`fitFactoryPage` (PR 259) เลือกแบบที่ใช้หน้าน้อยสุดก่อน แล้วย่อภาพลงได้ถึงสูง 40 มม. (มีจุดกำกับ 50 มม.) → ใบที่เหลือที่ว่างท้ายหน้า 1 นิดเดียว ภาพถูกย่อเหลือ ~45–50 มม. ให้จบหน้าเดียว

## เปลี่ยนอะไร (`production-confirmation.html`)
- `factNeedH`: ภาพทุกภาพต้องมีด้านยาว ≥ 9 ซม. (`FACT_SIDE`) · ภาพมีจุดกำกับวัดที่ตัวภาพ ไม่นับขอบชื่อจุด (`CO_MX` / `CO_MY`) · ภาพยาวมาก (แถบ) ยังใช้ความสูงขั้นต่ำเดิม 40 / 50 มม.
- ความสูงสูงสุด 130 → 170 มม. (`FACT_MAX_H`) ภาพเดียวที่ขึ้นหน้าใหม่ใช้เต็มความกว้าง
- ยังเลือกแบบที่ใช้หน้าน้อยสุดก่อนเหมือนเดิม แต่ไม่ย่อภาพต่ำกว่าเกณฑ์ → ที่ว่างไม่พอ = ภาพขึ้นหน้าถัดไปขนาดใหญ่ · ฉบับลูกค้าไม่เปลี่ยน
