## งานที่เหลือก่อนทดลอง ส. 21
1. **ทีมเย็บซ้อมหน้าจักรเย็บใหม่** ด้วยงาน `TEST-` (เริ่มเย็บด้วยการกดเลือกจักร · จัดการจักร) · ยังไม่มีใครกดจริงบนระบบ

- ช่วงเวลามาตรฐานหลายสถานี (segment) ที่บางสถานีส่งออก ยังนับเวลาข้างนอกรวมในช่วง
- `job_sla_flags` เรียก `private.sla_state` ทีละงานทุกครั้งที่โหลด (รับได้ที่ ~50 งาน · งานเยอะขึ้นค่อยรวมเป็น query เดียว)
- `#/board?job=` ของงานที่ไม่อยู่บนบอร์ด ไม่แสดงข้อมูลส่งออก · Realtime ไม่ฟัง `machine_types` / `confirmation_drafts` / `vendors`
- ไม่มีปุ่มย้อนสถานะงาน ("แจ้งว่ากดผิด" แค่บันทึก) · `resume_sewing` ไม่ตรวจจักรใช้ร่วม (ตั้งใจ)
- ภาพคู่มือบางภาพยังเป็นหน้าจอเก่า (`r2-station-panel` · `r5-queue-*` ไม่มีแถบสถานีด้านบน แต่ปุ่มในการ์ดยังตรง)
- รายงานแผนกยังเป็นรายงานทั้งโรงงาน (ไม่มีตัวกรองสถานี) · กล่องจดหมายไม่ส่งถึงบทบาท `staff` · บทบาท `staff` เย็บไม่ได้ (เย็บเป็นของฝ่ายผลิต)
- ทดสอบ DB: `run.mjs` ปิดจำนวนเครื่อง (`machines = null`) หลังตรวจค่าจริง เพราะชุดอื่นทิ้งงานกำลังทำไว้ · `station-machines.mjs` ทดสอบการจำกัดเครื่องเอง · `sewing-pick.mjs` ลบสูตรจักรสินค้าทดสอบตอนจบ
