# รับงานใหม่ด้วยเลขที่ใบของงานที่ยกเลิก จากฟอร์มที่เปิดใบงานเดิมค้างไว้

Branch `claude/cancelled-no-reuse` · ไม่แตะฐานข้อมูล

## เจ้าของแจ้ง
"ตอนยกเลิกไปแล้ว พอมารับงานใหม่รหัสเดิมมันบอกว่า มีงานอยู่แล้ว ทั้งๆที่โดนยกเลิกไปแล้ว" (เจ้าของอยากให้ลบงานที่ยกเลิก)

## สาเหตุ (จาก log ระบบจริง · ดูแค่ข้อความ error และเวลา)
1. 26 พ.ย. 17:06–17:12 บันทึกใบของงานหนึ่งหลังยกเลิกถูกปฏิเสธ "เป็นของงานที่ส่งงานเข้าโรงงานแล้ว" เพราะตอนนั้นฐานจริงยังไม่มี PR 248 (ลง 17:19) · หลัง 17:19 ใช้เลขเดิมได้ (รับ 17:21)
2. 27 พ.ย. 10:01 ฟอร์มที่เปิดใบของงานเดียวกัน (รับใหม่แล้วยกเลิกอีกครั้ง) ค้างไว้ (โหมดใบแก้ · จำในเบราว์เซอร์) กดบันทึกหลังงานถูกยกเลิก → `revise_job_spec` ปฏิเสธ "งานนี้ถูกยกเลิกแล้ว แก้ใบยืนยันไม่ได้" → แอดมินเลยต่อท้ายเลขเป็นงานใหม่แทน · **ข้อนี้ยังเกิดได้บน main** → แก้ใน PR นี้

ไม่ลบงานที่ยกเลิก: ใช้เลขเดิมได้อยู่แล้ว · ลบแล้วประวัติงาน (events ห้ามลบ) และไฟล์ของงานหาย
