# ส่งงาน C1 · ชุดทดสอบหน้าเว็บและ CI

Branch `codex/c1-app-tests` · ฐานงาน `7d7b92c` (รวม A3–A5 แล้ว)

## เปลี่ยนอะไร

- เพิ่ม Vitest เป็น devDependency และรับเฉพาะ `src/**/*.test.ts` ในชุด Vitest โดยใช้ UTC เพื่อให้ทดสอบกรณีข้ามเที่ยงคืนไทยบนเครื่องต่างเขตเวลาได้เหมือนกัน
- ให้ `npm test` รัน Vitest และชุด `node:test` เดิมใน `app/tests/` ตามข้อ 4.1
- เพิ่มขั้นแยกใน `app-build` ตามลำดับ `npm ci` → `npm run lint` → `npm test` → `npm run build` และคงงาน `db-tests` เดิมไว้
- เพิ่ม 6 ไฟล์ทดสอบ ครอบคลุมวันทำงาน การคาดการณ์คิวและรอฟิล์ม DTF การแสดงเวลาและขั้นตอน สถานะและกำหนดส่ง ขอบเขตของบทบาท ตัวเลขสรุปตามบทบาท และความครบถ้วนของข้อมูลตัวอย่าง

## ผลตรวจในเครื่อง

| รายการ | ผล |
|---|---|
| `npm ci` ใน `app/` | ติดตั้งจาก lockfile สำเร็จด้วย Node 24.19.0 |
| `npm run lint` และ `npm run build` ใน `app/` | ผ่านทั้งสองคำสั่ง |
| `npm test` ใน `app/` | Vitest 75 กรณีใน 6 ไฟล์ (ผ่าน 74 และ `it.fails` ตามคาด 1) และ `node:test` ผ่าน 91/91 |
| `npm ci` และ `npm test` ใน `supabase/tests/` | PGlite ในเครื่องผ่าน 383/383 |
| Chrome ที่ 375, 768 และ 1440 px | เปิดหน้าล็อกอิน หน้างานฝ่ายผลิต บอร์ด และรายละเอียดใบงานได้ครบ ความกว้างหน้าเท่ากับ viewport ทุกกรณี ปุ่มเข้าสู่ระบบและรับงานใหม่สูงอย่างน้อย 48 px และพบ console error 0 รายการ |

ตรวจเบราว์เซอร์จาก build ในเครื่องโดยใช้ API และ Realtime จำลองผ่าน Playwright นอก repo ฐานข้อมูลจริงไม่ได้เชื่อมต่อระหว่างการตรวจ

## บั๊กนอกขอบเขต

- `isOverdue` ใช้วันตามเขตเวลาของเครื่องผ่าน `startOfDay` ตัวอย่างงานกำหนดส่ง 17 พ.ย. 2569 เวลา 17:00 ไทย ที่เวลา 18 พ.ย. 00:01 ไทย บนเครื่อง UTC คืนค่า `false` แม้ข้ามวันไทยแล้ว ยืนยันใน Node ว่าเริ่มคืน `true` หลัง UTC ข้ามวัน กรณีนี้บันทึกเป็น `it.fails` ใน `app/src/proto/model.test.ts` เมื่อ Claude แก้ให้ใช้วันไทยแล้ว ให้เปลี่ยนกรณีนี้เป็น `it`
- `npm audit` รายงานระดับปานกลาง 4 รายการในสาย dependency ของ PWA จำนวนและแพ็กเกจตรงกับฐาน `main` ก่อนเพิ่ม Vitest
