# แบบเมนูตามบทบาท (ร่างให้เจ้าของตรวจ)

ตามรูป 5 บทบาทที่เจ้าของส่งมา 19 พ.ย. · คงสีเขียวแบรนด์ · สร้างทุกหน้า
**ใหม่** = ยังไม่มีในระบบ ต้องสร้าง · **เดิม** = ใช้หน้าที่มีอยู่ ย้ายมาอยู่ในเมนูใหม่

## บทบาท
| ในรูป | บทบาทในระบบ |
|---|---|
| Manager | ผู้บริหาร (`manager`) |
| ผู้ดูแลระบบ | เจ้าของระบบ (`owner`) |
| แอดมิน | แอดมิน (`admin`) |
| ผู้จัดการแผนกผลิต | ฝ่ายผลิต (`production`) + ผู้ควบคุมงาน (`supervisor`) |
| STAFF | **บทบาทใหม่ "พนักงานสถานี" (`staff`)** + ฝ่าย QC (`qc`) |

## 1. ผู้บริหาร
| เมนู | หน้า | เนื้อหา |
|---|---|---|
| ภาพรวมการผลิต | เดิม | ภาพรวมทั้งโรงงาน (สถานีตอนนี้ · ส่งออกข้างนอก · รับงานเพิ่มได้ไหม) |
| กำหนดส่งลูกค้า | **ใหม่ (26 พ.ย.)** | งานที่ยังไม่ส่งเรียงตามวันส่ง · เลยกำหนด / วันนี้ / พรุ่งนี้ / คาดว่าไม่ทัน |
| ใบงานทั้งหมด | เดิม (แยกออกมา) | ค้นหางาน + ตารางงานทุกงาน |
| ทุก Station | เดิม | บอร์ดทั้งโรงงาน + แท็บจักรเย็บ |
| รายงาน | เดิม | รายงาน 7/30/90 วัน |
| รายการรออนุมัติ | **ใหม่** | ดูข้อ "ต้องตัดสิน" ข้างล่าง |

## 2. ผู้ดูแลระบบ (เจ้าของ)
| เมนู | หน้า | เนื้อหา |
|---|---|---|
| ภาพรวมระบบ | **ใหม่** | ผู้ใช้ active แยกบทบาท · ผู้ใช้ที่ยังไม่ได้จับคู่สถานี · สินค้าที่ยังไม่มีสูตรจักร · จักรเสีย · การเปลี่ยนแปลงล่าสุดจาก Audit Log |
| ผู้ใช้งาน | เดิม | ตั้งค่า → ผู้ใช้ (เพิ่ม/ปิดบัญชี · เปลี่ยนบทบาท) |
| Roles & Permissions | **ใหม่** | ตารางว่าแต่ละบทบาททำอะไรได้ (เริ่ม/เสร็จ · แทรกคิว · ปิดปัญหา · รับงาน · ส่งออก · ตั้งค่า …) · **ดูอย่างเดียว** เพราะสิทธิ์จริงบังคับในฐานข้อมูล ถ้าให้แก้สิทธิ์จากหน้าเว็บ กฎ workflow จะหลุดได้ · เปลี่ยนบทบาทของคนทำที่หน้าผู้ใช้งาน |
| Station Assignment | **ใหม่** | จับคู่พนักงาน ↔ สถานี (1 คนได้หลายสถานี) · STAFF เห็นและกดได้เฉพาะสถานีที่จับคู่ (บังคับในฐานข้อมูล) |
| Audit Log | **ใหม่** | ทุกการกระทำกับงาน (จาก `events`) + **บันทึกใหม่** การแก้ตั้งค่า/ผู้ใช้/สถานี/จักร (ใคร · เมื่อไร · ค่าเดิม → ค่าใหม่) · กรองตามคน / วัน / ชนิด |
| ตั้งค่าระบบ | เดิม | สถานี · เวลามาตรฐาน · วัตถุดิบ · เหตุผล · จักร · การแจ้งเตือน |

เจ้าของยังเปิดหน้าของทุกบทบาทได้ (กลุ่มเมนูที่ 2 "งานผลิต": ภาพรวมการผลิต · กำหนดส่งลูกค้า · ทุก Station · รายงาน)

## 3. แอดมิน
| เมนู | หน้า | เนื้อหา |
|---|---|---|
| ภาพรวมใบงาน | เดิม | สถานีตอนนี้ · งานส่งออกข้างนอก · สิ่งที่แอดมินต้องทำ |
| กำหนดส่งลูกค้า | **ใหม่ (26 พ.ย. แอดมินขอ)** | งานที่ต้องส่งลูกค้าเรียงตามวัน · วันนี้ต้องส่งอะไร พร้อมส่งหรือยัง อยู่สถานีไหน · วิธีรับสินค้า/ที่อยู่ · พิมพ์รายการ |
| จัดการใบงาน | เดิม (รวมใหม่) | รับงานใหม่ · ใบยืนยันที่บันทึกไว้ · ค้นหา/แก้งาน · ส่งออก/รับกลับ |
| คิวการผลิต | **ใหม่** | คิวทุกสถานีเรียงตามลำดับ (ดูอย่างเดียว · แทรกคิวเป็นสิทธิ์ฝ่ายผลิต/ผู้บริหาร) |
| ติดตาม Station | เดิม | บอร์ดทั้งโรงงาน |
| รายงาน | เดิม | **เปิดให้แอดมินดูได้** (ตอนนี้แอดมินดูไม่ได้) |

## 4. ผู้จัดการแผนกผลิต (ฝ่ายผลิต · ผู้ควบคุมงาน)
| เมนู | หน้า | เนื้อหา |
|---|---|---|
| ภาพรวมแผนก | **ใหม่** | สรุปเฉพาะสถานีที่ดูแล: งานกำลังทำ / รอคิว / พัก / ใกล้ครบ-เกินเวลามาตรฐาน · จักรว่าง |
| คิวงาน | เดิม | ต้องทำตอนนี้ + คิวของสถานีที่ดูแล (แทรกคิว · เริ่มข้ามคิว) |
| กำหนดส่งลูกค้า | **ใหม่ (26 พ.ย.)** | ดูว่างานไหนต้องเร่งให้ทันวันส่ง |
| Station ที่ดูแล | เดิม | บอร์ดเฉพาะสถานีที่ดูแล + จักรเย็บ |
| ปัญหา / งานแก้ | **ใหม่** | รายการปัญหาที่ยังเปิด (กด "แก้แล้ว ทำต่อ" ได้ในหน้านี้) · งานแก้ที่ QC ตีกลับ · รายงานเกินเวลามาตรฐาน |
| รายงานแผนก | เดิม + ตัวกรอง | รายงานเดิม กรองเฉพาะสถานีที่ดูแล |

## 5. STAFF (พนักงานสถานี · QC)
| เมนู | หน้า | เนื้อหา |
|---|---|---|
| งานของฉัน | เดิม | งานที่กำลังทำอยู่ที่สถานีของฉัน (เริ่ม · เสร็จ · พักงาน) |
| คิวงาน Station | เดิม | คิวของสถานีที่จับคู่ไว้ (ไม่ต้องเลือกสถานีเองแล้ว) |
| ประวัติการทำงาน | **ใหม่** | สิ่งที่ฉันกดวันนี้ / 7 วัน (เริ่ม · เสร็จ · พัก · QC) จาก `events` |
| รายงานปัญหา | **ใหม่** | เลือกงานที่สถานีของฉัน → เลือกเหตุผล → แจ้ง (ใช้ `open_issue` เดิม) · ดูว่าปัญหาที่แจ้งแก้แล้วหรือยัง |

**สิทธิ์ STAFF (บังคับในฐานข้อมูล):** เริ่ม · เสร็จ · พักงาน · รายงานปัญหา **เฉพาะสถานีที่จับคู่** · ไม่แทรกคิว ไม่ปิดปัญหา ไม่จัดจักร ไม่รับงาน

## ต้องตัดสิน
1. **รายการรออนุมัติ (ผู้บริหาร)** ตอนนี้ระบบไม่มีอะไรที่ "รออนุมัติ" (ทุกปุ่มมีผลทันที) · เสนอให้เป็น **"รอผู้บริหารดู"** ไม่หยุดงาน:
   - ปัญหาที่ยังเปิด (กดแก้แล้ว ทำต่อได้)
   - รายงานเกินเวลามาตรฐาน โดยเฉพาะที่ "ขอความช่วยเหลือ" → ผู้บริหารกด "รับทราบ"
   - งานที่ถูกแทรกคิว / เริ่มข้ามคิว (พร้อมเหตุผล) → กด "รับทราบ"
   - ถ้าต้องการ **อนุมัติจริง** (เช่น แทรกคิวต้องรอผู้บริหารกดอนุมัติก่อนมีผล) = เปลี่ยน workflow · แนะนำทำหลังเปิดใช้
2. **พนักงานหน้างานตอนนี้** จะใช้บัญชี STAFF รายคน (ต้องจับคู่สถานีทุกคน) หรือบัญชีฝ่ายผลิตแบบเดิม · มีผลกับการสร้างบัญชีวันอาทิตย์

## ลำดับทำ (เริ่มคืนนี้)
1. เมนูตามบทบาท + ย้ายหน้าเดิมเข้าเมนูใหม่ + แอดมินดูรายงานได้
2. บทบาท `staff` + ตาราง Station Assignment ในฐานข้อมูล (ลงฐานจริงก่อน merge)
3. หน้าใหม่: ปัญหา/งานแก้ · รายงานปัญหา · ประวัติการทำงาน · คิวการผลิต · ภาพรวมแผนก
4. Audit Log (บันทึกการแก้ตั้งค่า) · Roles & Permissions · ภาพรวมระบบ · รายการรออนุมัติ
5. แก้คู่มือ + ภาพหน้าจอ + แผนอบรม

**ความเสี่ยง:** อบรมเสาร์เช้า · ข้อ 1–3 ทันก่อนเสาร์ได้ · ข้อ 4–5 อาจเสร็จศุกร์ดึก · ทุกข้อแยก PR ถามก่อน merge ทีละอัน · ถ้าข้อไหนไม่ทันเสาร์ ไม่ merge แล้วอบรมด้วยของเดิมได้
