# สรุปผลตรวจระบบรอบ 18 สำหรับเจ้าของระบบ (ทดสอบครบทั้งระบบในเครื่อง)

> **อัปเดตจาก Claude:** แก้ครบทุกข้อแล้ว · ข้อ 1 ลงระบบจริงแล้ว · ข้อ 2–4 ขึ้นเว็บเมื่อ merge PR รอบนี้ · "ล่าช้า X วัน" นับวันปฏิทินตามที่ลูกค้ารอจริง (ตั้งใจ ไม่ใช่บั๊ก) · ข้อที่วัดลิ้นชักล้นจอไม่ใช่บั๊ก (วัดตอนลิ้นชักกำลังเลื่อน)

> **ตรวจเมื่อ:** 23 พ.ย. 2569 · ทดสอบบนระบบจำลองในเครื่องเท่านั้น ไม่ได้แตะระบบจริงและข้อมูลจริงของโรงงาน

## 2. บั๊กที่พบในรอบนี้ (เรียงตามความสำคัญ)

### ระดับ 1 — แจ้งทันทีและแก้ไขแล้วบนระบบหลัก (`main` PR #192)
1. **แก้ใบยืนยันจากงานที่แบ่งออกมา (`-2`) ไม่ได้ และไม่ไปอัปเดตงานแม่ (`R18-01`):**
   - **เกิดอะไร:** ถ้าแอดมินเปิดใบยืนยันจากงานลูก (`-2`) เพื่อแก้สเปก ระบบเดิมปฏิเสธว่าเลขที่ใบไม่ตรง และดึงข้อมูลเฉพาะงานลูกไม่รวมงานแม่
   - **กระทบใคร:** แอดมินที่แก้ใบยืนยันจากงานที่ถูกแบ่งออกไปแล้ว
   - **สถานะ:** **แจ้งและแก้ไขแล้วใน `main` (PR #192)**

### ระดับ 2 — ควรแก้ไขต่อ
2. **ป้าย "ล่าช้า X วัน" นับรวมวันอาทิตย์ และหน้าภาพรวมยังใช้คำเดิม (`R18-02`):**
   - **เกิดอะไร:** งานที่เลยกำหนดข้ามวันอาทิตย์ถูกนับวันอาทิตย์รวมไปด้วย (เช่น เลยมาวันพฤหัส ถึงวันจันทร์ขึ้น `ล่าช้า 4 วัน` แทนที่จะเป็น 3 วันทำงาน) และในหน้า **ภาพรวม** ยังขึ้นคำว่า `เลยกำหนดส่ง` ไม่ขึ้น `ล่าช้า X วัน` เหมือนหน้าบอร์ด
   - **กระทบใคร:** แอดมินและผู้บริหารที่ดูจำนวนวันล่าช้าเพื่อเร่งงาน
   - **ระหว่างรอแก้:** นับวันจันทร์–เสาร์ด้วยตาคร่าวๆ หากเลยกำหนดข้ามวันอาทิตย์จะบวกเพิ่ม 1 วัน

### ระดับ 3 — ปรับปรุงเพิ่มความสะดวกและสิทธิ์หน้าจอ
3. **พนักงานสถานีที่พิมพ์ลิงก์หน้า "คิวการผลิต" ตรงๆ ยังเปิดดูคิวทุกสถานีได้ (`R18-03`):**
   - **เกิดอะไร:** ปกติเมนูพนักงานไม่มีหน้านี้ แต่ถ้าพิมพ์ลิงก์ `#/production-queue` เองจะเปิดดูคิวทั้งโรงงานได้ (กดสั่งงานไม่ได้ ระบบป้องกันไว้แล้ว)
   - **ระหว่างรอแก้:** ไม่มีผลต่อข้อมูล เพราะกดแก้ไขอะไรไม่ได้
4. **ฟอร์มแก้ใบหลังรับงานยังกดเปลี่ยน "สินค้า" และ "ขึ้นตัวอย่าง" บนหน้าจอได้ (`R18-04`):**
   - **เกิดอะไร:** ปุ่มเปลี่ยนสินค้าและตัวเลือกขึ้นตัวอย่างในฟอร์มแก้ใบยังไม่ถูกปิดไว้ แอดมินจะถูกปฏิเสธก็ต่อเมื่อกด "บันทึกการแก้เข้างาน" แล้ว
   - **ระหว่างรอแก้:** หากลูกค้าเปลี่ยนชนิดสินค้าหรือเปลี่ยนการขึ้นตัวอย่าง ให้แจ้งผู้บริหารยกเลิกงานแล้วรับเป็นใบใหม่แทน

## 3. สิ่งที่ต้องบอกทีม
- **เวลาแก้ใบยืนยันหลังรับงาน:** ทำได้ทั้งเปลี่ยนลูกค้า, ชื่องาน, จำนวน, กำหนดส่ง และสเปก แต่ **ห้ามเปลี่ยนชนิดสินค้าหรือเปลี่ยนการขึ้นตัวอย่าง** (ถ้าเปลี่ยนต้องให้ผู้บริหารยกเลิกงานแล้วรับใหม่) และถ้างานมีม็อคอัพกำกับสเปกที่อนุมัติแล้ว ระบบจะเตือนจุดที่เป็นค่าเก่าให้แอดมินเข้าไปสร้างม็อคอัพฉบับใหม่ด้วย
- **ปุ่ม "ไม่ใช้กับงานนี้" ในฟอร์มใบยืนยัน:** ช่องบังคับที่งานนั้นไม่ใช้ แอดมินกด "ไม่ใช้กับงานนี้" เพื่อซ่อนคำเตือนและไม่พิมพ์ลง PDF ได้เลย

## 4. ข้อเสนอที่ไม่ใช่บั๊ก
- ให้หน้า **ภาพรวม** ใช้ป้าย `"ล่าช้า X วัน"` แบบเดียวกับหน้าบอร์ดและรายละเอียดงาน เพื่อให้ทุกคนเห็นตัวเลขเดียวกันทั้งระบบ
- ล็อกปุ่ม "เปลี่ยนสินค้า" และตัวเลือก "ขึ้นตัวอย่าง" ในฟอร์มใบยืนยันเมื่อเปิดมาจากงานที่รับแล้ว เพื่อไม่ให้แอดมินเผลอแก้แล้วโดนปฏิเสธตอนบันทึก
