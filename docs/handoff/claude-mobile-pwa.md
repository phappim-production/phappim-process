## ข้อ 4: ล็อกอินค้างบนเครื่องสถานี — **เดิมทำได้อยู่แล้ว ไม่ได้แก้**
supabase-js เก็บ session ใน localStorage (`persistSession` ค่าเริ่มต้น) และต่ออายุเอง · ไม่มีโค้ดออกจากระบบอัตโนมัติ (ออกได้ทางปุ่มเท่านั้น) · สคริปต์กู้แอปค้าง (PR 222) ล้างแค่ cache/service worker ไม่ล้าง localStorage · `qa-mobile.mjs` ข้อ `login-stays-after-reopen` ยืนยันแล้ว
ข้อควรรู้: iPhone ที่เปิดผ่าน Safari ธรรมดา (ไม่ได้ติดตั้ง) แล้วไม่ใช้ 7 วัน iOS ลบ localStorage → ต้องเข้าใหม่ · แอปที่ติดตั้งบนหน้าจอโฮมไม่โดน (เขียนไว้ในคู่มือแล้ว) · ถ้าเจ้าของตั้ง "Time-box / Inactivity timeout" ใน Supabase Auth ไว้ จะออกเองตามนั้น (ไม่ได้ตรวจในระบบจริงตามกติกา)
