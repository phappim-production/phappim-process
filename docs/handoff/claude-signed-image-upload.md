# แนบใบยืนยันที่ลูกค้าเซ็นเป็นรูปได้ + ตัดลายเซ็นจากรูปที่แนบไว้ (28 พ.ย. · เจ้าของขอ)

เจ้าของ: "ให้สามารถ อัพโหลดใบยืนยันที่ลูกค้าเซ็นแล้วเป็นไฟล์รูปภาพได้ด้วย เพราะตอนนี้เหมือนจะรับแค่ PDF และ การคอบลายเซ็นลูกค้ามาใช้งานก็ต้องรองรับแบบ PDF ด้วย"

## ตรวจแล้วพบ (ที่บังคับ PDF อย่างเดียว)
- ฐาน: `private.check_confirmation_pdf` (นามสกุล .pdf) · `private.check_file_upload` (ชนิด + path .pdf) · bucket สำรอง `confirmations` รับ PDF อย่างเดียว
- Worker `workers/files`: `KINDS.confirmations` path/ชนิด PDF อย่างเดียว
- แอป: `pdfProblem` · `confirmationPath` (.pdf ตายตัว) · ช่องเลือกไฟล์ `accept="application/pdf"` ที่หน้ารับงานและรายละเอียดงาน · อัปโหลดด้วยชนิด `application/pdf` ตายตัว
- ตัดลายเซ็น (`CustomerSignature.tsx`): รับเฉพาะรูปจากเครื่อง · ใบที่แนบไว้ในงานใช้ไม่ได้ · PDF ต้องแคปหน้าจอเอง

## เปลี่ยนอะไร
- migration `20261216000000_signed_confirmation_images.sql`: ใบยืนยันรับ `.pdf / .jpg / .png / .webp` ชนิดต้องตรงนามสกุล · ข้อความ error ไทยใหม่ · bucket สำรองรับชนิดเดียวกัน
- Worker: confirmations รับรูป JPG / PNG / WEBP (ตรวจเนื้อไฟล์เหมือนเดิม) · ลิงก์เปิดไฟล์ตอบ CORS ให้เว็บที่อนุญาต (แอปอ่านใบที่แนบไว้มาตัดลายเซ็น) · **ต้อง deploy Worker ใหม่**
- แอป: `SIGNED_TYPES` / `signedExt` (ดูชนิดไฟล์ก่อน เครื่องที่ไม่บอกชนิดดูนามสกุล · .jpeg → .jpg) / `signedFileProblem` / `isSignedImage` · หน้ารับงาน + รายละเอียดงาน (แนบ / เปลี่ยนใบ) รับ PDF หรือรูป · ปุ่มเปิดบอก "เปิดรูปใบยืนยันที่ลูกค้าเซ็น" เมื่อเป็นรูป · ประวัติงานบอกว่าแนบรูป/PDF · คำแปลพม่า 4 คำ
- ตัดลายเซ็น: ปุ่ม "ใช้ใบที่ลูกค้าเซ็นที่แนบไว้ในงาน" (รูปหรือ PDF) · `fetchAttached`
- **ตัดลายเซ็นจาก PDF** (เจ้าของอนุญาตเพิ่ม `pdfjs-dist@6.5.438`): `app/src/data/pdfPages.ts` แปลงหน้า PDF เป็นภาพด้านยาว 2400 px · เปิดหน้าสุดท้ายก่อน (ช่องเซ็นอยู่ท้ายใบ) · ปุ่มหน้าก่อน / หน้าถัดไป · PDF ติดรหัสผ่าน / ไฟล์เสีย บอกให้แคปหน้าจอ
- pdf.js โหลดเฉพาะตอนเปิด PDF ในหน้าตัดลายเซ็น (แยกไฟล์ `pdfjs-*.js` 444 KB + worker 1.27 MB) · ไม่ใส่ในแคชของแอป (`globIgnores`) เครื่องหน้างานไม่ต้องโหลด · worker ตั้งชื่อ `.js` (เซิร์ฟเวอร์บางที่ส่ง `.mjs` เป็นชนิดผิด เบราว์เซอร์ไม่รัน)
