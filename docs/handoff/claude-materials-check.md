# ขั้นรอผลิต: เช็ควัตถุดิบ + ถ่ายรูป ก่อนปล่อยเข้าไลน์ (26 พ.ย.)

เจ้าของสั่ง: รับงานเข้าโรงงานแล้วให้ไปอยู่ **รอผลิต** ก่อน (ไม่ใช่รอพิมพ์ทันที) · มีเช็คลิสต์วัตถุดิบ · ครบแล้วแอดมินจึงนำเข้าไลน์การผลิต · ถ่ายรูปวัตถุดิบ
คำตอบเจ้าของ: ติ๊ก = **แอดมินคนเดียว** · รายการ = **แอดมินพิมพ์เองทุกงาน** · รูป = **รูปรวมอย่างน้อย 1 รูปต่องาน** · เวลาผลิต = **นับจากวันปล่อยเข้าไลน์**

## เปลี่ยนอะไร
- ฐานข้อมูล `20261206000000_materials_check.sql`
  - `production_settings.materials_check` (ค่าเริ่ม เปิด) · ปิด = `receive_job` ปล่อยทันทีแบบเดิม
  - `job_material_photos` (path ใน bucket `mockups` โฟลเดอร์ของใบ · ห้ามเก็บรูปในตาราง) + Realtime + `file_read_allowed` เปิดรูปได้
  - RPC ใหม่ (admin · owner): `set_job_materials` · `add_material_photos` · `remove_material_photo` · `release_job` · แก้ `check_material` เป็นแอดมินเท่านั้น ไม่ปล่อยเอง
  - `release_job`: ต้องมีรายการ ≥ 1 ติ๊กครบ รูป ≥ 1 · คิวต่อท้าย (`queue_seq` ใหม่) · event `released` `manual: true`
  - `lead_state`: งานรอผลิต = ยังไม่นับ · เริ่มนับวันที่ปล่อยแบบ manual ของงานต้นทาง · งานเดิม (ไม่มี event manual) ใช้วันรับงานเหมือนเดิม
- หน้าเว็บ
  - บอร์ดมีคอลัมน์ **รอผลิต** (กลุ่มก่อนผลิต) · การ์ด "รอเช็ควัตถุดิบ" · พนักงานสถานี / QC / ผู้ควบคุมงาน ไม่เห็นงานนี้
  - รายละเอียดงาน: แผง **รอผลิต · เช็ควัตถุดิบ** (`app/src/pages/MaterialsCheck.tsx`) แอดมินเพิ่ม/ลบ/ติ๊กรายการ ถ่ายรูป (กล้องหลัง · ย่อรูป · ≤ 12) ปุ่มปล่อยบอกเหตุผลที่กดไม่ได้ + กล่องยืนยัน · บทบาทอื่นอ่านอย่างเดียว
  - ต้องทำตอนนี้ / ภาพรวม / ค้นหางาน / กำหนดส่งลูกค้า / ประวัติงาน ใช้คำ "รอผลิต" · หน้ารับงานบอกว่าเวลาผลิตนับจากวันปล่อย · ข้อความหลังรับงานบอกให้ไปเช็ควัตถุดิบ
  - คำแปลพม่าของข้อความที่พนักงานอาจเห็น
- ระบบจำลอง `tools/qa-r14`: ปิดขั้นนี้เป็นค่าเริ่ม (ชุด QA เดิมรับงานแล้วเริ่มสถานีแรก) · เปิดด้วย `QA_MATERIALS_CHECK=1` หรือ `/__qa/sql` · ชุดใหม่ `qa-materials.mjs`
- คู่มือแอดมิน (ข้อ 3.1) · ฝ่ายผลิต · เจ้าของระบบ · `docs/api-workflow.md` · `DEVELOPMENT.md`

- ตรวจทานโดยผู้ตรวจแยก แล้วแก้: เตือนแอดมินเมื่อรอผลิตเกิน 2 วัน (เดิมเตือนเฉพาะงานที่มีรายการยังไม่ติ๊ก) · ปิดขั้นภายหลังแล้วงานที่ค้างไม่หลุดเข้าไลน์ตอนสั่งฟิล์ม + กดปล่อยได้ไม่ต้องเช็ค · ใช้รูปม็อคอัพเป็นรูปวัตถุดิบไม่ได้ · แนบรูปเดิมซ้ำบอกว่าแนบแล้ว · 2 เครื่องแก้รายการพร้อมกันไม่ทับกัน (`p_base`) · พยากรณ์วันเสร็จของงานรอผลิตที่ขึ้นตัวอย่างนับวันตัวอย่าง · ปุ่มลบรูปไม่ทับรูปข้างกัน · เลือกรูปจากคลังได้ · ข้อความเกินเวลาผลิตบอก "เริ่มนับ" แทน "รับงาน"

## ยังไม่ได้ทำ / ต้องรู้
- **ยังไม่ลงฐานจริง** · ลงแล้วขั้นนี้เปิดทันที: งานที่รับหลังจากนั้นจะรอที่รอผลิตจนแอดมินปล่อย (งานที่อยู่ในไลน์แล้วไม่กระทบ)
- หน้าตั้งค่ายังไม่มีสวิตช์เปิด/ปิดขั้นนี้ (ปิดได้ที่ฐานข้อมูล `update public.production_settings set materials_check = false`)
- แท็บ "แม่แบบวัตถุดิบ" ในหน้าตั้งค่ายังไม่ใช้ (เจ้าของเลือกให้แอดมินพิมพ์เองทุกงาน)

## เพิ่ม 26 พ.ย. ค่ำ: ส่งออกจากรอผลิต
เจ้าของสั่ง: "ในสถานะรอผลิต จะต้องสามารถส่งออกภายนอกได้ด้วย และการส่งออกภายนอก ไม่ต้องมีการเช็ควัตถุดิบ" · migration `20261208000000_outsource_from_waiting.sql` (`send_out` รับงาน `materials` → ปล่อยเข้าไลน์ไม่ตรวจ + ส่งออกจากสถานีแรก · ส่งไม่สำเร็จย้อนกลับทั้งหมด) · แผงส่งออกขึ้นในงานรอผลิต · ประวัติ "ส่งออกบริษัทภายนอก · ไม่ต้องเช็ควัตถุดิบ" · ทดสอบ `supabase/tests/outsource-waiting.mjs` + `qa-materials.mjs` ขั้น outsource-from-waiting
