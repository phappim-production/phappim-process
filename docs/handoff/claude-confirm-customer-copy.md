# ใบยืนยันการผลิต: ฉบับลูกค้า / ฉบับโรงงาน

## เจ้าของสั่ง
ใบที่ส่งลูกค้าเซ็นต้องไม่เห็นยอดเผื่อเสีย และรายละเอียดภายในโรงงาน (เทคนิค สีหมึก สีด้าย ฯลฯ)
ลูกค้าเห็นแค่: รหัสลูกค้า (เลข SC) · ประเภทสินค้า · วันที่สั่งงาน · เลขที่งาน · วัสดุที่ใช้ · การแพ็คจัดส่ง · ชื่อลูกค้า · จำนวนงาน · การจัดส่ง · ผู้ประสานงาน · Size

## เปลี่ยนอะไร (`production-confirmation.html`)
- **ฉบับลูกค้า** = "ดูตัวอย่าง PDF" / "ส่งออก PDF" ในฟอร์มที่แอดมินกรอก
  - หัวใบ (ทุกหน้า): เลขที่ใบ SC · ประเภทสินค้า · ลูกค้า · ชื่องาน · จำนวน
  - ข้อมูลใบ: วันที่สั่งงาน (= วันที่ออกใบ) · ผู้ประสานงาน (แอดมิน + เบอร์) · การจัดส่ง (+ ที่อยู่)
  - หัวข้อสินค้า: เฉพาะวัสดุ (ชนิดผ้า สีผ้า ผ้าเพิ่ม วัสดุ ผ้าซับใน ไส้ สีหมวก) · ไซซ์และจำนวน (ตารางจำนวน ตารางไซซ์ ขนาดสำเร็จ รายการ ขนาด) · แพ็คกิ้งทั้งหัวข้อ
  - ยังพิมพ์: ภาพม็อคอัพ + จุดกำกับ (อ้างได้เฉพาะช่องที่ลูกค้าเห็น) · ข้อตกลง · ช่องเซ็น
  - ไม่พิมพ์: เผื่อเสีย · ผู้ติดต่อ/เบอร์ลูกค้า · วันนัดส่งตัวอย่าง · แบบและแพทเทิร์น · งานพิมพ์ (เทคนิค ตำแหน่ง สีหมึก สีด้ายปัก สีฟอยล์ การเทียบสี) · การเย็บ · ป้าย · หมายเหตุถึงฝ่ายผลิต · คอลัมน์ "พิมพ์สี / หมายเหตุ" ของผ้าเพิ่ม
- **ฉบับโรงงาน** = เปิดดูจากระบบ (ดูอย่างเดียว) · แสดงครบทุกช่องเหมือนเดิม + หัวใบเขียน "ฉบับโรงงาน"
- ข้อมูลที่บันทึกเข้าระบบ / บันทึกไฟล์ ไม่เปลี่ยน (`p_spare_qty` และทุกช่องยังส่งครบ) · การตรวจช่องบังคับไม่เปลี่ยน

## ทดสอบ
- `app/tests/confirmationBehavior.test.mjs` 3 ข้อใหม่: ฉบับลูกค้าซ่อน/แสดงตามรายการ + ระบบได้รับครบ · จุดกำกับในฉบับลูกค้า · ฉบับโรงงานเห็นครบ
- ข้อเดิม "ไม่มีปกไม่พิมพ์ลง PDF" ตรวจในฉบับโรงงานแทน (ปกไม่อยู่ในฉบับลูกค้าแล้ว) · harness เพิ่ม `setViewOnly`
- `npm run build` · `npm run lint` · `npm test` (app 567 + 173) · `supabase/tests` 106 ผ่าน
- เครื่องตัวเอง (`tools/qa-r14/server.mjs`, `/confirmation`) 375 / 768 / 1440 px: ไม่ล้นข้าง · console ไม่มี error · ฉบับลูกค้าไม่มีคำภายใน · ฉบับโรงงานเห็นครบ

## ยังไม่ได้ทำ / ให้เจ้าของดู
- "เลขที่งาน" ใช้ชื่องานที่หัวใบ (ฟอร์มไม่มีเลขงานแยกจากเลข SC)
- ไม่พิมพ์ "กำหนดส่งงาน" (เดิมก็ไม่ได้พิมพ์) และวันนัดส่งตัวอย่าง (ไม่อยู่ในรายการ)
- แอดมินพิมพ์ "ฉบับโรงงาน" จากฟอร์มเองไม่ได้ ต้องเปิดดูจากระบบ

## รอบ 2 (เจ้าของดูแล้ว)
- ฉบับลูกค้าไม่พิมพ์หัวข้อว่าง "ไฟล์งานและหมายเหตุ" เหนือภาพม็อคอัพอีก (ชื่อไฟล์งานไม่พิมพ์อยู่แล้ว) · การเย็บ งานพิมพ์ / ตกแต่ง ไม่พิมพ์อยู่แล้วตั้งแต่รอบ 1 · ฉบับลูกค้าเหลือหัวข้อ ผ้า / ไซซ์และจำนวน / แพ็คกิ้ง + ภาพ
- เอาช่องเซ็น "แอดมินผู้ทำใบ" ออก (ทั้งสองฉบับ) เหลือ ลูกค้า + ผู้ควบคุมงาน
- ทดสอบใหม่ 2 ข้อ · build / lint / app 567 + 175 / supabase 106 ผ่าน · เครื่องตัวเอง 375 / 768 / 1440 px ไม่ล้น ไม่มี error
